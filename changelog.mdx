<Update label="September 23, 2026" tags={["New releases", "Improvements"]}>
  ## New features

  - **Projects page:** A dedicated `/projects` page now showcases every side project in a responsive card grid. Each card shows the name, tagline, description, tech stack, and a link to the repository or live site. [Learn more](/projects).
  - **Tech filter:** Filter the project grid by technology using the buttons above the cards. Select **All** to reset.
  - **Project search:** Use the search box to find projects by name, tagline, or description. Search works together with the tech filter.

  ## Updates

  - **Status badges:** Each project card now shows an **Active** or **Archived** badge. You can tell at a glance which projects are still maintained. [Learn more](/projects#entry-schema).
</Update>
