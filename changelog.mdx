<Update label="September 8, 2026">

## New features

### Projects showcase page

The site has a dedicated `/projects` page that lists side projects in a responsive grid. Each card shows the project name, a one-line tagline, a longer description, tech stack tags, and a link to the repository or live site. Visitors can browse the full catalog without scrolling the home page.

See [the projects page guide](/projects) for the entry schema and writing guidance.

## Updates

### Search on the projects page

A search box on `/projects` matches against each project's name, tagline, and description. Search combines with the tech filter, so visitors can narrow results by keyword and stack at the same time.

### Filter projects by tech

Filter buttons above the grid let visitors show only projects built with a given technology. The filter list is generated from the tags on each project card.

### Project status badges

Each project card now shows an **Active** or **Archived** badge. Visitors can tell at a glance whether a project is still maintained (green) or frozen (gray). See [status guidance](/projects#writing-guidance) for when to use each label.

</Update>
