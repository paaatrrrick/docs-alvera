<Update label="November 10, 2026" description="Week of November 2" tags={["New features"]}>
  ## New features

  - **Sort guestbook entries:** A new toggle above the entry list lets visitors sort the current page by **Newest** or **Most reactions**, so popular notes are easy to find. Learn more in [Guestbook](/guestbook).
  - **Search guestbook entries:** A search box next to the sort toggle filters the current page by name or message, ignoring case. While a search is active, the entry count shows how many entries match, such as **3 of 25 entries**. Learn more in [Guestbook](/guestbook).
</Update>

<Update label="October 10, 2026" description="Week of October 5" tags={["New features"]}>
  ## New features

  - **Source code links on project cards:** Project entries now accept an optional `repo` URL. When you set it, the card shows a **Source code** link next to the tech list, so visitors can jump straight to the repository even when the card heading points to a live site. Learn more in [Projects](/projects).
</Update>
