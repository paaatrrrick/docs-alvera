<Update label="September 8, 2026" description="Projects page">

## New features

- **Projects showcase page.** The site now has a dedicated `/projects` page that lists every side project in a responsive grid. Each card shows the project name, a one-line tagline, a description, tech stack tags, and a link to the repository or live site. Visitors can browse the full catalog without scrolling the home page. See [the projects page guide](/projects).
- **Project search.** A search box at the top of `/projects` filters projects as you type. It matches against the project name, tagline, and description, and works together with the tech filter. An empty state appears when no projects match.

## Updates

- **Status badges on project cards.** Each project card now shows an **Active** or **Archived** badge next to its name. Active projects get a green badge and archived projects get a gray badge, so visitors can tell at a glance which projects are still maintained. See [the entry schema](/projects#entry-schema) for how to set a project's status.
- **Filter projects by tech.** Filter buttons above the grid narrow the list to projects that use a specific technology. Selecting **All** clears the filter.

</Update>
