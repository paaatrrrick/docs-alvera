<Update label="July 23, 2026">

## New features

- **Project status badges.** Each card on [`/projects`](/projects) now shows an **Active** or **Archived** badge in its header, so visitors can tell at a glance which projects are still maintained and which are frozen. Set the `status` field on any entry to `'Active'` (green) or `'Archived'` (gray). See the [entry schema](/projects#entry-schema) for details.

- **Search and tech filter on `/projects`.** The projects page now has a search box that matches project name, tagline, and description, plus a tech-stack filter. Combine both to narrow the grid down to exactly what you're looking for. See [writing guidance](/projects#writing-guidance) for tips on making your entries searchable.

</Update>
