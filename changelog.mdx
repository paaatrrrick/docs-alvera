<Update label="October 22, 2026" description="Week of October 19" tags={["Coming soon"]}>
  ## Coming soon

  - **Book club monthly picks:** The site now stores a monthly book club pick with a title, a meeting date, and a link to join the meeting. The first pick is *The Pragmatic Programmer*, with a meeting on November 20, 2026. The book club launches on November 10, 2026. Until then, it stays hidden unless you set `REACT_APP_BOOKCLUB=on`.
</Update>

<Update label="October 10, 2026" description="Week of October 5" tags={["New features"]}>
  ## New features

  - **Source code links on project cards:** Project entries now accept an optional `repo` URL. When you set it, the card shows a **Source code** link next to the tech list, so visitors can jump straight to the repository even when the card heading points to a live site. Learn more in [Projects](/projects).
</Update>
