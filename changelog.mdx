<Update label="September 8, 2026">

## New features

- **Search on the projects page.** A search box on `/projects` filters projects by name, tagline, or description. Search combines with the tech filter, and an empty state appears when nothing matches, so you can find a specific project quickly.
- **Tech stack filter.** Filter buttons on `/projects` are built from each project's tech tags. Select a technology to narrow the grid to projects that use it.
- **Project status badges.** Each project card now shows an Active or Archived badge, so you can tell at a glance which projects are still maintained.

For details on how project cards are structured, see the [projects page guide](/projects).

</Update>
