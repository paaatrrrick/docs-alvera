## Week of June 22, 2026

### New features

- **Projects showcase page.** A dedicated [`/projects`](/projects) page lists side projects in a responsive grid, with each card showing a tagline, description, tech tags, and a link to the repo or live site.
- **Search on `/projects`.** A search box filters projects by name, tagline, or description, and stacks with the tech filter. An empty state appears when nothing matches. See the [projects page guide](/projects) for how to write entries that surface well in search.
- **Tech filter on `/projects`.** Filter the grid by stack tag to narrow the list to a specific technology.
- **Status badges on project cards.** Each project card now shows an `Active` or `Archived` badge so visitors can tell at a glance which projects are still maintained. See [status badges](/status-badges) for the styling reference.
- **FAQ page.** A new FAQ page answers the most common questions in one place.
- **Advisory services section.** A new advisory page describes availability, focus areas, and how to get in touch.
- **Newsletter signup.** A subscribe form is now embedded on the site, backed by a lightweight subscription flow.
- **Digest cadence picker.** Subscribers can choose their newsletter cadence and the site remembers the preference between visits.
- **Digest time zone selection.** Pick the time zone the digest is sent in so it lands at a sensible local hour.
- **Pause and resume the digest.** Subscribers can temporarily pause the newsletter without unsubscribing, then resume when they're ready.
- **Next send preview.** The subscription UI now previews the next scheduled send time so you know exactly when the digest is coming.
- **Post view counter and total site views.** Each post shows its own view count, and the site footer surfaces a running total across all posts. Details in [post view counter](/post-view-counter).
- **Post meta byline.** Every post now leads with a byline containing the date, reading time, and view count.
- **Most-read popular posts widget.** A widget highlights the most-read posts so new visitors can jump straight to the highlights.
- **Comments on posts.** Readers can comment on posts, sort the thread, and see a comment count badge next to each post.
- **Bookmark search.** Search across bookmarks from the bookmarks page.
- **Command palette theme command.** Trigger light/dark theme changes directly from the command palette.
- **Feeds hub.** RSS, Atom, and JSON feeds are now built from a single index so subscribers can pick whichever format they prefer.

### Updates

- **Related posts weighted by recency.** The related-posts module now favors newer posts, so recommendations stay fresh as more content ships.
