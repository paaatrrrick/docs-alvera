<Update label="September 25, 2026" description="Week of September 21" tags={["New features", "Updates"]}>
  ## New features

  - **Project status badges.** Each card on the `/projects` page now shows an **Active** or **Archived** badge. Active projects get a green badge, and archived projects get a gray one. You can tell at a glance which projects are still maintained. See [Projects page](/projects#entry-schema).

  ## Updates

  - **Search projects.** Use the search box on `/projects` to find projects by name, tagline, or description. Search works together with the tech filter. See [Writing guidance](/projects#writing-guidance).
  - **Filter by tech.** Filter the project grid by technology with the buttons above the cards. Select **All** to reset.
</Update>
