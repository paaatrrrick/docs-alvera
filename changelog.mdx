<Update label="August 26, 2026">
  ## New features

  ### Search on the projects page

  The projects showcase page now includes a search box. Enter a query to filter projects by name, tagline, or description as you type.

  What this means for you:

  - Find a specific project quickly instead of scrolling the full grid.
  - Combine search with the existing tech stack filter to narrow results further. Only projects that match both stay visible.
  - See a clear empty state message when no projects match your search.

  Learn more about how the page is configured on the [projects page guide](/projects).
</Update>
