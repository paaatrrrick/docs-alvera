<Update label="Week of July 6, 2026">

## New features

- **Search on the [projects page](/projects).** The `/projects` showcase now includes a search box that filters by project name, tagline, and description. Search combines with the existing tech filter, so you can narrow to a stack and then search within it. When no projects match, the page shows a short empty state so it's clear the search ran.

## Writing guidance

- Project entries surface from search based on `name`, `tagline`, and `description`. When adding or editing an entry in the projects list, include the words a visitor would actually type — product category, problem space, or stack keywords that aren't already tags. See the updated [projects page guide](/projects) for the full field-by-field guidance.
