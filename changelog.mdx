<Update label="November 10, 2026" description="Week of November 2" tags={["New features"]}>
  ## New features

  - **Sort guestbook entries:** Visitors can switch between **Newest** and **Most reactions** above the entry list to surface the most popular notes. Learn more in [Guestbook](/guestbook).
  - **Search guestbook entries:** A new search box filters entries by name or message as visitors type. The entry count updates to show how many entries match. Learn more in [Guestbook](/guestbook).
</Update>

<Update label="October 10, 2026" description="Week of October 5" tags={["New features"]}>
  ## New features

  - **Source code links on project cards:** Project entries now accept an optional `repo` URL. When you set it, the card shows a **Source code** link next to the tech list, so visitors can jump straight to the repository even when the card heading points to a live site. Learn more in [Projects](/projects).
</Update>
