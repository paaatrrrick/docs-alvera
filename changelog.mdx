<Update label="October 5, 2026" description="Week of September 28" tags={["New features", "Updates"]}>
  ## New features

  - **Featured projects**: Mark a project as featured to pin it to the top of the [projects page](/projects) with a "Featured" badge.
  - **Project year**: Add an optional year to a project. It appears next to the project's tagline.
  - **Company links on roles**: Add an optional link to a role in [work experience](/work-experience). The role title then links to the company's site and opens in a new tab.
  - **Skills on roles**: List optional skills for each role. They appear under the role title.

  ## Updates

  - **Customizable post byline**: The [post byline](/post-view-counter#adding-the-byline-to-a-post-template) is now configurable. You can:
    - Hide the date, reading time, or view count individually.
    - Choose the separator shown between byline items. The default is `·`.
    - Add your own styling class to the byline.

  All new options are optional. Existing projects, roles, and posts look the same as before.
</Update>
