<Update label="October 22, 2026" description="Week of October 19" tags={["Upcoming"]}>
  ## Upcoming

  - **Book club monthly picks:** The site now stores a monthly book club pick with a title, a meeting date, and a link to join the meeting. Each pick is keyed to a month, and the site shows the pick that matches the current month. Book club is hidden behind the `REACT_APP_BOOKCLUB=on` environment variable and isn't visible to visitors yet. The public launch is planned for November 10, 2026.
</Update>

<Update label="October 10, 2026" description="Week of October 5" tags={["New features"]}>
  ## New features

  - **Source code links on project cards:** Project entries now accept an optional `repo` URL. When you set it, the card shows a **Source code** link next to the tech list, so visitors can jump straight to the repository even when the card heading points to a live site. Learn more in [Projects](/projects).
</Update>
