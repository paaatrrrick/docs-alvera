## Week of September 11, 2026

### New features

- **Search on the projects page.** You can now filter the [`/projects` showcase](/projects) with a search box that matches against a project's name, tagline, and description. Search combines with the existing tech filter, so you can narrow to a stack (for example, `React`) and then type a keyword to find a specific project inside that stack. When nothing matches, the grid shows an empty state instead of leaving the page blank.
