<Update label="July 10, 2026">

## New features

- **Search on the projects page.** The [`/projects` page](/projects) now includes a search box that filters projects by name, tagline, or description. Search works alongside the existing tech filter, so you can narrow by stack and keyword at the same time. When no projects match, the page shows an empty state instead of a blank grid.
