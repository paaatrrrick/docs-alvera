<Update label="October 30, 2026" description="Week of October 26" tags={["New features"]}>
  ## New features

  - **Embedded talk recordings (rolling out November 3):** Talks can now embed a recording from YouTube or Vimeo directly on the page. YouTube videos use privacy-enhanced (no-cookie) mode and Vimeo videos use do-not-track mode, so visitors aren't tracked just by viewing the page. You can optionally set a start time in seconds to jump straight to the relevant part of the talk. Only YouTube and Vimeo are supported. Recordings from other providers aren't embedded.
</Update>

<Update label="October 10, 2026" description="Week of October 5" tags={["New features"]}>
  ## New features

  - **Source code links on project cards:** Project entries now accept an optional `repo` URL. When you set it, the card shows a **Source code** link next to the tech list, so visitors can jump straight to the repository even when the card heading points to a live site. Learn more in [Projects](/projects).
</Update>
