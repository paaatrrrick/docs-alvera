<Update label="September 9, 2026" description="Projects search">

## New features

**Search on the projects page**

The [projects page](/projects) now includes a search box. Type a query to filter the project grid by name, tagline, or description.

- Search works alongside the existing tech filter, so you can narrow results by both a query and a technology at the same time.
- If nothing matches, the page shows an empty state instead of a blank grid.

</Update>
