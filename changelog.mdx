<Update label="July 15, 2026">

## New features

- **Search on the projects page.** The [`/projects`](/projects) showcase now includes a search box that filters entries by name, tagline, or description. Combine it with the existing tech filter to narrow the grid to the projects you're looking for. When no projects match the current query and filter, an empty state appears in place of the grid so it's clear nothing was hidden by accident.
