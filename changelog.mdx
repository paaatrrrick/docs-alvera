## Week of September 8, 2026

### New features

- **Search on the projects page.** The [`/projects`](/projects) showcase now has a search box that filters cards by project name, tagline, or description. Search stacks with the existing tech filter, so you can narrow to a stack and then type a keyword to find a specific project. When no project matches, the page shows an empty state instead of a blank grid. See [Projects page: structure and updates](/projects) for the field-by-field writing guidance that helps entries surface in search.
