## Week of July 17, 2026

### New features

- **Search on the projects page.** You can now search the [`/projects`](/projects) showcase by name, tagline, or description. Search works alongside the existing tech filter, so you can narrow to a stack and then type a keyword to find the exact project. When nothing matches, the page shows an empty state instead of a blank grid.

  Tip for authors: write the `name`, `tagline`, and `description` fields with the words a visitor would actually type. See the [projects page guide](/projects) for writing guidance.
