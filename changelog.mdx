<Update label="September 25, 2026" description="Week of September 21" tags={["New features", "Updates"]}>

## New features

- **Search on the projects page:** The [projects page](/projects) now has a search box. Type to filter projects by name, tagline, or description, so you can find a project without scrolling the full grid.

## Updates

- **Search works with the tech filter:** Search combines with the existing tech filter. Pick a technology and type a query to narrow results by both.
- **Empty state for no matches:** When no project matches your search and filter, the page shows a "No projects match your search." message instead of an empty grid.

</Update>
