<Update label="August 11, 2026">

## New features

- **Search and filter projects.** The [projects page](/projects) now lets you search by project name, tagline, or description and filter by technology. Combine both options to find relevant work faster. If nothing matches, you see a clear empty state.

- **Project status badges.** Each project card now shows an **Active** or **Archived** badge. You can tell at a glance which projects are still maintained. See the [projects page guide](/projects#entry-schema) for details.

</Update>
