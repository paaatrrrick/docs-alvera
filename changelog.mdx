<Update label="September 23, 2026" description="Week of September 21" tags={["New features", "Updates"]}>
  ## New features

  - **Projects page:** The new `/projects` page shows side projects in a responsive grid. Each card shows the name, a tagline, a description, tech tags, and a link to the repository or live site. See [Projects page](/projects).
  - **Status badges:** Each project card now shows an **Active** or **Archived** badge. You can tell at a glance which projects are still maintained. Active badges are green and archived badges are gray. See [Entry schema](/projects#entry-schema).

  ## Updates

  - **Tech filter:** Filter the project grid by technology using the buttons above the cards.
  - **Project search:** Search projects by name, tagline, or description. Search works together with the tech filter. If nothing matches, the page tells you so. See [Writing guidance](/projects#writing-guidance).
</Update>
