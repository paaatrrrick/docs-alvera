<Update label="September 8, 2026" description="Projects showcase">

## New features

### Projects showcase page

The site has a new `/projects` page that lists every side project in a responsive card grid. Each card shows the project name, a one-line tagline, a longer description, tech stack tags, and a link to the repository or live site. Visitors can now browse the full project catalog without scrolling the home page.

See [Projects page: structure and updates](/projects) for the entry schema and writing guidance.

### Project search

The `/projects` page now has a search box. It matches against each project's name, tagline, and description, and works together with the tech filter. If nothing matches, the page shows a "No projects match your search" message so visitors know the search worked.

## Updates

### Status badges on project cards

Each project card now shows a status badge in its header. **Active** (green) marks projects that are still maintained. **Archived** (gray) marks projects that no longer receive updates. Visitors can tell at a glance which projects are current before clicking through.

### Filter projects by tech stack

Filter buttons above the grid let visitors narrow the list to projects built with a specific technology. Selecting **All** restores the full list.
