<Update label="November 10, 2026" description="Week of November 9" tags={["New features"]}>
  ## New features

  - **Search guestbook entries:** The guestbook now has a **Search entries** field that filters the entries on the current page by name or message, ignoring case. While a search is active, the entry count shows how many match, such as **1 of 3 entries**. Learn more in [Guestbook](/guestbook).
</Update>

<Update label="October 10, 2026" description="Week of October 5" tags={["New features"]}>
  ## New features

  - **Source code links on project cards:** Project entries now accept an optional `repo` URL. When you set it, the card shows a **Source code** link next to the tech list, so visitors can jump straight to the repository even when the card heading points to a live site. Learn more in [Projects](/projects).
</Update>
