<Update label="June 24, 2026" description="Projects showcase and FAQ">

## New features

### Projects showcase page

The site has a new `/projects` page that displays every side project in a responsive grid. Each card shows the project name, a one-line tagline, a longer description, tech stack tags, and a link to the repository or live site. Visitors can browse the full catalog without scrolling the home page.

Learn how the page is structured in the [projects page guide](/projects).

### FAQ page

A new FAQ page answers the most common visitor questions in one place.

## Updates

### Search on the projects page

A search box on `/projects` filters projects by name, tagline, or description. Search combines with the tech filter, and an empty state appears when nothing matches.

### Tech stack filter

Filter buttons on `/projects` let visitors narrow the grid to a single technology. The buttons are derived from each project's tech tags.

### Project status badges

Each project card now shows an Active or Archived badge, so visitors can tell at a glance which projects are still maintained. See the [entry schema](/projects#entry-schema) for how status is set.

</Update>
