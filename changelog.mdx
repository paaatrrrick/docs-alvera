<Update label="October 22, 2026" description="Week of October 19" tags={["New features"]}>
  ## New features

  - **Talk recording embeds (preview):** Talks can now embed a recording from YouTube or Vimeo. YouTube videos load from the privacy-enhanced `youtube-nocookie.com` domain. Vimeo videos load with do-not-track enabled (`dnt=1`). Set an optional `start` value in seconds to begin playback at a timestamp. Any other provider throws an `Unsupported video provider` error. This feature is behind the `REACT_APP_TALK_VIDEOS=on` flag until it launches on November 3, 2026.
</Update>

<Update label="October 10, 2026" description="Week of October 5" tags={["New features"]}>
  ## New features

  - **Source code links on project cards:** Project entries now accept an optional `repo` URL. When you set it, the card shows a **Source code** link next to the tech list, so visitors can jump straight to the repository even when the card heading points to a live site. Learn more in [Projects](/projects).
</Update>
