<Update label="September 8, 2026" description="Projects page improvements">

## New features

### Search on the projects page

You can now search projects by name, tagline, or description on the projects page. Search works together with the tech stack filter, so you can narrow results by both keyword and technology. If nothing matches, the page shows an empty state instead of a blank grid.

Learn more about how the page is organized in the [projects page guide](/projects).

### Status badges on project cards

Each project card now shows an **Active** or **Archived** badge. You can tell at a glance which projects are still maintained and which are retired.

For badge conventions used across these docs, see [status badges](/status-badges).
