## New features

### Search on the projects page

The `/projects` page now includes a search box above the project grid.

- Type to filter projects by name, tagline, or description as you type.
- Search combines with the existing tech filter, so you can narrow by stack and keyword at the same time.
- If nothing matches, the page shows an empty state instead of a blank grid.

See [Projects page: structure and updates](/projects) for tips on writing project entries that surface well in search.
