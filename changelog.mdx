<Update label="August 27, 2026" description="Week of August 24">

## New features

### Search on the projects page

The [/projects showcase page](/projects) now includes a search box. Type a query to filter projects by name, tagline, or description as you type.

- Search combines with the existing tech filter, so you can narrow to a stack like React and then search within it.
- If nothing matches, the page shows an empty state instead of a blank grid.

This makes it faster to find a specific project as the catalog grows. See [Projects page: structure and updates](/projects) for how project entries are configured.
