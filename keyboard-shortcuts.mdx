Keyboard shortcuts let you move through the documentation without leaving the keyboard. Use them to open search, jump to the home page, and step through results in a single keystroke. Every shortcut on this page works from any page in the docs, so you can commit them to muscle memory once and rely on them everywhere.

## Shortcuts

- Press `/` to focus the search bar.
- Press `g` then `h` to go to the home page.
- Use the arrow keys to move between search results.
- Press `Esc` to close search.
