This page lists the issues that come up a lot and how to resolve them.

## Build fails

If your build is failing, there is usually an obvious reason. First, check the logs. Most of the time, a dependency was not installed correctly.

Try the following, in order:

1. Delete `node_modules` and run the install again.
2. Make sure your Node version matches what the [setup guide](/setup-guide) requires.
3. Read the build logs for more detail.

## Preview not loading

When the preview doesn't load, it's often a port conflict. Try starting the preview on a different port.

For anything else, open an issue on our tracker and we will look into it.
