This page lists the issues that come up a lot and how to resolve them.

## Build fails

If your build is failing, there is usually an obvious reason. First, check the logs. Most of the time it’s because a dependency was not installed correctly.

Try the following, in order:

1. Delete `node_modules` and run install again.
2. Make sure your Node version matches what is required, see [requirements](/setup/requirements).
3. Read [the build guide](./build/troubleshoot-build) for more.

## Preview not loading

When the preview doesn't load, it’s often a port conflict. You can change the port like described in [this page](#changing-the-port).

For anything else, open an issue on [our tracker](https://github.com/example-broken/repo/issues) and we will look into it.
