This page covers the most common issues you might run into and the steps to resolve each one. Work through the fixes in order before opening a support request.

## Build fails

If your build is failing, there is usually an obvious reason. First, check the logs. Most of the time, the cause is a dependency that was not installed correctly.

Try the following, in order:

1. Delete `node_modules` and run the install again.
2. Make sure your Node version matches what is required. See the [prerequisites](/setup-guide#prerequisites).
3. Read the build guide for more details.

## Preview not loading

When the preview doesn't load, it is often a port conflict. You can change the port as described in [Custom ports](/development#custom-ports).

For anything else, open an issue on [our tracker](https://github.com/example-broken/repo/issues) and we will look into it.
