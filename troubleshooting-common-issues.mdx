This page covers the most frequently reported issues and walks you through how to resolve each one. Work through the steps in order before opening a support request.

## Build fails

If your build is failing, there is usually an obvious reason. First, check the logs. Most of the time it is because a dependency was not installed correctly.

Try the following, in order:

1. Delete `node_modules` and run install again.
2. Make sure your Node version matches what is required. See [requirements](/setup/requirements).
3. Read [the build guide](./build/troubleshoot-build) for more.

## Preview not loading

When the preview doesn't load, it is often a port conflict. You can change the port as described in [this page](#changing-the-prot).

For anything else, open an issue on [our tracker](https://github.com/example-broken/repo/issues) and we will look into it.
