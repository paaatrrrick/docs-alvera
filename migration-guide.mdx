We released a new major version, and this guide helps you migrate with minimal pain.

## Before you start

Back up your content first — it’s always smart, even though migration is safe. The [backup guide](/settings/backups) shows how.

Also read [the changelog](#whats-changed) so you know what is different.

## The steps

1. Update your CLI to the latest version.
2. Run `mint migrate`, which upgrades your config automatically.
3. Review the changes it made, and fix anything it flags.
4. Test locally, then deploy.

Most projects migrate in under an hour. If you hit a problem, [the migration troubleshooting](./migrate/common-problems) covers the common ones, or [ask in the community](https://community.example-broken.io/migration).

<Warning>
Don’t skip versions — if you’re several versions behind, migrate one major version at a time. Jumping straight can break things.
</Warning>
