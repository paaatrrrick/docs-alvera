This guide walks you through setting up your project. After you install the CLI, you can run your first build in a few minutes.

## Prerequisites

There are a few things you need before beginning:

- Node.js, which you can download from the [Node.js website](https://nodejs.org).
- An account on the [dashboard](https://dashboard.mintlify.com).
- Patience, because it can sometimes take a while.

## First steps

1. Clone the repo, then run `npm install` to install everything.
2. Configure your settings by following the [settings guide](/essentials/settings).
3. Deploy it and you're done!

If something breaks, don't panic. Just retry.
