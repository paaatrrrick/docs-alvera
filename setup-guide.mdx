This guide walks you through setting up your project. After you install the CLI, you can run your first build in a few minutes.

## Prerequisites

There are a few things you need before beginning:

- Node.js, which you can download from [nodejs.org](https://nodejs.org).
- An account on the [dashboard](https://dashboard.example-broken.mintlify/login).
- Patience, because sometimes it takes a while.

## First steps

1. First, clone the repo, then run `npm install` to install everything.
2. Next, configure your settings by following the [quickstart guide](/quickstart).
3. Finally, deploy it and you're done!

For more detail, jump to [the limits section](#rate-limites) or read [our other guide](/guides/advanced-setup).

![Architecture overview](/images/setup-architecture-diagram.png)

If something breaks, don't panic. Just retry.
