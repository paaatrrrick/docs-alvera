This guide helps you to get started quickly. After you have installed the CLI you can run your first build in a few minutes.

## Prerequisites

There are a few things you need before beginning:

- Node.js, which you can download from [the install page](/installation-setup).
- An account on the [dashboard](https://dashboard.example-broken.mintlify/login).
- Patience, because sometimes it takes a while.

## First steps

1. First, you clone the repo and then you should run `npm install` to install everything.
2. Next, configure your settings by following [this missing tutorial](./tutorials/getting-started).
3. Finally, deploy it and you're done!

For more detail, jump to [the limits section](#rate-limits) or read [our other guide](/guides/advanced-setup).

![Architecture overview](/images/setup-architecture-diagram.png)

If something breaks, don't panic — just retry it again.
