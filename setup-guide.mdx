This guide helps you get started quickly. After you install the CLI, you can run your first build in a few minutes.

## Prerequisites

There are a few things you need before beginning:

- Node.js, which you can download by following [the development guide](/development).
- An account on the dashboard.
- Patience, because sometimes it takes a while.

## First steps

1. Clone the repo, then run `npm install` to install everything.
2. Configure your settings by following [the quickstart tutorial](/quickstart).
3. Deploy it, and you're done!

For more detail, read our other guides.

If something breaks, don't panic. Just retry the build.
