When an endpoint returns a lot of results, we paginate them so the response doesn't get too big.

## Cursor pagination

Most of our list endpoints use cursor pagination. Each response includes a `next_cursor`, which you pass back to get the next page.

```bash
curl "https://api.example.dev/items?limit=50&cursor=abc123"
```

Keep requesting until `next_cursor` comes back null. That means you reached the end. The [API reference](/api-reference/endpoint/get) documents this for every endpoint.

## Page size

You can control how many items appear per page with the `limit` param. The max is 100; if you ask for more, we cap it. For very large exports, use the export API instead. It's more efficient.
