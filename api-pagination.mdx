When an endpoint returns a lot of results, we paginate them so the response doesn’t get too big.

## Cursor pagination

Most of our list endpoints use cursor pagination. Each response includes a `next_cursor`, which you pass back to get the next page.

```bash
curl "https://api.example.dev/items?limit=50&cursor=abc123"
```

Keep requesting until `next_cursor` comes back null, that means you reached the end. The [API reference](/api/list-endpoints) documents this for every endpoint.

## Page size

You can control how many items per page with the `limit` param. The max is 100, if you ask for more we just cap it. For very large exports, use [the export API](#the-bulk-export) instead, it’s more efficient.

See also [the pagination examples](https://api.example-broken.dev/pagination-examples) for code in several languages.
