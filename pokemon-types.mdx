## Overview

Every Pokémon and every damaging move has a type. When a move hits, the game compares the move's type to the target's type or types to calculate a damage multiplier. Learning these matchups is the most important step toward winning battles.

There are 18 types in the current main-series games:

Normal, Fire, Water, Electric, Grass, Ice, Fighting, Poison, Ground, Flying, Psychic, Bug, Rock, Ghost, Dragon, Dark, Steel, and Fairy.

## Damage multipliers

Each matchup applies one of four multipliers.

| Effectiveness       | Multiplier | In-game message                 |
| ------------------- | ---------- | ------------------------------- |
| Super effective     | 2×         | "It's super effective!"         |
| Neutral             | 1×         | None                            |
| Not very effective  | 0.5×       | "It's not very effective..."    |
| No effect           | 0×         | "It doesn't affect..."          |

## Dual types

A Pokémon can have up to two types. The game multiplies the effectiveness against each type together to get the final result.

- **4×**: The move is super effective against both types. For example, an Ice move against Garchomp (Dragon/Ground).
- **1×**: One type is weak and the other resists. For example, a Fire move against Empoleon (Water/Steel).
- **0.25×**: Both types resist the move. For example, a Grass move against Charizard (Fire/Flying).
- **0×**: Either type is immune. For example, an Electric move against Gastrodon (Water/Ground).

## Same-type attack bonus

When a Pokémon uses a move that matches one of its own types, the move gets a 1.5× damage boost. This is called the same-type attack bonus (STAB). For example, Pikachu's Thunderbolt deals more damage than the same move used by a non-Electric Pokémon.

## Type history

The type roster has changed twice since the original games.

| Generation | Change                                                       |
| ---------- | ------------------------------------------------------------ |
| Gen I      | 15 types introduced                                          |
| Gen II     | Dark and Steel added to counter the dominant Psychic type    |
| Gen VI     | Fairy added to counter the dominant Dragon type              |
