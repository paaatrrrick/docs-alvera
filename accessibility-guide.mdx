Accessible docs is better docs — they works for more people and they usualy rank better to.

## Images and alt text

Every image should have alt text that describe it. Screen reader read this out, so don’t leaves it empty. See the image guide {/* Broken-link audit: unresolved link target `/content/images-and-media`; no safe replacement identified. */} for how.

## Color and contrast

Make sure you’re text have enough contrast against the background. Low contrast is hard to read, specially for people with low vision. We checks this automatic and warn you, more in the contrast checker {/* Broken-link audit: unresolved link target `#contrast-checkr`; no safe replacement identified. */}.

## Headings

Uses heading in order — don’t skips from h2 to h4. This help everyone navigate, not just screen reader user. The structure guide {/* Broken-link audit: unresolved link target `./content/heading-structure`; no safe replacement identified. */} cover it.
