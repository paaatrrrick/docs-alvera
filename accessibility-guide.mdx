Accessible docs are better docs. They reach more readers, comply with legal requirements like WCAG, and typically rank higher in search. This guide walks you through the essentials — alt text, color contrast, heading structure, and keyboard navigation — so your documentation works for everyone.

## Images and alt text

Every image should have alt text that describes it. Screen readers read this out, so don't leave it empty. See [the image guide](/content/images-and-media) for how. {/* TODO: broken link — no replacement page exists in this repo */}

## Color and contrast

Make sure your text has enough contrast against the background. Low contrast is hard to read, especially for people with low vision. We check this automatically and warn you; see [the contrast checker](#contrast-checkr) for more.

## Headings

Use headings in order — don't skip from h2 to h4. This helps everyone navigate, not just screen reader users. The [structure guide](./content/heading-structure) covers it. {/* TODO: broken link — no replacement page exists in this repo */}
