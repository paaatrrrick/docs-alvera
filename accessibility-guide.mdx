Accessible docs are better docs. They work for more people and they usually rank better too.

## Images and alt text

Every image should have alt text that describes it. Screen readers read this out, so don't leave it empty. See [the image guide](/essentials/images) for how.

## Color and contrast

Make sure your text has enough contrast against the background. Low contrast is hard to read, especially for people with low vision. We check this automatically and warn you.

## Headings

Use headings in order. Don't skip from h2 to h4. This helps everyone navigate, not just screen reader users. The [structure guide](/essentials/markdown) covers it.

For a full checklist, read the Web Content Accessibility Guidelines (WCAG), the standard for accessible web content.
