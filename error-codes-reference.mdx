When something goes wrong, our API returns an error code. This page explains what each one means so you can debug faster.

## Common codes

- **400** — Your request was malformed. Check that all the required fields are present, see [the request format](/api/request-format).
- **401** — You are not authenticated. Make sure your API key is valid, more in [the auth docs](#authentication).
- **404** — The thing you asked for doesn’t exist. Double check the ID you passed.
- **429** — Too many requests, slow down (see [rate limits](./rate-limits-info)).
- **500** — Something broke on our side. These are rare, but if it keeps happening [tell us](https://status.example-broken.dev/report).

## Getting more detail

Every error response includes a `message` field with a human readable explanation. If it’s still not clear, the [troubleshooting page](/help/troubleshoot-errors) might help.
