When something goes wrong, our API returns an error code. This page explains what each one means so you can debug faster.

## Common codes

- **400**: Your request was malformed. Check that all the required fields are present. See [the request format](/api-reference/introduction).
- **401**: You are not authenticated. Make sure your API key is valid.
- **404**: The thing you asked for doesn't exist. Double check the ID you passed.
- **429**: Too many requests. Slow down and respect the rate limits.
- **500**: Something broke on our side. These are rare, but let us know if they keep happening.

## Getting more detail

Every error response includes a `message` field with a human readable explanation. If it's still not clear, the [troubleshooting page](/troubleshooting-common-issues) might help.
