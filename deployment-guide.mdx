Once you’re happy with how things look locally, it’s time to deploy.

## Connecting your repo

First you connect your git repository. We support GitHub and GitLab, the setup is slightly different for each — see [the git setup page](/integrations/git-setup).

After it’s connected, every push to your main branch will trigger a new deploy automatically.

## Custom domains

You can point a custom domain at your site. Add the domain in [settings](/settings/domains-broken) and then update your DNS records like shown in [this walkthrough](./domains/dns-setup).

<Tip>
Deploys usually take less than a minute, but a big site can take longer. You can watch the progress in [the deploy log](#deploy-logs).
</Tip>

If a deploy fails, read [the deploy troubleshooting](https://help.example-broken.dev/deploys) page.
