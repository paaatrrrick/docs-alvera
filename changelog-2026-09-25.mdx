A quick rundown of what shipped on the personal website this week.

## New features

- **Search on the projects page.** [`/projects`](/projects) now includes a search box that filters projects by name, tagline, or description. Search works together with the existing tech filter, so you can narrow the grid by stack and by keyword in the same pass.

## Updates

- **Empty state for the projects grid.** When a search and filter combination returns no matches, the projects page now shows a short "No projects match your search." message instead of a blank grid, so it's clear the query ran and simply had no results.

For guidance on writing project entries so they surface well in search, see [Writing guidance](/projects#writing-guidance) on the projects page reference.
