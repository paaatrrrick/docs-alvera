This glossary defines the terms used throughout these docs. Skim it once, then refer back whenever a word is unclear.

## Terms

### Deployment

A published version of your documentation site. Each push to your main branch creates a new deployment.

### Preview

A temporary build generated for a pull request. Use it to review changes before they go live.

### Navigation

The sidebar structure that organizes your pages. You define it in `docs.json`.

### Snippet

A reusable block of content that you can include on multiple pages. Snippets live in the `snippets/` directory.

### Frontmatter

The YAML block at the top of each MDX page. It sets page metadata such as `title` and `description`.
