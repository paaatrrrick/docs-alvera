This glossary defines the terms used most often across these docs. Skim it once, then refer back whenever a word is unclear.

## Terms

**Deployment**
A published version of your documentation site. Each push to your main branch creates a new deployment.

**Preview**
A temporary build generated for a pull request. Use it to review changes before they go live.

**Navigation**
The sidebar structure that organizes your pages. You define it in `docs.json`. See [navigation](/essentials/navigation).

**Snippet**
A reusable block of content that you can include on multiple pages. See [reusable snippets](/essentials/reusable-snippets).

**Webhook**
An HTTP callback that sends an event payload to a URL you configure. See the [webhooks overview](/webhooks-overview).

If you are just getting started, read the [quickstart](/quickstart) first, then set up your environment with the [local development guide](/development).
