This glossary defines five common terms used throughout these docs. Skim it once, then refer back whenever a word is unclear.

## Terms

- **Deployment** — A published version of your site. Each push to your main branch creates a new deployment that your readers can access.
- **Preview** — A temporary build of a pull request, so you can review changes in an isolated environment before they go live.
- **Navigation** — The sidebar structure that organizes your pages into groups and tabs, defined in `docs.json`.
- **Snippet** — A reusable block of MDX content, stored under `snippets/`, that you can include on multiple pages to keep information in sync.
- **Frontmatter** — The YAML block at the top of every MDX file that sets page metadata such as `title`, `description`, and sidebar behavior.

If you are just getting started, read the [quickstart](/quickstart) first, then set up your environment with the [local development guide](/development).
