This glossary defines five terms you'll encounter most often across these docs. Skim it once, then refer back whenever a word is unclear.

## Terms

- **Deployment** — A published version of your documentation site. Each push to your production branch produces a new deployment. See [how Mintlify works](/how-mintlify-works) for the full build-and-publish flow.
- **Preview** — A temporary, per-pull-request build of your site that lets you review changes before merging. Previews use the same navigation and theme as your production deployment.
- **Navigation** — The sidebar and tab structure that organizes your pages, defined under the `navigation` key in [`docs.json`](/essentials/navigation). Groups, pages, and tabs are all configured here.
- **Snippet** — A reusable block of MDX content, stored in `snippets/`, that you can import into multiple pages to keep shared content in sync. See [reusable snippets](/essentials/reusable-snippets).
- **Frontmatter** — The YAML block at the top of every MDX page (between `---` markers) that sets page metadata such as `title` and `description`. Mintlify uses these fields to render page headers and search results.

If you are just getting started, read the [quickstart](/quickstart) first, then set up your environment with the [development guide](/development).
