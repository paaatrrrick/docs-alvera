This glossary defines terms you will encounter most often while writing, configuring, and publishing your documentation site.

## Terms

- **Deployment** — A published version of your site. Each push to your deploy branch creates a new deployment.
- **Preview** — A temporary build of a pull request so you can review changes before they go live.
- **Navigation** — The sidebar structure that organizes your pages, defined in `docs.json`.
- **Snippet** — A reusable block of content stored in `snippets/` that you can include on multiple pages.
- **Frontmatter** — The YAML block at the top of an MDX file that sets page metadata such as `title` and `description`.

If you are just getting started, read the [quickstart](/quickstart), then set up your environment with the [local development guide](/development).
