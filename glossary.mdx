This glossary defines the terms used throughout these docs. Skim it once, then refer back whenever a word is unclear.

## Deployment

A published version of your site. Each push to your main branch creates a new deployment.

## Preview

A temporary build of a pull request. Use it to review changes before they go live.

## Navigation

The sidebar structure that organizes your pages. You define it in the `navigation` property of `docs.json`.

## Snippet

A reusable block of content stored in the `snippets/` directory. You can include a snippet on multiple pages to avoid duplicating content.

## Frontmatter

The YAML block at the top of each MDX page, delimited by `---`. It sets page metadata such as `title` and `description`.
