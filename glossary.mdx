This glossary defines terms used throughout these docs. Refer back to it whenever a word is unclear.

## Terms

- **Deployment**: A published version of your site. Mintlify creates a new deployment each time you merge to your deploy branch. See [How Mintlify works](/how-mintlify-works).
- **MDX**: The file format for every page. MDX is Markdown plus React components like `<Card>`, `<Tabs>`, and `<Accordion>`. Each MDX file starts with YAML frontmatter such as `title` and `description`. See [Markdown syntax](/essentials/markdown).
- **Navigation**: The sidebar structure that organizes your pages into tabs and groups. You define it in the `navigation` field of `docs.json`. See [Navigation](/essentials/navigation).
- **Preview**: A temporary build of a pull request. Use it to review changes before they go live. To preview locally, run `mint dev`.
- **Snippet**: A reusable block of content stored in the `snippets/` directory. You can import a snippet into any page. See [Reusable snippets](/essentials/reusable-snippets).

If you are just getting started, read the [quickstart](/quickstart) first. Then set up your environment with the [local development guide](/development).
