## Repository summaries

Each of the following repositories is available as a read-only reference for this docs deployment.

- **[alfoods-and-patrick](https://github.com/paaatrrrick/alfoods-and-patrick)** — A Next.js starter project bootstrapped with `create-next-app` and configured with the Geist font from `next/font`.
- **[boilerplate](https://github.com/paaatrrrick/boilerplate)** — A full-stack Next.js, TypeScript, Node/Express, MongoDB, and TailwindCSS boilerplate with Firebase auth, navbars, error handling, and loading screens preconfigured.
- **[chemistryresearch](https://github.com/paaatrrrick/chemistryresearch)** — A static web app that visualizes an instructor facilitation coding scheme, deployed at facilitation-visualization.netlify.app.
- **[conductor-playground](https://github.com/paaatrrrick/conductor-playground)** — An empty scratch repository used for experimentation with Conductor.
- **[brain-test](https://github.com/paaatrrrick/brain-test)** — A Mintlify-based "company brain" template that models a mid-sized startup's onboarding, direction, teams, people, and resources as Markdown files an AI agent keeps current.
- **[docs](https://github.com/paaatrrrick/docs)** — A copy of the Mintlify starter kit with example guide pages, navigation, customizations, API reference, and popular components.
- **[docs-dre](https://github.com/paaatrrrick/docs-dre)** — Another Mintlify starter kit fork that additionally documents AI-assisted writing workflows via the `npx skills add` command.
- **[docs-franny](https://github.com/paaatrrrick/docs-franny)** — A minimal Mintlify starter kit with just `index.mdx`, `quickstart.mdx`, and `docs.json`.
- **[docs-monorepo](https://github.com/paaatrrrick/docs-monorepo)** — A monorepo layout that nests a full Mintlify starter kit inside a `docs/` subdirectory alongside `misc/` content.
- **[docs-starter](https://github.com/paaatrrrick/docs-starter)** — A personal portfolio-style Mintlify site ("Patrick Foster") with English, Spanish, and French translations of pages like experience, projects, and uses.
- **[efficieny-bench-spring-boot](https://github.com/paaatrrrick/efficieny-bench-spring-boot)** — A fork of the Spring Boot source tree used to build production-grade, Spring-powered Java applications and services.
- **[learning_flask](https://github.com/paaatrrrick/learning_flask)** — A pair-programming Flask exercise that predicts a user's salary with a machine learning model served through a small web app.
- **[pantern](https://github.com/paaatrrrick/pantern)** — A client/server project exploring how backend developers build frontends.
- **[patfoster-hw6](https://github.com/paaatrrrick/patfoster-hw6)** — A static HTML/CSS site submitted as homework 6 for the BAIS3300 course.
- **[radah](https://github.com/paaatrrrick/radah)** — A multi-part project for radah.ai combining a Swift macOS client that launches local VMs, a VM UI and agent, and a web server (Windows client not yet started).
- **[salary_prediction_model](https://github.com/paaatrrrick/salary_prediction_model)** — A Jupyter notebook that trains a machine-learning model on the 2022 Kaggle Survey to predict individual salary from seven features.
- **[test-repo](https://github.com/paaatrrrick/test-repo)** — A throwaway repository containing a single `text.txt` file, used purely for testing.
- **[voodootrade](https://github.com/paaatrrrick/voodootrade)** — An empty placeholder repository with no content yet committed.
- **[vtrade](https://github.com/paaatrrrick/vtrade)** — A TypeScript Next.js project bootstrapped with `create-next-app` and set up with the Geist font.
- **[wordsmith-api](https://github.com/paaatrrrick/wordsmith-api)** — The Express, Node.js, and MongoDB backend for Wordsmith, a GPT-powered Chrome extension that rewrites highlighted text in different tones.
- **[wordsmith-client](https://github.com/paaatrrrick/wordsmith-client)** — The Chrome extension and React web frontend for Wordsmith, letting users highlight text on any page and get AI-rewritten alternatives.
- **[yogi-tea](https://github.com/paaatrrrick/yogi-tea)** — A collection of Python notebooks, datasets, and machine-learning models built to help Yogi Tea analyze price elasticity, promotional lift, and unit sales forecasts.
