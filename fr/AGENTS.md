# Instructions pour le projet de documentation

## À propos de ce projet

- Il s’agit d’un site de documentation construit avec [Mintlify](https://mintlify.com)
- Les pages sont des fichiers MDX avec un frontmatter YAML
- La configuration se trouve dans `docs.json`
- Exécutez `mint dev` pour prévisualiser localement
- Exécutez `mint broken-links` pour vérifier les liens
