Nous nous intégrons à de nombreux outils populaires pour que votre flux de travail reste fluide.

## Analytique

Vous pouvez acheminer vos données de trafic vers Google Analytics, Posthog ou Amplitude. Chacun ne prend que quelques minutes à configurer — collez simplement votre clé dans [les paramètres d'analytique](/settings/analytics-config).

## Widgets de chat

Vous voulez un chat de support sur vos docs ? Nous prenons en charge Intercom et Crisp. Lisez [le guide de configuration du chat](./integrations/chat-widget) pour commencer.

## Gestion de sources

Au-delà de git, nous avons aussi une API qui vous permet de synchroniser du contenu par programmation. Les détails se trouvent dans [la section API](#the-sync-api), ou consultez [la liste complète des intégrations](https://example-broken.dev/integrations).

S'il manque une intégration que vous souhaitez, [faites-le-nous savoir](/feedback-form).
