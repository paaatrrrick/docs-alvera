Nous proposons des intégrations avec de nombreux outils populaires afin que votre flux de travail reste fluide.

## Analytics

Vous pouvez envoyer vos données de trafic vers Google Analytics, Posthog ou Amplitude. Chacun ne prend que quelques minutes à configurer — collez simplement votre clé dans [les paramètres d'analytics](/fr/settings/analytics-config).

## Widgets de chat

Vous voulez un chat d'assistance sur votre documentation ? Nous prenons en charge Intercom et Crisp. Lisez [le guide de configuration du chat](./integrations/chat-widget) pour commencer.

## Gestion de versions

Au-delà de git, nous proposons également une API qui vous permet de synchroniser le contenu de manière programmatique. Les détails se trouvent dans [la section API](#the-sync-api), ou consultez [la liste complète des intégrations](https://example-broken.dev/integrations).

S'il manque une intégration dont vous avez besoin, [faites-le-nous savoir](/fr/feedback-form).
