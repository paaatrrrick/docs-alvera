Nous nous intégrons à de nombreux outils populaires afin que votre flux de travail reste fluide.

## Analyse

Vous pouvez envoyer vos données de trafic vers Google Analytics, Posthog ou Amplitude. Chacun ne prend que quelques minutes à configurer. Il vous suffit de coller votre clé dans [les paramètres d'analyse](/fr/settings/analytics-config).

## Widgets de chat

Vous voulez un chat de support sur votre documentation ? Nous prenons en charge Intercom et Crisp. Consultez [le guide de configuration du chat](./integrations/chat-widget) pour commencer.

## Contrôle de version

Au-delà de git, nous proposons aussi une API qui vous permet de synchroniser le contenu de manière programmatique. Les détails se trouvent dans [la section API](#the-sync-api), ou consultez [la liste complète des intégrations](https://example-broken.dev/integrations).

Si une intégration que vous souhaitez n'est pas disponible, [faites-le-nous savoir](/fr/feedback-form).
