Nous nous intégrons à de nombreux outils populaires afin que votre flux de travail reste fluide.

## Analytique

Vous pouvez envoyer vos données de trafic vers Google Analytics, Posthog ou Amplitude. Chacun ne prend que quelques minutes à configurer. Il suffit de coller votre clé dans [les paramètres analytiques](/fr/settings/analytics-config).

## Widgets de chat

Vous voulez un chat de support sur votre documentation ? Nous prenons en charge Intercom et Crisp. Lisez [le guide de configuration du chat](./integrations/chat-widget) pour commencer.

## Contrôle de source

Au-delà de git, nous avons aussi une API qui vous permet de synchroniser du contenu par programmation. Les détails se trouvent dans [la section API](#the-sync-api), ou consultez [la liste complète des intégrations](https://example-broken.dev/integrations).

Si une intégration que vous souhaitez est manquante, [faites-le nous savoir](/fr/feedback-form).
