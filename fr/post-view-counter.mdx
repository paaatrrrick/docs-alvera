## Présentation

Le site personnel fournit un petit ensemble de composants et de hooks pour suivre et afficher le nombre de lectures des articles :

- **`ViewCounter`** — affiche le nombre de lectures d'un article, en s'appuyant sur le hook `useViewCount`.
- **`SiteViews`** — affiche le nombre total de lectures de tous les articles, en s'appuyant sur le hook `useTotalViews`.
- **`PostMeta`** — la ligne de métadonnées combinée affichée sous le titre d'un article (date, temps de lecture estimé, nombre de vues).

Ces trois éléments communiquent avec un service de vues partagé à l'adresse `https://api.paaatrrrick.com/views`. Le service renvoie des données tolérantes à `null`, de sorte que chaque composant n'affiche rien tant que l'appel réseau est en cours ou si la requête échoue.

## Quand utiliser chaque élément

| Composant / hook         | À utiliser lorsque…                                                                       |
| ------------------------ | ------------------------------------------------------------------------------- |
| `ViewCounter` / `useViewCount` | Vous voulez le nombre de lectures d'un seul article et souhaitez que la visite soit enregistrée.    |
| `SiteViews` / `useTotalViews`  | Vous voulez le nombre total de lectures sur l'ensemble du site (par ex. pied de page, page « À propos »). |
| `PostMeta`               | Vous affichez un modèle d'article et voulez la ligne standard date · temps de lecture · vues. |

## Ajouter la ligne de métadonnées à un modèle d'article

`PostMeta` est la méthode recommandée pour afficher le nombre de vues d'un article. Il regroupe la date, le temps de lecture et le compteur de vues sur une seule ligne, afin que chaque modèle n'ait pas à câbler lui-même chacun de ces éléments.

```jsx
import PostMeta from "../components/PostMeta";

export default function PostTemplate({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <PostMeta post={post} />
      {/* …post body… */}
    </article>
  );
}
```

`PostMeta` s'attend à ce que l'objet article fournisse :

| Champ   | Type              | Remarques                                                                 |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `id`    | string            | Utilisé comme clé du compteur de vues. Requis pour le suivi des vues.             |
| `date`  | string (facultatif) | Affiché tel quel lorsqu'il est présent. Omettez-le pour masquer la date.           |
| `body`  | string[] (facultatif) | Concaténé puis transmis à l'estimateur du temps de lecture.            |

Chaque segment se masque si ses données sont manquantes ou si l'appel réseau n'a pas encore abouti, de sorte que la ligne de métadonnées se dégrade proprement pour les articles sans date ou avant le chargement du nombre de vues.

## Afficher uniquement le nombre de vues

Si vous n'avez besoin que du nombre (par exemple sur une carte de liste d'articles), utilisez directement `ViewCounter` :

```jsx
import ViewCounter from "../components/ViewCounter";

<ViewCounter postId={post.id} />
```

Il affiche un `<span class="view-counter">` contenant le nombre formaté via `toLocaleString()` (ainsi `1234` s'affiche sous la forme `1,234 views`). Tant que la requête est en attente, il renvoie `null` et n'affiche rien.

### Lire sans enregistrer de vue

Par défaut, le montage de `ViewCounter` enregistre une vue. Si vous souhaitez lire le nombre sans l'incrémenter — par exemple sur un tableau de bord d'administration ou une page de liste — appelez directement `useViewCount` avec `increment: false` :

```jsx
import { useViewCount } from "../hooks/useViewCount";

function PostCard({ post }) {
  const count = useViewCount(post.id, { increment: false });
  return <li>{post.title} — {count?.toLocaleString() ?? "—"} views</li>;
}
```

## Afficher le total des vues du site

`SiteViews` affiche un résumé d'une ligne du nombre total de lectures de tous les articles. Placez-le où vous voulez afficher ce total — un pied de page, une page « À propos », un bandeau de statistiques sur la page d'accueil :

```jsx
import SiteViews from "../components/SiteViews";

<SiteViews />
```

Il affiche un `<p class="site-views">` avec un texte comme `12,480 total reads across all posts.`, ou rien tant que la requête est en cours.

## Endpoints d'API attendus par les hooks

Les hooks appellent un service de vues partagé. Si vous changez de backend, celui-ci doit exposer la même structure sur les mêmes chemins.

| Méthode | Endpoint                  | Utilisé par         | Comportement                                                                                   |
| ------ | ------------------------- | --------------- | ------------------------------------------------------------------------------------------ |
| `POST` | `/views/:postId`          | `useViewCount` (par défaut) | Enregistre une vue pour `postId` et renvoie le nouveau nombre.                              |
| `GET`  | `/views/:postId`          | `useViewCount` avec `{ increment: false }` | Renvoie le nombre actuel pour `postId` sans l'incrémenter.        |
| `GET`  | `/views/total`            | `useTotalViews` | Renvoie le nombre total de lectures de tous les articles.                                        |

Les corps de réponse ont les structures suivantes :

```json
// /views/:postId
{ "count": 1234 }

// /views/total
{ "total": 12480 }
```

Les deux hooks traitent les réponses autres que `200` et les données non numériques comme des données manquantes — ils conservent l'état à `null` afin que les composants n'affichent rien plutôt qu'un nombre erroné. L'URL de base est configurée dans les hooks sous la forme `https://api.paaatrrrick.com/views`.

## Style

`PostMeta` est fourni avec `postMeta.css`, qui dispose les segments sur une ligne flex avec de fins séparateurs en forme de point entre eux. Les classes que vous pouvez cibler sont :

- `.post-meta` — la ligne englobante.
- `.post-meta-date` — le segment de la date.
- `.view-counter` — le span du nombre de vues (également affiché seul par `ViewCounter`).
- `.site-views` — le paragraphe du total des vues affiché par `SiteViews`.
