## Aperçu

Le site web personnel est livré avec une petite suite de composants et de hooks pour suivre et afficher le nombre de fois qu'un article a été lu :

- **`ViewCounter`** — affiche le nombre de lectures d'un seul article, alimenté par le hook `useViewCount`.
- **`SiteViews`** — affiche le nombre total de lectures cumulées sur tous les articles, alimenté par le hook `useTotalViews`.
- **`PostMeta`** — la signature combinée affichée sous le titre d'un article (date, temps de lecture estimé, nombre de vues).

Les trois communiquent avec un service de vues partagé à l'adresse `https://api.paaatrrrick.com/views`. Le service renvoie des données sûres à l'égard des valeurs `null`, de sorte que chaque composant n'affiche rien pendant que l'appel réseau est en cours ou si la requête échoue.

## Quand utiliser chaque élément

| Composant / hook         | À utiliser lorsque…                                                                       |
| ------------------------ | ------------------------------------------------------------------------------- |
| `ViewCounter` / `useViewCount` | Vous voulez le nombre de lectures d'un seul article et vous voulez que la visite soit enregistrée.    |
| `SiteViews` / `useTotalViews`  | Vous voulez le nombre total de lectures sur l'ensemble du site (par ex. pied de page, page à propos). |
| `PostMeta`               | Vous affichez un modèle d'article et vous voulez la signature standard date · temps de lecture · vues. |

## Ajouter la signature à un modèle d'article

`PostMeta` est la manière recommandée de faire apparaître les compteurs de vues sur un article. Il regroupe la date, le temps de lecture et le compteur de vues en une seule ligne, de sorte que les modèles individuels n'ont pas besoin de câbler chaque élément eux-mêmes.

```jsx
import PostMeta from "../components/PostMeta";

export default function PostTemplate({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <PostMeta post={post} />
      {/* …post body… */}
    </article>
  );
}
```

`PostMeta` attend que l'objet post fournisse :

| Champ   | Type              | Notes                                                                 |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `id`    | string            | Utilisé comme clé du compteur de vues. Requis pour le suivi des vues.             |
| `date`  | string (optionnel) | Rendu tel quel lorsqu'il est présent. À omettre pour masquer le segment de date.           |
| `body`  | string[] (optionnel) | Combiné et transmis à l'estimateur de temps de lecture.            |

Chaque segment se masque si ses données sont manquantes ou si l'appel réseau n'a pas encore abouti, de sorte que la signature se dégrade proprement sur les articles sans date ou avant que le nombre de vues ne se charge.

## Afficher uniquement le nombre de vues

Si vous n'avez besoin que du nombre (par exemple, sur une carte de liste d'articles), utilisez `ViewCounter` directement :

```jsx
import ViewCounter from "../components/ViewCounter";

<ViewCounter postId={post.id} />
```

Il rend un `<span class="view-counter">` avec le nombre formaté via `toLocaleString()` (ainsi `1234` s'affiche comme `1,234 views`). Pendant que la requête est en attente, il renvoie `null` et n'affiche rien.

### Lire sans enregistrer une vue

Par défaut, le montage de `ViewCounter` enregistre une vue. Si vous souhaitez lire le nombre sans l'incrémenter, par exemple sur un tableau de bord d'administration ou une page de liste, appelez `useViewCount` directement avec `increment: false` :

```jsx
import { useViewCount } from "../hooks/useViewCount";

function PostCard({ post }) {
  const count = useViewCount(post.id, { increment: false });
  return <li>{post.title} — {count?.toLocaleString() ?? "—"} views</li>;
}
```

## Afficher le total des vues du site

`SiteViews` rend un résumé d'une ligne du total des lectures sur tous les articles. Placez-le partout où vous voulez le chiffre agrégé : un pied de page, une page à propos, une bande de statistiques sur la page d'accueil :

```jsx
import SiteViews from "../components/SiteViews";

<SiteViews />
```

Il rend un `<p class="site-views">` avec un texte comme `12,480 total reads across all posts.`, ou rien pendant que la requête est en cours.

## Points de terminaison API attendus par les hooks

Les hooks appellent un service de vues partagé. Si vous remplacez le backend, il doit exposer la même forme sur les mêmes chemins.

| Méthode | Point de terminaison                  | Utilisé par         | Comportement                                                                                   |
| ------ | ------------------------- | --------------- | ------------------------------------------------------------------------------------------ |
| `POST` | `/views/:postId`          | `useViewCount` (par défaut) | Enregistre une vue pour `postId` et renvoie le nouveau nombre.                              |
| `GET`  | `/views/:postId`          | `useViewCount` avec `{ increment: false }` | Renvoie le nombre actuel pour `postId` sans l'incrémenter.        |
| `GET`  | `/views/total`            | `useTotalViews` | Renvoie le nombre total de lectures sur tous les articles.                                        |

Les corps de réponse utilisent ces formes :

```json
// /views/:postId
{ "count": 1234 }

// /views/total
{ "total": 12480 }
```

Les deux hooks traitent les réponses non-`200` et les charges utiles non numériques comme des données manquantes. Ils maintiennent l'état à `null` afin que les composants n'affichent rien plutôt que d'afficher un nombre erroné. L'URL de base est configurée dans les hooks comme `https://api.paaatrrrick.com/views`.

## Style

`PostMeta` est livré avec `postMeta.css`, qui dispose les segments sous forme de ligne flex avec de fins séparateurs en points entre eux. Les classes individuelles que vous pouvez cibler sont :

- `.post-meta` — la ligne englobante.
- `.post-meta-date` — le segment de date.
- `.view-counter` — l'élément span du nombre de vues (également rendu par `ViewCounter` seul).
- `.site-views` — le paragraphe des vues totales rendu par `SiteViews`.
