## Vue d'ensemble {#overview}

Le site web personnel fournit un petit ensemble de composants et de hooks pour suivre et afficher le nombre de lectures des articles :

- **`ViewCounter`** : affiche le nombre de lectures d'un seul article, à l'aide du hook `useViewCount`.
- **`SiteViews`** : affiche le nombre total de lectures de tous les articles, à l'aide du hook `useTotalViews`.
- **`PostMeta`** : la ligne combinée affichée sous le titre d'un article (date, temps de lecture estimé, nombre de vues).

Les trois communiquent avec un service de vues partagé à l'adresse `https://api.paaatrrrick.com/views`. Le service renvoie des données sûres vis-à-vis de `null`, si bien que chaque composant n'affiche rien tant que l'appel réseau est en cours ou si la requête échoue.

## Quand utiliser chaque élément {#when-to-use-each-piece}

| Composant / hook         | À utiliser quand…                                                               |
| ------------------------ | ------------------------------------------------------------------------------- |
| `ViewCounter` / `useViewCount` | Vous voulez le nombre de lectures d'un seul article et vous voulez que la visite soit enregistrée. |
| `SiteViews` / `useTotalViews`  | Vous voulez le nombre total de lectures de tout le site (par exemple dans le pied de page ou la page « À propos »). |
| `PostMeta`               | Vous affichez un modèle d'article et voulez la ligne standard date · temps de lecture · vues. |

## Ajouter la ligne de métadonnées à un modèle d'article {#adding-the-byline-to-a-post-template}

`PostMeta` est la méthode recommandée pour afficher le nombre de vues sur un article. Il regroupe la date, le temps de lecture et le compteur de vues sur une seule ligne, afin que chaque modèle n'ait pas à brancher chaque élément lui-même.

```jsx
import PostMeta from "../components/PostMeta";

export default function PostTemplate({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <PostMeta post={post} />
      {/* …post body… */}
    </article>
  );
}
```

`PostMeta` attend que l'objet article fournisse :

| Champ   | Type              | Remarques                                                             |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `id`    | string            | Sert de clé au compteur de vues. Obligatoire pour le suivi des vues.  |
| `date`  | string (facultatif) | Affiché tel quel lorsqu'il est présent. Omettez-le pour masquer le segment de date. |
| `body`  | string[] (facultatif) | Concaténé puis transmis à l'estimateur de temps de lecture.       |

Chaque segment se masque si ses données sont absentes ou si l'appel réseau n'a pas encore abouti, ce qui permet à la ligne de se dégrader proprement sur les articles sans date ou avant le chargement du nombre de vues.

## Afficher uniquement le nombre de vues {#showing-just-the-view-count}

Si vous n'avez besoin que du nombre (par exemple sur une carte de liste d'articles), utilisez directement `ViewCounter` :

```jsx
import ViewCounter from "../components/ViewCounter";

<ViewCounter postId={post.id} />
```

Il affiche un `<span class="view-counter">` avec le nombre formaté par `toLocaleString()` (ainsi `1234` s'affiche `1,234 views`). Tant que la requête est en attente, il renvoie `null` et n'affiche rien.

### Lire sans enregistrer de vue {#reading-without-recording-a-view}

Par défaut, le montage de `ViewCounter` enregistre une vue. Si vous voulez lire le nombre sans l'incrémenter (par exemple sur un tableau de bord d'administration ou une page de liste), appelez directement `useViewCount` avec `increment: false` :

```jsx
import { useViewCount } from "../hooks/useViewCount";

function PostCard({ post }) {
  const count = useViewCount(post.id, { increment: false });
  return <li>{post.title} — {count?.toLocaleString() ?? "—"} views</li>;
}
```

## Afficher le total des vues du site {#showing-total-site-views}

`SiteViews` affiche un résumé d'une ligne du total des lectures de tous les articles. Placez-le là où vous voulez afficher ce total : un pied de page, une page « À propos » ou une bande de statistiques sur la page d'accueil.

```jsx
import SiteViews from "../components/SiteViews";

<SiteViews />
```

Il affiche un `<p class="site-views">` avec un texte comme `12,480 total reads across all posts.`, ou rien tant que la requête est en cours.

## Endpoints d'API attendus par les hooks {#api-endpoints-the-hooks-expect}

Les hooks appellent un service de vues partagé. Si vous changez de backend, il doit exposer la même structure sur les mêmes chemins.

| Méthode | Endpoint                 | Utilisé par     | Comportement                                                                               |
| ------ | ------------------------- | --------------- | ------------------------------------------------------------------------------------------ |
| `POST` | `/views/:postId`          | `useViewCount` (par défaut) | Enregistre une vue pour `postId` et renvoie le nouveau nombre.                   |
| `GET`  | `/views/:postId`          | `useViewCount` avec `{ increment: false }` | Renvoie le nombre actuel pour `postId` sans l'incrémenter.        |
| `GET`  | `/views/total`            | `useTotalViews` | Renvoie le nombre total de lectures de tous les articles.                                  |

Les corps de réponse ont ces formes :

```json
// /views/:postId
{ "count": 1234 }

// /views/total
{ "total": 12480 }
```

Les deux hooks traitent les réponses autres que `200` et les contenus non numériques comme des données manquantes : ils gardent l'état à `null` pour que les composants n'affichent rien plutôt qu'un nombre erroné. L'URL de base est configurée dans les hooks sur `https://api.paaatrrrick.com/views`.

## Styles {#styling}

`PostMeta` est livré avec `postMeta.css`, qui dispose les segments sur une ligne flex avec de fins séparateurs en forme de point. Les classes que vous pouvez cibler sont :

- `.post-meta` : la ligne englobante.
- `.post-meta-date` : le segment de date.
- `.view-counter` : le span du nombre de vues (également affiché seul par `ViewCounter`).
- `.site-views` : le paragraphe du total des vues affiché par `SiteViews`.
