## Démarrez en trois étapes

Faites tourner votre site de documentation en local et effectuez votre première personnalisation.

### Étape 1 : configurez votre environnement local

<AccordionGroup>
  <Accordion icon="copy" title="Cloner votre documentation en local">
    Pendant le processus d'onboarding, vous avez créé un dépôt GitHub avec le contenu de votre documentation si vous n'en aviez pas déjà un. Vous trouverez un lien vers ce dépôt dans votre [dashboard](https://dashboard.mintlify.com).
    
    Pour cloner le dépôt en local afin de pouvoir effectuer et prévisualiser des modifications sur votre documentation, suivez le guide [Cloning a repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) dans la documentation GitHub.
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Démarrer le serveur de prévisualisation">
    1. Installez la CLI Mintlify : `npm i -g mint`
    2. Rendez-vous dans votre répertoire de documentation et exécutez : `mint dev`
    3. Ouvrez `http://localhost:3000` pour voir votre documentation en direct !
    
    <Tip>Votre prévisualisation se met à jour automatiquement au fur et à mesure que vous modifiez les fichiers.</Tip>
  </Accordion>
</AccordionGroup>

### Étape 2 : déployez vos modifications

<AccordionGroup>
  <Accordion icon="github" title="Installer notre application GitHub">
    Installez l'application GitHub Mintlify depuis votre [dashboard](https://dashboard.mintlify.com/settings/organization/github-app).
    
    Notre application GitHub déploie automatiquement vos modifications sur votre site de documentation, ce qui vous évite d'avoir à gérer les déploiements vous-même.
</Accordion>
<Accordion icon="palette" title="Mettre à jour le nom et les couleurs de votre site">
    Pour une première modification, mettons à jour le nom et les couleurs de votre site de documentation.

    1. Ouvrez `docs.json` dans votre éditeur.
    2. Changez le champ `"name"` par le nom de votre projet.
    3. Mettez à jour les `"colors"` pour correspondre à votre marque.
    4. Enregistrez et voyez vos modifications instantanément sur `http://localhost:3000`.

    <Tip>Essayez de changer la couleur principale pour voir une différence immédiate !</Tip>
  </Accordion>
</AccordionGroup>

### Étape 3 : passez en production

<Accordion icon="rocket" title="Publier votre documentation">
  1. Committez et poussez vos modifications.
  2. Votre documentation sera mise à jour et en ligne en quelques instants !
</Accordion>
