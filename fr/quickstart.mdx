## Commencez en trois étapes

Faites fonctionner votre site de documentation en local et effectuez votre première personnalisation.

### Étape 1 : configurer votre environnement local

<AccordionGroup>
  <Accordion icon="copy" title="Cloner votre documentation en local">
    Lors du processus d'onboarding, vous avez créé un dépôt GitHub contenant votre documentation si vous n'en aviez pas déjà un. Vous trouverez un lien vers ce dépôt dans votre [tableau de bord](https://dashboard.mintlify.com).
    
    Pour cloner le dépôt en local afin de pouvoir modifier et prévisualiser votre documentation, suivez le guide [Clonage d'un dépôt](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) de la documentation GitHub.
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Démarrer le serveur d'aperçu">
    1. Installez la CLI Mintlify : `npm i -g mint`
    2. Accédez au répertoire de votre documentation et exécutez : `mint dev`
    3. Ouvrez `http://localhost:3000` pour voir votre documentation en direct !
    
    <Tip>Votre aperçu se met à jour automatiquement à mesure que vous modifiez les fichiers.</Tip>
  </Accordion>
</AccordionGroup>

### Étape 2 : déployer vos modifications

<AccordionGroup>
  <Accordion icon="github" title="Installer notre application GitHub">
    Installez l'application GitHub de Mintlify depuis votre [tableau de bord](https://dashboard.mintlify.com/settings/organization/github-app).
    
    Notre application GitHub déploie automatiquement vos modifications sur votre site de documentation : vous n'avez donc pas à gérer les déploiements vous-même.
</Accordion>
<Accordion icon="palette" title="Modifier le nom et les couleurs de votre site">
    Pour une première modification, changeons le nom et les couleurs de votre site de documentation.

    1. Ouvrez `docs.json` dans votre éditeur.
    2. Remplacez la valeur du champ `"name"` par le nom de votre projet.
    3. Modifiez `"colors"` pour les adapter à votre marque.
    4. Enregistrez et voyez instantanément vos modifications sur `http://localhost:3000`.

    <Tip>Essayez de changer la couleur principale pour voir immédiatement la différence !</Tip>
  </Accordion>
</AccordionGroup>

### Étape 3 : mettre en ligne

<Accordion icon="rocket" title="Publier votre documentation">
  1. Faites un commit et un push de vos modifications.
  2. Votre documentation sera mise à jour et en ligne en quelques instants !
</Accordion>
