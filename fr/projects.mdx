## Vue d'ensemble

Le site personnel dispose désormais d'une page dédiée `/projects`. Elle présente les projets personnels dans une grille responsive. Chaque carte affiche le nom du projet, une accroche, une description, les tags techniques et un lien vers le dépôt ou le site en ligne. Chaque carte affiche aussi un badge de cycle de vie `Active` ou `Archived`, en vert ou en gris.

Le composant `Projects` lit les entrées du tableau `projects` dans `src/constants/projects.js` et les affiche à `/projects`. Les visiteurs peuvent parcourir la liste complète des projets sans faire défiler la page d'accueil.

## Quand utiliser cette page

Ajoutez une entrée à `/projects` lorsque vous voulez mettre en avant un projet personnel sur sa propre carte, avec une accroche et des tags techniques. Utilisez la liste de la page d'accueil pour les projets mis en avant. Utilisez `/projects` pour le catalogue complet.

## Schéma d'entrée

Chaque objet du tableau `projects` accepte les champs suivants. Tous les champs sont obligatoires.

| Champ         | Type     | Description                                                                                       |
| ------------- | -------- | ------------------------------------------------------------------------------------------------- |
| `name`        | string   | Nom du projet rendu comme titre et lien de la carte.                                              |
| `tagline`     | string   | Résumé d'une ligne affiché directement sous le nom.                                               |
| `description` | string   | Paragraphe plus long qui explique ce que fait le projet et à qui il s'adresse.                    |
| `tech`        | string[] | Tags de stack rendus en liste horizontale (par exemple, `['React', 'Rust', 'SQLite']`).           |
| `status`      | string   | État du projet. Utilisez `'Active'` pour les projets que vous maintenez encore, ou `'Archived'` pour ceux que vous ne mettez plus à jour. Rendu comme un badge coloré dans l'en-tête de la carte. |
| `link`        | string   | URL vers laquelle pointe le titre de la carte. S'ouvre dans un nouvel onglet.                     |

## Ajouter un projet

Ouvrez `src/constants/projects.js` et ajoutez un nouvel objet au tableau `projects`. Les entrées sont rendues dans l'ordre du tableau, alors placez en premier le projet le plus récent ou le plus pertinent.

```js src/constants/projects.js
const projects = [
    {
        name: 'Inkwell',
        tagline: 'A markdown-first note-taking app',
        description: 'A local-first notes app with bidirectional links, a command palette, and end-to-end encrypted sync.',
        status: 'Active',
        tech: ['React', 'Rust', 'SQLite'],
        link: 'https://github.com/example/inkwell',
    },
];

export default projects;
```

<Tip>
Gardez `tagline` assez court pour tenir sur une ligne sur mobile. Visez moins de 60 caractères. Réservez l'argumentaire plus long pour `description`.
</Tip>

## Conseils de rédaction

La page `/projects` inclut un champ de recherche qui filtre sur `name`, `tagline` et `description`. La recherche fonctionne aussi avec le filtre par technologie. Utilisez des mots qu'un visiteur rechercherait, comme des catégories de produits, des domaines de problèmes ou des mots-clés de stack absents des tags. Ces mots aident les projets à apparaître dans les résultats.

- **Nom :** utilisez le nom canonique du projet. Évitez les préfixes emoji. Le design de la carte repose sur une hiérarchie typographique nette.
- **Accroche :** commencez par la catégorie ou la mécanique principale (« Gestionnaire de favoris auto-hébergé », pas « Un projet que j'ai fait »).
- **Description :** une ou deux phrases. Indiquez ce que fait le projet et le public visé.
- **Tags techniques :** listez les éléments structurants de la stack, pas chaque dépendance. Trois à cinq tags se lisent le mieux.
- **Statut :** utilisez `'Active'` pour les projets que vous maintenez encore. Passez à `'Archived'` lorsque vous arrêtez de publier des mises à jour. Les visiteurs comprennent ainsi que le projet est figé. Le badge devient gris au lieu de vert.
- **Lien :** préférez l'URL du dépôt pour les projets open source, ou le site en ligne pour les projets hébergés.

## Navigation

L'application enregistre la page dans `src/App.js` ainsi :

```js src/App.js
<Route exact path='/projects' component={Projects} />
```

Faites un lien vers cette page depuis n'importe où sur le site avec `/projects`. Les visiteurs qui ouvrent directement la route voient un lien « ← Back home » dans l'en-tête.
