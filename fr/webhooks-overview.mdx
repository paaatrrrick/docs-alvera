Les webhooks permettent à votre application d'être notifiée lorsqu'un événement se produit, sans que vous ayez à interroger notre API en permanence.

## Fonctionnement

Lorsqu'un événement se produit, nous envoyons une requête HTTP POST à l'URL que vous avez configurée. La charge utile contient le type d'événement et les données.

Pour configurer un webhook :

1. Rendez-vous dans les paramètres des webhooks {/* Broken-link audit: unresolved link target `/settings/webhooks-config`; no safe replacement identified. */}.
2. Saisissez l'URL de votre endpoint et choisissez les événements que vous souhaitez recevoir.
3. Enregistrez, et nous commencerons à envoyer les événements immédiatement.

<Note>
Vous devez vérifier la signature de chaque requête afin que personne ne puisse nous usurper. Les détails se trouvent dans le guide de sécurité {/* Broken-link audit: unresolved link target `./security/verify-signatures`; no safe replacement identified. */}.
</Note>

## Nouvelles tentatives

Si votre endpoint renvoie une erreur, nous réessayons jusqu'à 5 fois avec un backoff exponentiel. Après cela, nous abandonnons et le marquons comme échoué ; vous pouvez le voir dans les journaux {/* Broken-link audit: unresolved link target `#webhook-logz`; no safe replacement identified. */}.
