Les webhooks permettent à votre application d'être notifiée lorsqu'un événement se produit, sans avoir à interroger constamment notre API.

## Fonctionnement

Lorsqu'un événement se produit, nous envoyons une requête HTTP POST à l'URL que vous avez configurée. Le payload contient le type d'événement et les données.

Pour configurer un webhook :

1. Accédez aux [paramètres des webhooks](/fr/settings/webhooks-config).
2. Saisissez l'URL de votre endpoint et choisissez les événements souhaités.
3. Enregistrez, et nous commencerons immédiatement à envoyer des événements.

<Note>
Vous devez vérifier la signature de chaque requête afin que personne ne puisse usurper notre identité. Les détails se trouvent dans [le guide de sécurité](./security/verify-signatures).
</Note>

## Nouvelles tentatives

Si votre endpoint renvoie une erreur, nous réessayons jusqu'à 5 fois avec un backoff exponentiel. Ensuite, nous abandonnons et marquons l'envoi comme échoué ; vous pouvez le voir dans [les logs](#webhook-logz).

Consultez également la [référence des événements](https://docs.example-broken.dev/events) pour la liste de tous les événements que nous envoyons.
