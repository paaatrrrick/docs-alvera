---
title: 'Paramètres globaux dans docs.json'
description: 'Référence de chaque propriété de docs.json qui contrôle le nom du site, le thème, les couleurs, le logo, la navigation et les intégrations pour votre documentation Mintlify.'
icon: 'gear'
---

Chaque site Mintlify a besoin d'un fichier `docs.json` contenant les paramètres de configuration essentiels. Découvrez-en plus sur les [propriétés](#properties) ci-dessous.

## Propriétés

<ResponseField name="name" type="string" required>
Le nom de votre projet. Utilisé pour le titre global.

Exemple : `mintlify`

</ResponseField>

<ResponseField name="navigation" type="Navigation[]" required>
  Un tableau de groupes contenant toutes les pages de ce groupe.
  <Expandable title="Navigation">
    <ResponseField name="group" type="string">
    Le nom du groupe.

    Exemple : `Settings`

    </ResponseField>
    <ResponseField name="pages" type="string[]">
    Les chemins relatifs vers les fichiers Markdown qui serviront de pages.

    Exemple : `["customization", "page"]`

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="logo" type="string or object">
  Chemin vers l'image du logo, ou objet avec le chemin vers les images de logo « light » et « dark ».
  <Expandable title="Logo">
    <ResponseField name="light" type="string">
      Chemin vers le logo en mode clair.
    </ResponseField>
    <ResponseField name="dark" type="string">
      Chemin vers le logo en mode sombre.
    </ResponseField>
    <ResponseField name="href" type="string" default="/">
      Cible du lien lorsque l'utilisateur clique sur le logo.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="favicon" type="string">
  Chemin vers l'image du favicon.
</ResponseField>

<ResponseField name="colors" type="Colors">
  Codes couleur hexadécimaux pour votre thème global.
  <Expandable title="Colors">
    <ResponseField name="primary" type="string" required>
      La couleur principale. Utilisée le plus souvent pour le contenu mis en avant, les en-têtes de
      section et les accents, en mode clair.
    </ResponseField>
    <ResponseField name="light" type="string">
      La couleur principale pour le mode sombre. Utilisée le plus souvent pour le contenu mis en avant,
      les en-têtes de section et les accents, en mode sombre.
    </ResponseField>
    <ResponseField name="dark" type="string">
      La couleur principale pour les boutons importants.
    </ResponseField>
    <ResponseField name="background" type="object">
      La couleur de l'arrière-plan en mode clair et en mode sombre.
      <Expandable title="Object">
        <ResponseField name="light" type="string" required>
          Le code hexadécimal de la couleur d'arrière-plan en mode clair.
        </ResponseField>
        <ResponseField name="dark" type="string" required>
          Le code hexadécimal de la couleur d'arrière-plan en mode sombre.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topbarLinks" type="TopbarLink[]">
  Tableau de `name` et `url` de liens à inclure dans la barre supérieure.
  <Expandable title="TopbarLink">
    <ResponseField name="name" type="string">
    Le nom du bouton.

    Exemple : `Contact us`
    </ResponseField>
    <ResponseField name="url" type="string">
    L'URL vers laquelle le bouton redirige lorsqu'on clique dessus. Exemple : `https://mintlify.com/docs`
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topbarCtaButton" type="Call to Action">
  <Expandable title="Topbar Call to Action">
    <ResponseField name="type" type={'"link" or "github"'} default="link">
    `link` affiche un bouton. `github` affiche les informations du dépôt à l'URL fournie, y compris le nombre d'étoiles GitHub.
    </ResponseField>
    <ResponseField name="url" type="string">
    Si `link` : la cible du bouton.
    
    Si `github` : le lien vers le dépôt duquel charger les informations GitHub.
    </ResponseField>
    <ResponseField name="name" type="string">
    Le texte à l'intérieur du bouton. Requis uniquement si `type` vaut `link`.
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="versions" type="string[]">
  Tableau des noms de versions. À n'utiliser que si vous souhaitez afficher différentes versions
  de la documentation via un menu déroulant dans la barre de navigation.
</ResponseField>

<ResponseField name="anchors" type="Anchor[]">
  Un tableau des ancres, incluant `icon`, `color` et `url`.
  <Expandable title="Anchor">
    <ResponseField name="icon" type="string">
    L'icône [Font Awesome](https://fontawesome.com/search?q=heart) utilisée pour mettre en avant l'ancre.

    Exemple : `comments`
    </ResponseField>
    <ResponseField name="name" type="string">
    Le nom du libellé de l'ancre.

    Exemple : `Community`
    </ResponseField>
    <ResponseField name="url" type="string">
      Le début de l'URL qui indique quelles pages appartiennent à l'ancre. En général, il s'agit du nom du dossier dans lequel vous placez vos pages.
    </ResponseField>
    <ResponseField name="color" type="string">
      La couleur hexadécimale de l'arrière-plan de l'icône d'ancre. Peut également être un dégradé si vous passez un objet avec les propriétés `from` et `to`, chacune étant une couleur hexadécimale.
    </ResponseField>
    <ResponseField name="version" type="string">
      À utiliser si vous souhaitez masquer une ancre jusqu'à ce que la version de documentation appropriée soit sélectionnée.
    </ResponseField>
    <ResponseField name="isDefaultHidden" type="boolean" default="false">
      Passez `true` si vous souhaitez masquer l'ancre jusqu'à ce que vous liez directement quelqu'un à une page qu'elle contient.
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      L'une des valeurs suivantes : "brands", "duotone", "light", "sharp-solid", "solid" ou "thin".
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topAnchor" type="Object">
  Remplacer les configurations par défaut de l'ancre située tout en haut.
  <Expandable title="Object">
    <ResponseField name="name" default="Documentation" type="string">
      Le nom de l'ancre située tout en haut.
    </ResponseField>
    <ResponseField name="icon" default="book-open" type="string">
      Icône Font Awesome.
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      L'une des valeurs suivantes : "brands", "duotone", "light", "sharp-solid", "solid" ou "thin".
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tabs" type="Tabs[]">
  Un tableau d'onglets de navigation.
  <Expandable title="Tabs">
    <ResponseField name="name" type="string">
      Le nom du libellé de l'onglet.
    </ResponseField>
    <ResponseField name="url" type="string">
      Le début de l'URL qui indique quelles pages appartiennent à l'onglet. En général,
      il s'agit du nom du dossier dans lequel vous placez vos pages.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api" type="API">
  Configuration des paramètres d'API. Découvrez-en plus sur les pages d'API dans [API Components](https://mintlify.com/docs/api-playground/overview).
  <Expandable title="API">
    <ResponseField name="baseUrl" type="string">
      L'URL de base pour tous les endpoints de l'API. Si `baseUrl` est un tableau, cela activera
      plusieurs options d'URL de base entre lesquelles l'utilisateur pourra basculer.
    </ResponseField>

    <ResponseField name="auth" type="Auth">
      <Expandable title="Auth">
        <ResponseField name="method" type='"bearer" | "basic" | "key"'>
          La stratégie d'authentification utilisée pour tous les endpoints de l'API.
        </ResponseField>
        <ResponseField name="name" type="string">
        Le nom du paramètre d'authentification utilisé dans le playground de l'API.

        Si la méthode est `basic`, le format doit être `[usernameName]:[passwordName]`.
        </ResponseField>
        <ResponseField name="inputPrefix" type="string">
        La valeur par défaut destinée à servir de préfixe au champ de saisie d'authentification.

        Par exemple, un `inputPrefix` de `AuthKey` définirait la valeur par défaut du champ d'authentification à `AuthKey`.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="playground" type="Playground">
      Configurations pour le playground de l'API.

      <Expandable title="Playground">
        <ResponseField name="mode" default="show" type='"show" | "simple" | "hide"'>
          Indique si le playground est affiché, masqué, ou n'affiche que l'endpoint sans interactivité utilisateur supplémentaire (`simple`).

          Découvrez-en plus dans les [guides du playground](https://mintlify.com/docs/api-playground/overview).
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="maintainOrder" type="boolean">
      Activer ce drapeau garantit que l'ordre des clés dans les pages OpenAPI correspond à l'ordre des clés défini dans le fichier OpenAPI.

      <Warning>Ce comportement sera bientôt activé par défaut, moment auquel ce champ sera déprécié.</Warning>
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="openapi" type="string | string[]">
  Une chaîne ou un tableau de chaînes d'URL(s) ou de chemin(s) relatif(s) vers votre
  fichier OpenAPI.
  
  Exemples :
  <CodeGroup>
    ```json Absolute
    "openapi": "https://example.com/openapi.json"
    ```
    ```json Relative
    "openapi": "/openapi.json"
    ```
    ```json Multiple
    "openapi": ["https://example.com/openapi1.json", "/openapi2.json", "/openapi3.json"]
    ```
  </CodeGroup>

</ResponseField>

<ResponseField name="footerSocials" type="FooterSocials">
  Un objet de comptes de réseaux sociaux où le couple clé:propriété représente la plateforme de réseau social et l'URL du compte.
  
  Exemple :
  ```json
  {
    "x": "https://x.com/mintlify",
    "website": "https://mintlify.com"
  }
  ```
  <Expandable title="FooterSocials">
    <ResponseField name="[key]" type="string">
    L'une des valeurs suivantes : `website`, `facebook`, `x`, `discord`, `slack`, `github`, `linkedin`, `instagram`, `hacker-news`.
    
    Exemple : `x`
    </ResponseField>
    <ResponseField name="property" type="string">
    L'URL vers la plateforme sociale.
    
    Exemple : `https://x.com/mintlify`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="feedback" type="Feedback">
  Configurations pour activer les boutons de retour d'expérience.

  <Expandable title="Feedback">
    <ResponseField name="suggestEdit" type="boolean" default="false">
    Active un bouton permettant aux utilisateurs de suggérer des modifications via des pull requests.
    </ResponseField>
    <ResponseField name="raiseIssue" type="boolean" default="false">
    Active un bouton permettant aux utilisateurs de signaler un problème concernant la documentation.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="modeToggle" type="ModeToggle">
  Personnalisez le sélecteur de mode sombre.
  <Expandable title="ModeToggle">
    <ResponseField name="default" type={'"light" or "dark"'}>
      À définir si vous souhaitez toujours afficher le mode clair ou sombre pour les nouveaux utilisateurs. Lorsque non
      défini, nous utilisons par défaut le même mode que le système d'exploitation de l'utilisateur.
    </ResponseField>
    <ResponseField name="isHidden" type="boolean" default="false">
      Passez à `true` pour masquer le sélecteur de mode sombre/clair. Vous pouvez combiner `isHidden` avec `default` pour forcer votre documentation à n'utiliser que le mode clair ou le mode sombre. Par exemple :
      
      <CodeGroup>
      ```json Only Dark Mode
      "modeToggle": {
        "default": "dark",
        "isHidden": true
      }
      ```

      ```json Only Light Mode
      "modeToggle": {
        "default": "light",
        "isHidden": true
      }
      ```
      </CodeGroup>

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="backgroundImage" type="string">
  Une image d'arrière-plan à afficher derrière chaque page. Voir l'exemple avec
  [Infisical](https://infisical.com/docs) et [FRPC](https://frpc.io).
</ResponseField>
