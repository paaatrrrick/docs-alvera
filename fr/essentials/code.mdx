## Code en ligne

Pour désigner un `mot` ou une `expression` comme du code, entourez-le d'accents graves (`).

```
To denote a `word` or `phrase` as code, enclose it in backticks (`).
```

## Blocs de code

Utilisez des [blocs de code délimités](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks) en entourant le code de trois accents graves et faites suivre les accents graves d'ouverture du langage de programmation de votre extrait pour obtenir la coloration syntaxique. Vous pouvez également écrire le nom de votre code après le langage de programmation.

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```
