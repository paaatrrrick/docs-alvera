Configurez Cursor pour vous aider à rédiger et à maintenir votre documentation Mintlify.

## Prérequis

- Éditeur Cursor installé

## Configuration

<Steps>
<Step title="Ouvrir le répertoire de votre documentation dans Cursor">
  Ouvrez la racine du dépôt de votre documentation, là où se trouve `docs.json`.
</Step>

<Step title="Installer le skill Mintlify">
  Dans le terminal intégré, exécutez :

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  Cela fournit à Cursor la référence des composants Mintlify, les normes de rédaction
  et des conseils sur le workflow.
</Step>

<Step title="Personnaliser les instructions du projet">
  Modifiez `AGENTS.md` à la racine de votre projet pour ajouter la terminologie propre au projet,
  vos préférences de style et les limites du contenu.
</Step>

<Step title="Commencer à rédiger avec Cursor">
  Ouvrez un fichier et utilisez les fonctionnalités IA de Cursor pour rédiger et modifier la documentation.
</Step>
</Steps>
