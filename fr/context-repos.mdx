## Résumés des dépôts

Chacun des dépôts suivants est disponible en lecture seule comme référence pour ce déploiement de documentation.

- **[alfoods-and-patrick](https://github.com/paaatrrrick/alfoods-and-patrick)** — Un projet de démarrage Next.js initialisé avec `create-next-app` et configuré avec la police Geist de `next/font`.
- **[boilerplate](https://github.com/paaatrrrick/boilerplate)** — Un modèle full-stack Next.js, TypeScript, Node/Express, MongoDB et TailwindCSS, avec authentification Firebase, barres de navigation, gestion des erreurs et écrans de chargement préconfigurés.
- **[chemistryresearch](https://github.com/paaatrrrick/chemistryresearch)** — Une application web statique qui visualise un schéma de codage de la facilitation par les instructeurs, déployée sur facilitation-visualization.netlify.app.
- **[conductor-playground](https://github.com/paaatrrrick/conductor-playground)** — Un dépôt vide de type bloc-notes utilisé pour l'expérimentation avec Conductor.
- **[brain-test](https://github.com/paaatrrrick/brain-test)** — Un modèle de « cerveau d'entreprise » basé sur Mintlify qui modélise l'intégration, la direction, les équipes, les personnes et les ressources d'une startup de taille moyenne sous forme de fichiers Markdown qu'un agent d'IA maintient à jour.
- **[docs](https://github.com/paaatrrrick/docs)** — Une copie du kit de démarrage Mintlify avec des exemples de pages de guide, navigation, personnalisations, référence d'API et composants populaires.
- **[docs-dre](https://github.com/paaatrrrick/docs-dre)** — Un autre fork du kit de démarrage Mintlify qui documente en plus les workflows d'écriture assistée par IA via la commande `npx skills add`.
- **[docs-franny](https://github.com/paaatrrrick/docs-franny)** — Un kit de démarrage Mintlify minimal qui contient uniquement `index.mdx`, `quickstart.mdx` et `docs.json`.
- **[docs-monorepo](https://github.com/paaatrrrick/docs-monorepo)** — Une disposition monorepo qui imbrique un kit de démarrage Mintlify complet dans un sous-répertoire `docs/` aux côtés de contenu `misc/`.
- **[docs-starter](https://github.com/paaatrrrick/docs-starter)** — Un site Mintlify de style portfolio personnel (« Patrick Foster ») avec des traductions en anglais, espagnol et français de pages comme expérience, projets et utilisations.
- **[efficieny-bench-spring-boot](https://github.com/paaatrrrick/efficieny-bench-spring-boot)** — Un fork du code source de Spring Boot utilisé pour créer des applications et services Java de qualité production propulsés par Spring.
- **[learning_flask](https://github.com/paaatrrrick/learning_flask)** — Un exercice de programmation en binôme avec Flask qui prédit le salaire d'un utilisateur à l'aide d'un modèle de machine learning servi par une petite application web.
- **[pantern](https://github.com/paaatrrrick/pantern)** — Un projet client/serveur qui explore comment les développeurs backend construisent des frontends.
- **[patfoster-hw6](https://github.com/paaatrrrick/patfoster-hw6)** — Un site statique HTML/CSS soumis en devoir 6 du cours BAIS3300.
- **[radah](https://github.com/paaatrrrick/radah)** — Un projet en plusieurs parties pour radah.ai combinant un client macOS en Swift qui lance des machines virtuelles locales, une interface et un agent VM, et un serveur web (le client Windows n'est pas encore commencé).
- **[salary_prediction_model](https://github.com/paaatrrrick/salary_prediction_model)** — Un notebook Jupyter qui entraîne un modèle de machine learning sur l'enquête Kaggle de 2022 pour prédire le salaire individuel à partir de sept caractéristiques.
- **[test-repo](https://github.com/paaatrrrick/test-repo)** — Un dépôt jetable contenant un unique fichier `text.txt`, utilisé uniquement à des fins de test.
- **[voodootrade](https://github.com/paaatrrrick/voodootrade)** — Un dépôt vide qui n'a pas encore de contenu validé.
- **[vtrade](https://github.com/paaatrrrick/vtrade)** — Un projet Next.js en TypeScript initialisé avec `create-next-app` et configuré avec la police Geist.
- **[wordsmith-api](https://github.com/paaatrrrick/wordsmith-api)** — Le backend Express, Node.js et MongoDB de Wordsmith, une extension Chrome propulsée par GPT qui réécrit le texte surligné selon différents tons.
- **[wordsmith-client](https://github.com/paaatrrrick/wordsmith-client)** — L'extension Chrome et le frontend web React de Wordsmith, permettant aux utilisateurs de surligner du texte sur n'importe quelle page et d'obtenir des alternatives réécrites par IA.
- **[yogi-tea](https://github.com/paaatrrrick/yogi-tea)** — Un ensemble de notebooks Python, jeux de données et modèles de machine learning conçus pour aider Yogi Tea à analyser l'élasticité-prix, l'augmentation promotionnelle et les prévisions de ventes unitaires.
