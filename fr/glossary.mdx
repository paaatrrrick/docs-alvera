Ce glossaire définit les termes utilisés dans toute cette documentation. Parcourez-le une fois, puis consultez-le dès qu'un mot n'est pas clair.

## Termes

**Déploiement**
Une version publiée de votre site. Chaque push vers votre branche principale crée un nouveau déploiement.

**Aperçu**
Une compilation temporaire d'une pull request. Utilisez-le pour vérifier les modifications avant leur mise en ligne.

**Navigation**
La structure de la barre latérale qui organise vos pages. Vous la définissez dans `docs.json`.

**Snippet**
Un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages. Les snippets se trouvent dans le répertoire `snippets/`.

**Frontmatter**
Le bloc YAML au début de chaque page MDX. Il définit les métadonnées de la page, comme `title` et `description`.

Si vous débutez, lisez d'abord le [démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement local](/fr/development).
