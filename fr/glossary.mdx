Ce glossaire définit cinq termes que vous rencontrerez tout au long de la documentation. Consultez-le chaque fois qu'un mot n'est pas clair.

## Termes

- **Deployment** — Une version publiée de votre site de documentation. Chaque push vers votre branche de déploiement produit un nouveau deployment que voient les utilisateurs finaux.
- **Preview** — Une build temporaire générée pour une pull request afin que vous puissiez examiner les changements avant leur mise en ligne. Les previews utilisent la même configuration que la production, mais sont isolées par branche.
- **Navigation** — La barre latérale et la structure de premier niveau qui organisent vos pages, définies dans `docs.json`. Consultez [essentials/navigation](/fr/essentials/navigation) pour le schéma.
- **Snippet** — Un bloc de contenu MDX réutilisable stocké dans `snippets/` que vous pouvez inclure sur plusieurs pages pour éviter la duplication.
- **Frontmatter** — Le bloc YAML en haut de chaque fichier MDX (entre les marqueurs `---`) qui définit les métadonnées de la page, comme `title` et `description`.

Si vous débutez, lisez le [guide de démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement local](/fr/development).
