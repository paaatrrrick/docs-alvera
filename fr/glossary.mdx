Ce glossaire définit les termes utilisés dans toute cette documentation. Parcourez-le une fois, puis revenez-y dès qu'un mot n'est pas clair.

## Termes

### Déploiement

Une version publiée de votre site de documentation. Chaque push vers votre branche main crée un nouveau déploiement.

### Aperçu

Une compilation temporaire générée pour une pull request. Utilisez-la pour vérifier les modifications avant leur mise en ligne.

### Navigation

La structure de la barre latérale qui organise vos pages. Vous la définissez dans `docs.json`.

### Snippet

Un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages. Les snippets se trouvent dans le répertoire `snippets/`.

### Frontmatter

Le bloc YAML en haut de chaque page MDX. Il définit les métadonnées de la page, comme `title` et `description`.
