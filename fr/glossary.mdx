Ce glossaire définit les termes utilisés dans cette documentation. Consultez-le chaque fois qu'un mot n'est pas clair.

## Termes

- **Déploiement** : Une version publiée de votre site. Mintlify crée un nouveau déploiement chaque fois que vous fusionnez dans votre branche de déploiement. Consultez [Comment fonctionne Mintlify](/fr/how-mintlify-works).
- **MDX** : Le format de fichier de chaque page. MDX est du Markdown enrichi de composants React comme `<Card>`, `<Tabs>` et `<Accordion>`. Chaque fichier MDX commence par un frontmatter YAML, par exemple `title` et `description`. Consultez [Syntaxe Markdown](/fr/essentials/markdown).
- **Navigation** : La structure de la barre latérale qui organise vos pages en onglets et en groupes. Vous la définissez dans le champ `navigation` de `docs.json`. Consultez [Navigation](/fr/essentials/navigation).
- **Aperçu** : Une build temporaire d'une pull request. Utilisez-la pour vérifier les modifications avant leur mise en ligne. Pour un aperçu local, exécutez `mint dev`.
- **Extrait (snippet)** : Un bloc de contenu réutilisable stocké dans le répertoire `snippets/`. Vous pouvez importer un extrait dans n'importe quelle page. Consultez [Extraits réutilisables](/fr/essentials/reusable-snippets).

Si vous débutez, lisez d'abord le [guide de démarrage rapide](/fr/quickstart). Configurez ensuite votre environnement avec le [guide de développement local](/fr/development).
