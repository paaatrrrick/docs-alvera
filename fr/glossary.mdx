Ce glossaire définit cinq termes courants utilisés dans cette documentation. Consultez-le dès qu'un mot n'est pas clair.

## Termes

- **Déploiement** — Une version publiée de votre site. Chaque push sur votre branche principale crée un nouveau déploiement.
- **Aperçu** — Une build temporaire d'une pull request, pour vous permettre de vérifier les changements avant leur mise en ligne.
- **Navigation** — La structure de la barre latérale qui organise vos pages, définie dans `docs.json`.
- **Snippet** — Un bloc de contenu MDX réutilisable que vous pouvez inclure sur plusieurs pages depuis le dossier `snippets/`.
- **Frontmatter** — Le bloc YAML en haut d'un fichier MDX qui définit les métadonnées de la page, comme `title` et `description`.

Si vous débutez, lisez d'abord le [démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement](/fr/development).
