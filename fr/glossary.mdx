Ce glossaire définit les termes utilisés dans toute cette documentation. Parcourez-le une fois, puis revenez-y dès qu'un mot vous semble flou.

## Termes

- **Déploiement (Deployment)** : une version publiée de votre site. Chaque push sur votre branche `main` crée un nouveau déploiement.
- **Aperçu (Preview)** : une compilation temporaire d'une pull request. Utilisez-la pour vérifier les changements avant leur mise en ligne.
- **Navigation** : la structure de la barre latérale qui organise vos pages. Vous la définissez dans [`docs.json`](/fr/essentials/navigation).
- **Extrait (Snippet)** : un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages. Voir [extraits réutilisables](/fr/essentials/reusable-snippets).
- **Frontmatter** : le bloc YAML en haut d'un fichier `.mdx` qui définit les métadonnées de la page, comme `title` et `description`.

Si vous débutez, lisez le [démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement local](/fr/development).
