Ce glossaire définit les termes utilisés dans cette documentation. Parcourez-le une fois, puis revenez-y dès qu'un mot n'est pas clair.

## Termes

- **Déploiement** : Une version publiée de votre site. Chaque push sur votre branche principale crée un nouveau déploiement.
- **Aperçu** : Une compilation temporaire d'une pull request. Utilisez-la pour vérifier les modifications avant leur mise en ligne.
- **Navigation** : La structure de la barre latérale qui organise vos pages. Vous la définissez dans `docs.json`.
- **Snippet** : Un bloc de contenu réutilisable que vous pouvez inclure dans plusieurs pages.
- **Frontmatter** : Le bloc YAML en haut de chaque page MDX. Il définit des métadonnées comme le `title` et la `description` de la page.

Si vous débutez, lisez d'abord le [démarrage rapide](/fr/quickstart). Configurez ensuite votre environnement avec le [guide de développement local](/fr/development).
