Ce glossaire définit les termes les plus fréquemment utilisés dans cette documentation. Parcourez-le une fois, puis revenez-y dès qu'un mot n'est pas clair.

## Termes

**Deployment**
Une version publiée de votre site de documentation. Chaque push vers votre branche principale crée un nouveau deployment.

**Preview**
Une compilation temporaire générée pour une pull request. Utilisez-la pour vérifier les modifications avant leur mise en ligne.

**Navigation**
La structure de la barre latérale qui organise vos pages. Vous la définissez dans `docs.json`. Consultez [navigation](/fr/essentials/navigation).

**Snippet**
Un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages. Consultez [snippets réutilisables](/fr/essentials/reusable-snippets).

**Webhook**
Un rappel HTTP qui envoie une charge utile d'événement à une URL que vous configurez. Consultez la [présentation des webhooks](/fr/webhooks-overview).

Si vous débutez, lisez d'abord le [démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement local](/fr/development).
