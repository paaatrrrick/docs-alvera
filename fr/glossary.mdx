Ce glossaire définit cinq termes que vous rencontrerez le plus souvent dans ces docs. Parcourez-le une fois, puis revenez-y chaque fois qu'un mot n'est pas clair.

## Termes

- **Deployment** — Une version publiée de votre site de documentation. Chaque push sur votre branche de production crée un nouveau deployment. Consultez [comment fonctionne Mintlify](/how-mintlify-works) pour le flux complet de compilation et de publication.
- **Preview** — Une compilation temporaire de votre site par pull request qui vous permet de relire les modifications avant de les fusionner. Les previews utilisent la même navigation et le même thème que votre deployment de production.
- **Navigation** — La structure de la barre latérale et des onglets qui organise vos pages, définie sous la clé `navigation` dans [`docs.json`](/essentials/navigation). Les groupes, les pages et les onglets se configurent ici.
- **Snippet** — Un bloc de contenu MDX réutilisable, stocké dans `snippets/`, que vous pouvez importer dans plusieurs pages pour synchroniser le contenu partagé. Consultez [snippets réutilisables](/essentials/reusable-snippets).
- **Frontmatter** — Le bloc YAML en haut de chaque page MDX (entre les marqueurs `---`) qui définit les métadonnées de la page, telles que `title` et `description`. Mintlify utilise ces champs pour afficher les en-têtes de page et les résultats de recherche.

Si vous débutez, lisez d'abord le [démarrage rapide](/quickstart) puis configurez votre environnement avec le [guide de développement](/development).
