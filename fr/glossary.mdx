Ce glossaire définit les termes utilisés dans ces documents. Parcourez-le une fois, puis revenez-y dès qu'un mot n'est pas clair.

## Termes

- **Déploiement** : Une version publiée de votre site. Chaque push sur votre branche principale crée un nouveau déploiement.
- **Aperçu** : Une build temporaire d'une pull request, pour que vous puissiez examiner les changements avant leur mise en ligne.
- **Navigation** : La structure de la barre latérale qui organise vos pages, définie dans votre fichier de configuration.
- **Snippet** : Un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages.
- **Frontmatter** : Le bloc YAML en haut de chaque page MDX qui définit les métadonnées comme `title` et `description`.

Si vous débutez, lisez d'abord le [guide de démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement local](/fr/development).
