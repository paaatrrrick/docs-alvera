Ce glossaire définit les termes utilisés dans l'ensemble de cette documentation. Parcourez-le une fois, puis revenez-y chaque fois qu'un mot vous semble flou.

## Termes {#terms}

- **Déploiement** : une version publiée de votre site. Chaque push sur votre branche principale crée un nouveau déploiement.
- **Aperçu** : une build temporaire d'une pull request. Utilisez-le pour vérifier les modifications avant leur mise en ligne.
- **Navigation** : la structure de la barre latérale qui organise vos pages. Vous la définissez dans `docs.json`.
- **Snippet** : un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages.
- **Frontmatter** : le bloc YAML situé en haut d'un fichier MDX. Il définit les métadonnées de la page, comme `title` et `description`.

Si vous débutez, lisez d'abord le [guide de démarrage rapide](/fr/quickstart). Configurez ensuite votre environnement avec le [guide de développement local](/fr/development).
