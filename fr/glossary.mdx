Ce glossaire définit les termes utilisés dans toute cette documentation. Parcourez-le une fois, puis revenez-y dès qu'un mot n'est pas clair.

## Termes

**Déploiement**
Une version publiée de votre site. Chaque push vers votre branche principale crée un nouveau déploiement.

**Aperçu**
Une build temporaire d'une pull request. Utilisez-la pour vérifier les changements avant leur mise en ligne.

**Navigation**
La structure de la barre latérale qui organise vos pages. Vous la définissez dans `docs.json`.

**Snippet**
Un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages. Consultez les [snippets réutilisables](/fr/essentials/reusable-snippets).

**Frontmatter**
Le bloc YAML en haut de chaque page MDX qui définit des métadonnées comme `title` et `description`.

Si vous débutez, lisez d'abord le [démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement local](/fr/development).
