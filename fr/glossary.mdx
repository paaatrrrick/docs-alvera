Ce glossaire définit les termes utilisés dans cette documentation. Consultez-le lorsque le sens d'un mot n'est pas clair.

## Termes

- **Déploiement:** Une version publiée de votre site. Chaque push vers votre branche principale crée un nouveau déploiement.
- **Aperçu:** Un build temporaire issu d'une pull request pour examiner les modifications avant leur mise en ligne.
- **Navigation:** La structure de la barre latérale qui organise vos pages. Vous la définissez dans votre fichier de configuration.
- **Snippet:** Un bloc de contenu réutilisable que vous pouvez inclure dans plusieurs pages.
- **Frontmatter:** Le bloc YAML au début d'un fichier MDX qui définit les métadonnées de la page, comme `title` et `description`.

Si vous débutez, consultez d'abord le [guide de démarrage rapide](/quickstart), puis configurez votre environnement avec le [guide de développement local](/development).
