Ce glossaire définit les termes utilisés tout au long de cette documentation. Parcourez-le une fois, puis revenez-y chaque fois qu'un mot n'est pas clair.

## Termes

- **Déploiement** : Une version publiée de votre site. Chaque push sur votre branche principale crée un nouveau déploiement.
- **Aperçu** : Une build temporaire d'une pull request. Utilisez-la pour vérifier les changements avant leur mise en ligne.
- **Navigation** : La structure de la barre latérale qui organise vos pages. Elle est définie dans `docs.json` sous le champ `navigation`.
- **Snippet** : Un bloc de contenu réutilisable stocké dans `snippets/` que vous pouvez inclure sur plusieurs pages.
- **Frontmatter** : Le bloc YAML en haut de chaque fichier MDX. Il définit les métadonnées de la page, telles que `title` et `description`.

Si vous débutez, lisez d'abord le [démarrage rapide](/quickstart) puis configurez votre environnement avec le [guide de développement local](/development).
