Ce glossaire définit les termes utilisés tout au long de cette documentation. Parcourez-le une fois, puis revenez-y chaque fois qu'un mot n'est pas clair.

## Termes

- **Deployment** — Une version publiée de votre site. Chaque push sur votre branche principale crée un nouveau deployment accessible aux utilisateurs finaux.
- **Preview** — Une compilation temporaire d'une pull request, pour vous permettre d'examiner les changements avant leur mise en ligne.
- **Navigation** — La structure de la barre latérale qui organise vos pages, définie dans le champ `navigation` de votre fichier de configuration `docs.json`.
- **Snippet** — Un bloc réutilisable de contenu MDX, stocké dans le répertoire `snippets/`, que vous pouvez inclure sur plusieurs pages pour éviter les duplications.
- **Frontmatter** — Le bloc YAML en haut de chaque fichier `.mdx` (entre les délimiteurs `---`) qui définit les métadonnées de la page, telles que `title` et `description`.

Si vous débutez, lisez d'abord le [guide de démarrage rapide](/fr/quickstart), puis configurez votre environnement avec le [guide de développement local](/fr/development).
