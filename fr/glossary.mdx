Ce glossaire définit les termes utilisés dans ces documents. Parcourez-le une fois, puis consultez-le chaque fois qu'un mot n'est pas clair.

## Termes

- **Déploiement** — Une version publiée de votre site. Chaque push vers votre branche principale crée un nouveau déploiement.
- **Aperçu** — Une compilation temporaire d'une pull request, pour que vous puissiez examiner les modifications avant leur mise en ligne.
- **Navigation** — La structure de la barre latérale qui organise vos pages, définie dans votre fichier de configuration.
- **Snippet** — Un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages.
- **MDX** — Le format de fichier utilisé pour les pages de documentation. MDX combine Markdown avec des composants de style JSX, ce qui vous permet de mélanger prose, blocs de code et composants interactifs dans un seul fichier.

Si vous débutez, lisez d'abord le [guide de démarrage](/quickstart), puis configurez votre environnement avec le [guide de développement local](/development).
