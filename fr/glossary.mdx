Ce glossaire définit les termes utilisés tout au long de ces documents. Parcourez-le une fois, puis revenez-y chaque fois qu'un mot n'est pas clair.

## Termes

- **Déploiement** : Une version publiée de votre site. Chaque push sur votre branche main crée un nouveau déploiement.
- **Aperçu** : Une compilation temporaire d'une pull request, pour que vous puissiez examiner les modifications avant qu'elles ne soient mises en ligne.
- **Navigation** : La structure de la barre latérale qui organise vos pages, définie dans votre fichier de configuration.
- **Snippet** : Un bloc de contenu réutilisable que vous pouvez inclure sur plusieurs pages.
- **MDX** : Le format de fichier utilisé pour les pages de documentation. MDX combine Markdown et composants JSX, ce qui vous permet de mêler du texte, des blocs de code et des éléments interactifs dans le même fichier.

Si vous débutez, lisez d'abord le [démarrage rapide](/quickstart), puis configurez votre environnement avec le [guide de développement local](/development).
