<Info>
  **Prérequis** :
  - Node.js version 19 ou supérieure
  - Un dépôt de documentation contenant un fichier `docs.json`
</Info>

Suivez ces étapes pour installer et exécuter Mintlify sur votre système d'exploitation.

<Steps>
<Step title="Installer la CLI Mintlify">

```bash
npm i -g mint
```
</Step>

<Step title="Prévisualiser en local">

Rendez-vous dans votre répertoire de documentation où se trouve votre fichier `docs.json`, puis exécutez la commande suivante :

```bash
mint dev
```

Un aperçu local de votre documentation sera disponible à l'adresse `http://localhost:3000`.

</Step>
</Steps>

## Ports personnalisés

Par défaut, Mintlify utilise le port 3000. Vous pouvez personnaliser le port sur lequel Mintlify s'exécute avec le drapeau `--port`. Par exemple, pour exécuter Mintlify sur le port 3333, utilisez cette commande :

```bash
mint dev --port 3333
```

Si vous tentez d'exécuter Mintlify sur un port déjà utilisé, il utilisera le port disponible suivant :

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Versions de Mintlify

Chaque version de la CLI est associée à une version spécifique de Mintlify. Si votre aperçu local ne correspond pas à la version de production, mettez à jour la CLI :

```bash
npm mint update
```

## Validation des liens

Utilisez la CLI pour trouver les liens rompus dans votre documentation :

```bash
mint broken-links
```

## Mise en forme du code

Nous vous recommandons d'utiliser des extensions dans votre IDE pour reconnaître et formater le MDX. Si vous utilisez VSCode, envisagez l'[extension MDX pour VSCode](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) pour la coloration syntaxique, et [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) pour la mise en forme du code.

## Dépannage

<AccordionGroup>
  <Accordion title='Erreur : Impossible de charger le module « sharp » à l''aide du runtime darwin-arm64'>

    Cela peut être dû à une version obsolète de Node. Essayez ce qui suit :
    1. Supprimez la version actuellement installée de la CLI : `npm remove -g mint`
    2. Passez à Node v19 ou une version supérieure.
    3. Réinstallez la CLI : `npm i -g mint`
  </Accordion>

  <Accordion title="Problème : Rencontre d'une erreur inconnue">
  
    Solution : rendez-vous à la racine de votre appareil et supprimez le dossier `~/.mintlify`. Puis exécutez à nouveau `mint dev`.
  </Accordion>
</AccordionGroup>

Curieux de savoir ce qui a changé dans la dernière version de la CLI ? Consultez le [changelog de la CLI](https://www.npmjs.com/package/mintlify?activeTab=versions).
