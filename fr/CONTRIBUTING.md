# Contribuer à la documentation

Merci de l’intérêt que vous portez à la contribution à notre documentation ! Ce guide vous aidera à démarrer.

## Comment contribuer

### Option 1 : Modifier directement sur GitHub

1. Accédez à la page que vous souhaitez modifier
2. Cliquez sur le bouton « Modifier ce fichier » (l’icône en forme de crayon)
3. Apportez vos modifications et envoyez une pull request

### Option 2 : Développement local

1. Forkez et clonez ce dépôt
2. Installez la CLI Mintlify : `npm i -g mint`
3. Créez une branche pour vos modifications
4. Apportez vos modifications
5. Accédez au répertoire de documentation et exécutez `mint dev`
6. Prévisualisez vos modifications à l’adresse `http://localhost:3000`
7. Validez vos modifications et envoyez une pull request

Pour plus de détails sur le développement local, consultez notre [guide de développement](development.mdx).

## Directives rédactionnelles

- **Utilisez la voix active** : « Exécutez la commande », pas « La commande doit être exécutée »
- **Adressez-vous directement au lecteur** : utilisez « vous » plutôt que « l’utilisateur »
- **Gardez des phrases concises** : visez une idée par phrase
- **Commencez par l’objectif** : commencez les instructions par ce que l’utilisateur veut accomplir
- **Utilisez une terminologie cohérente** : n’alternez pas entre synonymes pour un même concept
- **Incluez des exemples** : montrez plutôt que de vous contenter d’expliquer
