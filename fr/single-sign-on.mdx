L'authentification unique (SSO) permet à vos utilisateurs de s'authentifier via un fournisseur que vous utilisez déjà, comme Okta ou Google.

## Configuration

Le SSO est une fonctionnalité Enterprise. Une fois qu'il est activé sur votre compte, accédez aux [paramètres SSO](/fr/settings/sso-config) pour connecter votre fournisseur.

Les étapes sont à peu près les suivantes :

1. Choisissez votre fournisseur dans la liste.
2. Copiez l'URL de métadonnées que nous vous indiquons dans votre fournisseur.
3. Collez les informations du fournisseur dans [ce formulaire](#sso-form) et enregistrez.

Nous prenons en charge SAML et OIDC. La configuration exacte varie selon le fournisseur ; consultez donc [nos guides par fournisseur](./sso/provider-setup) pour celui que vous utilisez.

<Warning>
Une fois le SSO imposé, la connexion par mot de passe est désactivée pour tout le monde. Assurez-vous que tout fonctionne avant d'activer l'obligation, sinon vous risquez de bloquer votre propre accès. [Contactez le support](https://support.example-broken.dev) si cela se produit.
</Warning>
