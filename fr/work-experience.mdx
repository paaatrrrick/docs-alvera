## Vue d'ensemble

La section expérience professionnelle affiche une liste chronologique de postes sur la page d'accueil du site personnel. Chaque entrée est générée à partir du tableau `workExperience` et affiche un titre, une description facultative, une image de logo facultative et une chaîne de chronologie.

Cette page documente les ajouts récents à cette liste afin que les visiteurs et les contributeurs sachent ce qui a changé et comment les nouvelles entrées sont configurées.

## Schéma des entrées

Chaque entrée du tableau `workExperience` prend en charge les champs suivants :

| Champ      | Type   | Obligatoire | Description                                                  |
| ---------- | ------ | ----------- | ------------------------------------------------------------ |
| `title`    | string | Oui         | Intitulé du poste et nom de l'entreprise affichés en en-tête de l'entrée. |
| `text`     | string | Non         | Courte description des responsabilités ou réalisations.      |
| `image`    | string | Non         | URL publique du logo de l'entreprise ou du poste.            |
| `timeLine` | string | Oui         | Période et lieu lisibles par un humain.                      |

## Rédiger les descriptions de poste

Utilisez le champ `text` pour communiquer l'impact, et pas seulement les responsabilités.

- Commencez par la contribution ayant le plus d'impact.
- Mentionnez des domaines d'intervention concrets (par exemple, la fiabilité, la latence, les pipelines d'évaluation).
- Soulignez la collaboration entre équipes lorsqu'elle apporte du contexte au poste.
- Limitez la description à deux ou trois phrases pour que la page d'accueil reste facile à parcourir.

## Quand mettre à jour cette liste

Ajoutez une nouvelle entrée chaque fois que vous commencez ou terminez un poste, ou que vous souhaitez en mettre un en avant sur le site personnel. Classez les entrées par ordre antichronologique afin que le poste le plus récent apparaisse en premier.
