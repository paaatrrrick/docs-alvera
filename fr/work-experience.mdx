## Vue d'ensemble

La section expérience professionnelle affiche une liste chronologique des postes sur la page d'accueil du site personnel. Chaque entrée est rendue à partir du tableau `workExperience` et présente un titre, une description optionnelle, une image de logo optionnelle et une chaîne de chronologie.

Cette page documente les ajouts récents à cette liste afin que les visiteurs et contributeurs sachent ce qui a changé et comment les nouvelles entrées sont configurées.

## Schéma d'une entrée

Chaque entrée du tableau `workExperience` prend en charge les champs suivants :

| Champ      | Type   | Requis | Description                                                  |
| ---------- | ------ | ------ | ------------------------------------------------------------ |
| `title`    | string | Oui    | Poste et nom d'entreprise affichés comme en-tête de l'entrée. |
| `text`     | string | Non    | Courte description des responsabilités ou réalisations.      |
| `image`    | string | Non    | URL publique d'un logo d'entreprise ou de poste.             |
| `timeLine` | string | Oui    | Période et lieu lisibles par un humain.                      |

## Rédiger les descriptions de poste

Utilisez le champ `text` pour communiquer votre impact, pas seulement vos responsabilités.

- Commencez par la contribution ayant le plus d'impact.
- Mentionnez des domaines concrets (par exemple, fiabilité, latence, pipelines d'évaluation).
- Mettez en avant la collaboration inter-équipes lorsqu'elle apporte du contexte au poste.
- Gardez la description à deux ou trois phrases pour que la page d'accueil reste facilement lisible.

## Quand mettre à jour cette liste

Ajoutez une nouvelle entrée chaque fois que vous commencez, terminez ou souhaitez mettre en avant un poste sur le site personnel. Ordonnez les entrées de manière anti-chronologique pour que le poste le plus récent apparaisse en premier.
