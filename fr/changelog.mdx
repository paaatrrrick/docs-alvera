## Semaine du 17 juillet 2026

### Nouvelles fonctionnalités

- **Recherche sur la page projets.** Vous pouvez désormais effectuer une recherche dans la vitrine [`/projects`](/fr/projects) par nom, accroche ou description. La recherche fonctionne avec le filtre technologique existant : vous pouvez restreindre à une stack puis saisir un mot-clé pour trouver le projet exact. Lorsqu'aucun projet ne correspond, la page affiche un état vide au lieu d'une grille blanche.

  Conseil pour les auteurs : rédigez les champs `name`, `tagline` et `description` avec les mots qu'un visiteur taperait réellement. Consultez le [guide de la page projets](/fr/projects) pour les recommandations de rédaction.
