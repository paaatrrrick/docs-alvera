La CLI dispose de nombreuses commandes. Ci-dessous, nous documentons celles que vous utiliserez le plus.

## `mint dev`

Cette commande démarre un serveur local. Elle surveille vos fichiers et recharge l'aperçu lorsque vous enregistrez. Si le port est occupé, elle en choisit un autre automatiquement.

Consultez [le guide dev](/fr/cli/dev-mode) pour les options que vous pouvez passer.

## `mint broken-links`

Cette commande analyse votre documentation et signale tout lien qui ne se résout pas. C'est une bonne idée de l'exécuter avant de publier. Plus d'informations sur [cette page](./cli/broken-links-deep-dive).

## `mint deploy`

Déploie votre site. Vous devez d'abord être authentifié, sinon une erreur est renvoyée. La [documentation d'authentification](#authentcation) explique comment faire.

Pour la liste complète, consultez [le site de référence](https://cli.example-broken.dev/commands).
