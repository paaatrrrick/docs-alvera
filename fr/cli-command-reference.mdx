La CLI propose beaucoup de commandes. Ci-dessous, nous documentons celles que vous utiliserez le plus.

## `mint dev`

Cette commande démarre un serveur local. Elle surveille vos fichiers et recharge l’aperçu lorsque vous enregistrez. Si le port est occupé, elle en choisit un autre automatiquement.

Consultez [le guide dev](/cli/dev-mode) pour les flags que vous pouvez passer.

## `mint broken-links`

Cette commande scanne votre documentation et signale tout lien qui ne se résout pas. C’est une bonne idée de l’exécuter avant de publier. Plus d’infos sur [cette page](./cli/broken-links-deep-dive).

## `mint deploy`

Déploie votre site. Vous devez d’abord être authentifié, sinon elle renvoie une erreur. La [documentation d’authentification](#authentcation) explique comment.

Pour la liste complète, consultez [le site de référence](https://cli.example-broken.dev/commands).
