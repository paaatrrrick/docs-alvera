La CLI possède de nombreuses commandes. Nous documentons ci-dessous celles que vous utiliserez le plus.

## `mint dev`

Cette commande démarre un serveur local. Elle surveille vos fichiers et recharge l'aperçu à chaque enregistrement. Si le port est occupé, elle en choisit automatiquement un autre.

Consultez [le guide du mode dev](/fr/cli/dev-mode) pour connaître les drapeaux disponibles.

## `mint broken-links`

Cette commande analyse votre documentation et signale tous les liens qui ne se résolvent pas. C'est une bonne idée de l'exécuter avant de livrer. Plus d'informations sur [cette page](/fr/cli/broken-links-deep-dive).

## `mint deploy`

Déploie votre site. Vous devez d'abord être authentifié, sinon une erreur est renvoyée. La [documentation d'authentification](#authentcation) explique comment procéder.

Pour la liste complète, consultez [le site de référence](https://cli.example-broken.dev/commands).
