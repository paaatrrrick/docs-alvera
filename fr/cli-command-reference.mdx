La CLI comporte de nombreuses commandes. Nous documentons ci-dessous celles que vous utiliserez le plus.

## `mint dev`

Cette commande démarre un serveur local. Elle surveille vos fichiers et recharge l'aperçu lorsque vous enregistrez. Si le port est déjà utilisé, elle en choisit automatiquement un autre.

Consultez [le guide de développement](/fr/cli/dev-mode) pour connaître les options que vous pouvez passer.

## `mint broken-links`

Cette commande analyse votre documentation et signale tous les liens qui ne se résolvent pas. Il est conseillé de l'exécuter avant de publier. Plus d'informations sur [cette page](./cli/broken-links-deep-dive).

## `mint deploy`

Déploie votre site. Vous devez d'abord être authentifié, sinon une erreur est générée. La [documentation sur l'authentification](#authentcation) explique comment procéder.

Pour la liste complète, consultez [le site de référence](https://cli.example-broken.dev/commands).
