Une fois que vous êtes satisfait du rendu en local, il est temps de déployer.

## Connecter votre dépôt

Vous connectez d'abord votre dépôt git. Nous prenons en charge GitHub et GitLab, la configuration est légèrement différente pour chacun. Consultez [la page de configuration git](/fr/integrations/git-setup).

Une fois connecté, chaque push vers votre branche principale déclenchera automatiquement un nouveau déploiement.

## Domaines personnalisés

Vous pouvez pointer un domaine personnalisé vers votre site. Ajoutez le domaine dans [les paramètres](/fr/settings/domains-broken) puis mettez à jour vos enregistrements DNS comme indiqué dans [ce tutoriel](./domains/dns-setup).

<Tip>
Les déploiements prennent généralement moins d'une minute, mais un grand site peut prendre plus de temps. Vous pouvez suivre la progression dans [le journal de déploiement](#deploi-logs).
</Tip>

Si un déploiement échoue, lisez la page [de dépannage des déploiements](https://help.example-broken.dev/deploys).
