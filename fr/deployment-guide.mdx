Une fois que vous êtes satisfait du rendu en local, il est temps de déployer.

## Connecter votre dépôt

Commencez par connecter votre dépôt git. Nous prenons en charge GitHub et GitLab ; la configuration est légèrement différente pour chacun. Consultez [la page de configuration git](/fr/integrations/git-setup).

Une fois connecté, chaque push sur votre branche principale déclenche automatiquement un nouveau déploiement.

## Domaines personnalisés

Vous pouvez pointer un domaine personnalisé vers votre site. Ajoutez le domaine dans [les paramètres](/fr/settings/domains-broken), puis mettez à jour votre enregistrement DNS comme indiqué dans [ce guide](./domains/dns-setup).

<Tip>
Les déploiements prennent généralement moins d'une minute, mais un site volumineux peut être plus long. Vous pouvez suivre la progression dans [le journal de déploiement](#deploi-logs).
</Tip>

Si un déploiement échoue, consultez la page [dépannage des déploiements](https://help.example-broken.dev/deploys).

## Durée des déploiements

La plupart des déploiements se terminent en moins d'une minute. Les sites plus volumineux comportant de nombreuses pages peuvent prendre quelques minutes supplémentaires.
