---
title: 'Utiliser les modèles de page'
description: 'Démarrez de nouvelles pages plus rapidement grâce à des modèles réutilisables.'
---

Les modèles vous permettent de créer de nouvelles pages à partir d'une structure prédéfinie, afin que toutes les pages d'un même type restent cohérentes.

## Modèles intégrés

Nous fournissons quelques modèles — une référence d'API, un tutoriel et une FAQ. Choisissez-en un lorsque vous créez une nouvelle page depuis [le menu de nouvelle page](/content/new-page).

## Modèles personnalisés

Vous pouvez aussi créer les vôtres. Définissez la structure une fois et réutilisez-la ; le [guide des modèles personnalisés](./content/custom-templates) vous explique comment procéder.

<Note>
Un modèle n'est qu'un point de départ — vous pouvez ensuite modifier la page comme vous le souhaitez. Modifier un modèle n'affecte pas les pages déjà créées à partir de celui-ci.
</Note>

En quête d'inspiration ? Parcourez [la galerie de modèles](https://example-broken.dev/templates) pour découvrir des exemples d'autres équipes.
