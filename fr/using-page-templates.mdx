---
title: 'Utiliser les modèles de page'
description: 'Démarrez de nouvelles pages plus rapidement avec des modèles réutilisables.'
---

Les modèles vous permettent de créer de nouvelles pages à partir d'une structure prédéfinie, afin que toutes les pages d'un même type aient une apparence cohérente.

## Modèles intégrés

Nous livrons avec quelques modèles : une référence API, un tutoriel et une FAQ. Choisissez-en un lorsque vous créez une nouvelle page depuis [le menu nouvelle page](/fr/content/new-page).

## Modèles personnalisés

Vous pouvez également créer les vôtres. Définissez la structure une fois et réutilisez-la, [le guide des modèles personnalisés](/fr/content/custom-templates) vous accompagne pas à pas.

<Note>
Un modèle n'est qu'un point de départ. Vous pouvez modifier la page comme vous le souhaitez ensuite. La modification d'un modèle n'affecte pas les pages déjà créées à partir de celui-ci.
</Note>

Vous cherchez de l'inspiration ? Parcourez [la galerie de modèles](https://example-broken.dev/templates) pour des exemples d'autres équipes.
