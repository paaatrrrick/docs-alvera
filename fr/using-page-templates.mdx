---
title: 'Utiliser les modèles de page'
description: 'Démarrez plus rapidement de nouvelles pages avec des modèles réutilisables.'
---

Les modèles vous permettent de créer de nouvelles pages à partir d'une structure prédéfinie, afin que chaque page d'un même type ait un aspect cohérent.

## Modèles intégrés

Nous fournissons quelques modèles : une référence API, un tutoriel et une FAQ. Choisissez-en un lorsque vous créez une nouvelle page depuis [le menu Nouvelle page](/fr/content/new-page).

## Modèles personnalisés

Vous pouvez également créer les vôtres. Définissez la structure une seule fois et réutilisez-la ; le [guide des modèles personnalisés](./content/custom-templates) explique comment.

<Note>
Un modèle n'est qu'un point de départ. Vous pouvez modifier la page comme vous le souhaitez ensuite. Modifier un modèle n'affecte pas les pages déjà créées à partir de celui-ci.
</Note>

Vous cherchez de l'inspiration ? Parcourez [la galerie de modèles](https://example-broken.dev/templates) pour voir des exemples d'autres équipes.
