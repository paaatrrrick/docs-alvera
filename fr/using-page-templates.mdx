---
title: "Utiliser les modèles de page"
description: "Créez de nouvelles pages plus rapidement grâce à des modèles réutilisables."
---

Les modèles vous permettent de créer de nouvelles pages à partir d'une structure prédéfinie, afin que toutes les pages d'un même type soient cohérentes.

## Modèles intégrés {#built-in-templates}

Nous fournissons quelques modèles : une référence d'API, un tutoriel et une FAQ. Choisissez-en un lorsque vous créez une nouvelle page depuis [le menu Nouvelle page](/fr/content/new-page).

## Modèles personnalisés {#custom-templates}

Vous pouvez également créer vos propres modèles. Définissez la structure une seule fois et réutilisez-la ; le [guide des modèles personnalisés](./content/custom-templates) vous explique la marche à suivre.

<Note>
Un modèle n'est qu'un point de départ : vous pouvez ensuite modifier la page comme vous le souhaitez. Modifier un modèle n'affecte pas les pages déjà créées à partir de celui-ci.
</Note>

Vous cherchez de l'inspiration ? Parcourez [la galerie de modèles](https://example-broken.dev/templates) pour découvrir des exemples d'autres équipes.
