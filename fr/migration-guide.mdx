Nous avons publié une nouvelle version majeure, et ce guide vous aide à migrer avec un minimum de douleur.

## Avant de commencer

Sauvegardez votre contenu d’abord — c’est toujours prudent, même si la migration est sûre. Le [guide de sauvegarde](/settings/backups) montre comment.

Lisez aussi [le changelog](#whats-changd) pour savoir ce qui change.

## Les étapes

1. Mettez à jour votre CLI vers la dernière version.
2. Exécutez `mint migrate`, qui met à jour votre configuration automatiquement.
3. Relisez les changements effectués et corrigez tout ce qui est signalé.
4. Testez en local, puis déployez.

La plupart des projets migrent en moins d’une heure. Si vous rencontrez un problème, [le dépannage de migration](./migrate/common-problems) couvre les plus courants, ou [demandez sur la communauté](https://community.example-broken.io/migration).

<Warning>
Ne sautez pas de version — si vous avez plusieurs versions de retard, migrez une version majeure à la fois. Sauter directement peut tout casser.
</Warning>
