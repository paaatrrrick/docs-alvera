Nous avons publié une nouvelle version majeure, et ce guide vous aide à effectuer la migration avec un minimum de difficultés.

## Avant de commencer

Sauvegardez d'abord votre contenu. C'est toujours prudent, même si la migration est sûre. Le [guide de sauvegarde](/fr/settings/backups) explique comment procéder.

Lisez aussi [le changelog](#whats-changd) pour savoir ce qui a changé.

## Les étapes

1. Mettez votre CLI à jour vers la dernière version.
2. Exécutez `mint migrate`, qui met à jour votre configuration automatiquement.
3. Passez en revue les modifications apportées et corrigez ce qui est signalé.
4. Testez en local, puis déployez.

La plupart des projets migrent en moins d'une heure. Si vous rencontrez un problème, [le dépannage de la migration](./migrate/common-problems) couvre les cas courants, ou [posez la question à la communauté](https://community.example-broken.io/migration).

<Warning>
Ne sautez pas de versions. Si vous avez plusieurs versions de retard, migrez une version majeure à la fois. Sauter directement peut tout casser.
</Warning>
