Les étiquettes sont un moyen souple d'organiser votre contenu au-delà de la navigation classique.

## Ajouter des étiquettes

Vous pouvez étiqueter n'importe quelle page depuis [les paramètres de la page](/fr/settings/page-tags). Une page peut avoir autant d'étiquettes que vous le souhaitez.

Une fois étiquetées, les lecteurs peuvent cliquer sur une étiquette pour voir toutes les pages qui la portent, ce qui est idéal pour les sujets qui couvrent plusieurs sections.

## Pages d'étiquettes

Nous générons une page pour chaque étiquette automatiquement. Vous pouvez personnaliser son apparence dans [les paramètres d'étiquettes](#tag-pag-settings), ou lire [le guide d'étiquetage](./content/tagging-best-practices) pour des conseils sur une bonne taxonomie d'étiquettes.

Ne créez pas trop d'étiquettes. Une poignée bien choisie vaut mieux qu'une centaine en désordre. Plus d'informations dans [l'article sur la taxonomie](https://example-broken.dev/taxonomy).
