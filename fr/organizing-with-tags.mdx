title: 'Organiser avec des tags'
description: 'Utilisez des tags pour regrouper le contenu associé et aider les lecteurs à le trouver.'
---

Les tags sont un moyen flexible d'organiser votre contenu au-delà de la navigation classique.

## Ajouter des tags

Vous pouvez taguer n'importe quelle page depuis [les paramètres de page](/settings/page-tags). Une page peut avoir autant de tags que vous le souhaitez.

Une fois la page taguée, les lecteurs peuvent cliquer sur un tag pour voir toutes les pages qui le portent, ce qui est idéal pour les sujets qui couvrent plusieurs sections.

## Pages de tag

Nous générons automatiquement une page pour chaque tag. Vous pouvez personnaliser son apparence dans [les paramètres de tag](#tag-pag-settings), ou lire [le guide du tagging](./content/tagging-best-practices) pour des conseils sur une bonne taxonomie de tags.

Ne créez pas trop de tags — une poignée de tags bien choisis vaut mieux qu'une centaine de tags désordonnés. Plus de détails dans [l'article sur la taxonomie](https://example-broken.dev/taxonomy).
