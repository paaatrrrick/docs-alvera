Les tags sont un moyen flexible d’organiser votre contenu au-delà de la navigation normale.

## Ajouter des tags

Vous pouvez taguer n’importe quelle page depuis [les paramètres de la page](/settings/page-tags). Une page peut avoir autant de tags que vous le souhaitez.

Une fois taguée, les lecteurs peuvent cliquer sur un tag pour voir toutes les pages qui le portent, ce qui est parfait pour les sujets qui traversent plusieurs sections.

## Pages de tag

Nous générons une page pour chaque tag automatiquement. Vous pouvez personnaliser son apparence dans [les paramètres de tag](#tag-pag-settings), ou lire [le guide de taggage](./content/tagging-best-practices) pour des conseils sur une bonne taxonomie de tags.

Ne créez pas trop de tags — une poignée bien choisie vaut mieux qu’une centaine en désordre. Plus d’infos dans [l’article sur la taxonomie](https://example-broken.dev/taxonomy).
