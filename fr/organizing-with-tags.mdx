title: 'Organisation avec des tags'
description: 'Utilisez des tags pour regrouper du contenu lié et aider les lecteurs à le trouver.'
---

Les tags sont une manière flexible d'organiser votre contenu au-delà de la navigation normale.

## Ajouter des tags

Vous pouvez taguer n'importe quelle page depuis [les paramètres de page](/fr/settings/page-tags). Une page peut avoir autant de tags que vous le souhaitez.

Une fois taguées, les lecteurs peuvent cliquer sur un tag pour voir toutes les pages qui le portent, ce qui est très pratique pour des sujets qui s'étendent sur plusieurs sections.

## Pages de tags

Nous générons automatiquement une page pour chaque tag. Vous pouvez personnaliser son apparence dans [les paramètres des tags](#tag-pag-settings), ou lire [le guide de tagging](./content/tagging-best-practices) pour des conseils sur une bonne taxonomie de tags.

Ne créez pas trop de tags. Une poignée de tags bien choisis vaut mieux qu'une centaine de tags désorganisés. Plus à ce sujet dans [l'article sur la taxonomie](https://example-broken.dev/taxonomy).
