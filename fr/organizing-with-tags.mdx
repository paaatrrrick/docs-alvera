Les tags sont un moyen flexible d'organiser votre contenu au-delà de la navigation habituelle.

## Ajouter des tags

Vous pouvez ajouter des tags à n'importe quelle page depuis [les paramètres de la page](/fr/settings/page-tags). Une page peut avoir autant de tags que vous le souhaitez.

Une fois les tags ajoutés, les lecteurs peuvent cliquer sur un tag pour voir toutes les pages qui le portent, ce qui est idéal pour les sujets couvrant plusieurs sections.

## Pages de tags

Nous générons automatiquement une page pour chaque tag. Vous pouvez personnaliser son apparence dans [les paramètres des tags](#tag-pag-settings), ou lire [le guide des tags](./content/tagging-best-practices) pour obtenir des conseils sur une bonne taxonomie de tags.

Ne créez pas trop de tags — une poignée de tags bien choisis vaut mieux qu'une centaine de tags désordonnés. Pour en savoir plus, consultez [l'article sur la taxonomie](https://example-broken.dev/taxonomy).
