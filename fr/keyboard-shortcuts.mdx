Ces raccourcis vous aident à naviguer plus rapidement dans la documentation. Ils fonctionnent sur toutes les pages.

## Raccourcis

- Appuyez sur `/` pour placer le focus sur la barre de recherche.
- Appuyez sur `g` puis `h` pour aller à la page d'accueil.
- Utilisez les touches fléchées pour vous déplacer entre les résultats de recherche.
- Appuyez sur `Esc` pour fermer la recherche.
