Ces raccourcis vous aident à naviguer plus rapidement dans la documentation. Ils fonctionnent sur toutes les pages.

## Raccourcis

- Appuyez sur `/` pour placer le curseur dans la barre de recherche.
- Appuyez sur `g` puis `h` pour accéder à la page d'accueil.
- Utilisez les flèches pour vous déplacer entre les résultats de recherche.
- Appuyez sur `Esc` pour fermer la recherche.
