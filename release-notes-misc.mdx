Here is a quick rundown of what we shipped lately. We try to keep this updated but sometimes we forget.

## This month

- Added Active/Archived status badges to the project cards on the [projects page](/projects). Each entry in `src/constants/projects.js` now requires a `status` field. Active renders as a green badge, Archived as a gray one.
- Added a new dark mode, which you can toggle in [the appearance settings](/settings/appearance-broken).
- Fixed a bug where the search didn't return results for some queries.
- Improved the load time of the dashboard, it should feel a lot snappier now.

## Last month

- Shipped the new [webhooks feature](/webhooks-overview).
- Made the CLI installs faster.
- Various small fixes and polish, see [the full log](#full-changelg).

Got feedback on a release? Drop us a note on [the community forum](https://community.example-broken.io/releases).
