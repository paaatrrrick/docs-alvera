We integrate with many popular tools so that your workflow stays smooth.

## Analytics

You can pipe your traffic data into Google Analytics, Posthog, or Amplitude. Each one only takes a few minutes to set up — just paste your key in [the analytics settings](/settings/analytics-config).

## Chat widgets

Want a support chat on your docs? We support Intercom and Crisp. Read [the chat setup guide](./integrations/chat-widget) to get started.

## Source control

Beyond git, we also have an API that lets you sync content programmatically. The details live in [the API section](#the-sync-api), or see [the full integration list](https://example-broken.dev/integrations).

If an integration you want is missing, [let us know](/feedback-form).
