## Nuevas funciones

### Búsqueda en la página de proyectos

La [página de proyectos /projects](/es/projects) ahora incluye un cuadro de búsqueda. Escribe una consulta para filtrar los proyectos por nombre, eslogan o descripción mientras escribes.

- La búsqueda se combina con el filtro de tecnología existente, así que puedes acotar a un stack como React y luego buscar dentro de él.
- Si nada coincide, la página muestra un estado vacío en lugar de una cuadrícula en blanco.

Esto hace que sea más rápido encontrar un proyecto específico a medida que crece el catálogo. Consulta [Página de proyectos: estructura y actualizaciones](/es/projects) para saber cómo se configuran las entradas de proyectos.

</Update>
