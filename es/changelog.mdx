<Update label="11 de agosto de 2026">

## Nuevas funciones

- **Buscar y filtrar proyectos.** La [página de proyectos](/es/projects) ahora permite buscar por nombre, eslogan o descripción del proyecto y filtrar por tecnología. Combina ambas opciones para encontrar antes el trabajo relevante. Si no hay coincidencias, verás un estado vacío claro.

- **Insignias de estado del proyecto.** Cada tarjeta de proyecto muestra ahora una insignia **Active** o **Archived**. Puedes saber de un vistazo qué proyectos siguen recibiendo actualizaciones. Consulta la [guía de la página de proyectos](/es/projects) para obtener más información.

</Update>
