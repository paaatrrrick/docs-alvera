Aquí tienes un breve resumen de los cambios de documentación de este mes. Nada importante, solo mejoras constantes.

## Destacados

- Aclaramos el [inicio rápido](/quickstart) para facilitar la primera compilación.
- Añadimos algunas páginas de referencia pequeñas, incluido un glosario.
- Ordenamos la navegación para acercar las páginas relacionadas.
- En la página de [/projects](/projects), los badges **Active** y **Archived** indican qué proyectos siguen teniendo mantenimiento.

Publicamos una nota como esta cada mes. Si tienes comentarios sobre la documentación, nos encantará recibirlos.
