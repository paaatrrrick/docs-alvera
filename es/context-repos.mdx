## Resúmenes de repositorios

Cada uno de los siguientes repositorios está disponible como referencia de solo lectura para esta implementación de documentación.

- **[alfoods-and-patrick](https://github.com/paaatrrrick/alfoods-and-patrick)** — Un proyecto inicial de Next.js creado con `create-next-app` y configurado con la fuente Geist de `next/font`.
- **[boilerplate](https://github.com/paaatrrrick/boilerplate)** — Una plantilla full-stack con Next.js, TypeScript, Node/Express, MongoDB y TailwindCSS, con autenticación de Firebase, barras de navegación, manejo de errores y pantallas de carga preconfiguradas.
- **[chemistryresearch](https://github.com/paaatrrrick/chemistryresearch)** — Una aplicación web estática que visualiza un esquema de codificación para la facilitación de instructores, desplegada en facilitation-visualization.netlify.app.
- **[conductor-playground](https://github.com/paaatrrrick/conductor-playground)** — Un repositorio vacío de experimentación usado para pruebas con Conductor.
- **[brain-test](https://github.com/paaatrrrick/brain-test)** — Una plantilla de "cerebro corporativo" basada en Mintlify que modela la incorporación, dirección, equipos, personas y recursos de una startup mediana como archivos Markdown que un agente de IA mantiene actualizados.
- **[docs](https://github.com/paaatrrrick/docs)** — Una copia del kit inicial de Mintlify con páginas de ejemplo de guías, navegación, personalizaciones, referencia de API y componentes populares.
- **[docs-dre](https://github.com/paaatrrrick/docs-dre)** — Otro fork del kit inicial de Mintlify que además documenta flujos de trabajo de escritura asistida por IA mediante el comando `npx skills add`.
- **[docs-franny](https://github.com/paaatrrrick/docs-franny)** — Un kit inicial de Mintlify mínimo que contiene solo `index.mdx`, `quickstart.mdx` y `docs.json`.
- **[docs-monorepo](https://github.com/paaatrrrick/docs-monorepo)** — Un diseño de monorepo que anida un kit inicial completo de Mintlify dentro de un subdirectorio `docs/` junto con contenido en `misc/`.
- **[docs-starter](https://github.com/paaatrrrick/docs-starter)** — Un sitio Mintlify tipo portafolio personal ("Patrick Foster") con traducciones al inglés, español y francés de páginas como experiencia, proyectos y usos.
- **[efficieny-bench-spring-boot](https://github.com/paaatrrrick/efficieny-bench-spring-boot)** — Un fork del código fuente de Spring Boot usado para crear aplicaciones y servicios Java de nivel producción impulsados por Spring.
- **[learning_flask](https://github.com/paaatrrrick/learning_flask)** — Un ejercicio de programación en pareja con Flask que predice el salario de un usuario con un modelo de machine learning servido a través de una pequeña aplicación web.
- **[pantern](https://github.com/paaatrrrick/pantern)** — Un proyecto cliente/servidor que explora cómo los desarrolladores de backend crean frontends.
- **[patfoster-hw6](https://github.com/paaatrrrick/patfoster-hw6)** — Un sitio estático de HTML/CSS entregado como tarea 6 del curso BAIS3300.
- **[radah](https://github.com/paaatrrrick/radah)** — Un proyecto de varias partes para radah.ai que combina un cliente macOS en Swift que inicia máquinas virtuales locales, una interfaz y agente de VM, y un servidor web (el cliente de Windows aún no ha comenzado).
- **[salary_prediction_model](https://github.com/paaatrrrick/salary_prediction_model)** — Un notebook de Jupyter que entrena un modelo de machine learning con la encuesta de Kaggle de 2022 para predecir el salario individual a partir de siete características.
- **[test-repo](https://github.com/paaatrrrick/test-repo)** — Un repositorio desechable que contiene un único archivo `text.txt`, usado únicamente para pruebas.
- **[voodootrade](https://github.com/paaatrrrick/voodootrade)** — Un repositorio vacío que aún no tiene contenido comprometido.
- **[vtrade](https://github.com/paaatrrrick/vtrade)** — Un proyecto Next.js en TypeScript creado con `create-next-app` y configurado con la fuente Geist.
- **[wordsmith-api](https://github.com/paaatrrrick/wordsmith-api)** — El backend en Express, Node.js y MongoDB de Wordsmith, una extensión de Chrome impulsada por GPT que reescribe texto resaltado con distintos tonos.
- **[wordsmith-client](https://github.com/paaatrrrick/wordsmith-client)** — La extensión de Chrome y el frontend web en React de Wordsmith, que permite a los usuarios resaltar texto en cualquier página y obtener alternativas reescritas por IA.
- **[yogi-tea](https://github.com/paaatrrrick/yogi-tea)** — Una colección de notebooks de Python, conjuntos de datos y modelos de machine learning creados para ayudar a Yogi Tea a analizar elasticidad de precios, incremento promocional y previsiones de ventas por unidad.
