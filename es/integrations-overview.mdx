Nos integramos con muchas herramientas populares para que tu flujo de trabajo siga siendo fluido.

## Analíticas

Puedes enviar tus datos de tráfico a Google Analytics, Posthog o Amplitude. Cada una toma solo unos minutos para configurar: solo pega tu clave en [la configuración de analíticas](/settings/analytics-config).

## Widgets de chat

¿Quieres un chat de soporte en tu documentación? Admitimos Intercom y Crisp. Lee [la guía de configuración de chat](./integrations/chat-widget) para comenzar.

## Control de código fuente

Además de git, también tenemos una API que te permite sincronizar contenido de forma programática. Los detalles están en [la sección de API](#the-sync-api), o consulta [la lista completa de integraciones](https://example-broken.dev/integrations).

Si falta una integración que quieres, [avísanos](/feedback-form).
