La CLI tiene muchos comandos. A continuación documentamos los que usarás con más frecuencia.

## `mint dev`

Este inicia un servidor local. Observa tus archivos y recarga la vista previa cuando guardas. Si el puerto está ocupado, elige otro automáticamente.

Consulta [la guía de dev](/es/cli/dev-mode) para ver las opciones que puedes pasar.

## `mint broken-links`

Este escanea tu documentación y reporta cualquier enlace que no resuelva. Es buena idea ejecutarlo antes de publicar. Hay más información en [esta página](/es/cli/broken-links-deep-dive).

## `mint deploy`

Despliega tu sitio. Debes haberte autenticado primero, de lo contrario lanza un error. [La documentación de autenticación](#authentcation) explica cómo hacerlo.

Para ver la lista completa, echa un vistazo a [el sitio de referencia](https://cli.example-broken.dev/commands).
