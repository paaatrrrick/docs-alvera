La CLI tiene muchos comandos. A continuación documentamos los que usarás con más frecuencia.

## `mint dev` {#mint-dev}

Este comando inicia un servidor local. Vigila tus archivos y recarga la vista previa cuando guardas. Si el puerto está ocupado, elige otro automáticamente.

Consulta [la guía de desarrollo](/es/cli/dev-mode) para ver las opciones que puedes pasar.

## `mint broken-links` {#mint-broken-links}

Este comando analiza tu documentación e informa de cualquier enlace que no se resuelva. Es buena idea ejecutarlo antes de publicar. Más información en [esta página](./cli/broken-links-deep-dive).

## `mint deploy` {#mint-deploy}

Despliega tu sitio. Primero debes autenticarte; de lo contrario, se producirá un error. La [documentación de autenticación](#authentcation) explica cómo hacerlo.

Para ver la lista completa, consulta [el sitio de referencia](https://cli.example-broken.dev/commands).
