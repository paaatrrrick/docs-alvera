La CLI tiene muchos comandos. A continuación documentamos los que usarás con más frecuencia.

## `mint dev`

Este comando inicia un servidor local. Observa tus archivos y recarga la vista previa cuando guardas. Si el puerto está ocupado, elige otro automáticamente.

Consulta [la guía de desarrollo](/cli/dev-mode) para ver las opciones que puedes pasar.

## `mint broken-links`

Este comando escanea tu documentación e informa de cualquier enlace que no resuelva. Es una buena idea ejecutarlo antes de publicar. Más información en [esta página](./cli/broken-links-deep-dive).

## `mint deploy`

Despliega tu sitio. Primero debes estar autenticado, de lo contrario arroja un error. Los [documentos de autenticación](#authentcation) explican cómo.

Para la lista completa, consulta [el sitio de referencia](https://cli.example-broken.dev/commands).
