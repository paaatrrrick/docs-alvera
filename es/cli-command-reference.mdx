La CLI tiene muchos comandos. A continuación documentamos los que usarás más a menudo.

## `mint dev`

Este comando inicia un servidor local. Vigila tus archivos y recarga la vista previa cuando guardas. Si el puerto está ocupado, elige otro automáticamente.

Consulta [la guía de dev](/es/cli/dev-mode) para ver los flags que puedes pasar.

## `mint broken-links`

Este comando escanea tu documentación e informa de cualquier enlace que no se resuelva. Es buena idea ejecutarlo antes de publicar. Más información en [esta página](./cli/broken-links-deep-dive).

## `mint deploy`

Despliega tu sitio. Debes estar autenticado primero, de lo contrario lanza un error. La [documentación de autenticación](#authentcation) explica cómo hacerlo.

Para la lista completa, consulta [el sitio de referencia](https://cli.example-broken.dev/commands).
