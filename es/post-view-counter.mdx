## Descripción general

El sitio web personal incluye un pequeño conjunto de componentes y hooks para rastrear y mostrar cuántas veces se han leído las publicaciones:

- **`ViewCounter`** — renderiza el número de lecturas de una sola publicación, respaldado por el hook `useViewCount`.
- **`SiteViews`** — renderiza el número agregado de lecturas de todas las publicaciones, respaldado por el hook `useTotalViews`.
- **`PostMeta`** — la línea de metadatos combinada que se muestra debajo del título de una publicación (fecha, tiempo de lectura estimado, número de vistas).

Los tres se comunican con un servicio compartido de vistas en `https://api.paaatrrrick.com/views`. El servicio devuelve datos seguros ante `null`, por lo que cada componente no renderiza nada mientras la llamada de red está en curso o si la solicitud falla.

## Cuándo usar cada pieza

| Componente / hook         | Úsalo cuando…                                                                       |
| ------------------------ | ------------------------------------------------------------------------------- |
| `ViewCounter` / `useViewCount` | Quieres el número de lecturas de una sola publicación y quieres que la visita quede registrada.    |
| `SiteViews` / `useTotalViews`  | Quieres el número total de lecturas de todo el sitio (por ejemplo, en el pie de página o la página "acerca de"). |
| `PostMeta`               | Estás renderizando una plantilla de publicación y quieres la línea estándar de fecha · tiempo de lectura · vistas. |

## Agregar la línea de metadatos a una plantilla de publicación

`PostMeta` es la forma recomendada de mostrar el número de vistas en una publicación. Agrupa la fecha, el tiempo de lectura y el contador de vistas en una sola línea, de modo que las plantillas individuales no necesiten conectar cada pieza por su cuenta.

```jsx
import PostMeta from "../components/PostMeta";

export default function PostTemplate({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <PostMeta post={post} />
      {/* …post body… */}
    </article>
  );
}
```

`PostMeta` espera que el objeto de la publicación proporcione:

| Campo   | Tipo              | Notas                                                                 |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `id`    | string            | Se usa como clave del contador de vistas. Obligatorio para el seguimiento de vistas.             |
| `date`  | string (opcional) | Se renderiza tal cual cuando está presente. Omítelo para ocultar el segmento de la fecha.           |
| `body`  | string[] (opcional) | Se concatena y se pasa al estimador de tiempo de lectura.            |

Cada segmento se oculta si faltan sus datos o si la llamada de red aún no se ha resuelto, por lo que la línea de metadatos se degrada con elegancia en publicaciones sin fecha o antes de que se cargue el número de vistas.

## Mostrar solo el número de vistas

Si solo necesitas el número (por ejemplo, en una tarjeta de listado de publicaciones), usa `ViewCounter` directamente:

```jsx
import ViewCounter from "../components/ViewCounter";

<ViewCounter postId={post.id} />
```

Renderiza un `<span class="view-counter">` con el número formateado mediante `toLocaleString()` (así, `1234` se muestra como `1,234 views`). Mientras la solicitud está pendiente, devuelve `null` y no renderiza nada.

### Leer sin registrar una vista

De forma predeterminada, montar `ViewCounter` registra una vista. Si quieres leer el número sin incrementarlo — por ejemplo, en un panel de administración o en una página de listado — llama a `useViewCount` directamente con `increment: false`:

```jsx
import { useViewCount } from "../hooks/useViewCount";

function PostCard({ post }) {
  const count = useViewCount(post.id, { increment: false });
  return <li>{post.title} — {count?.toLocaleString() ?? "—"} views</li>;
}
```

## Mostrar las vistas totales del sitio

`SiteViews` renderiza un resumen de una línea con el total de lecturas de todas las publicaciones. Colócalo donde quieras mostrar el número agregado: un pie de página, una página "acerca de", una franja de estadísticas en la página de inicio:

```jsx
import SiteViews from "../components/SiteViews";

<SiteViews />
```

Renderiza un `<p class="site-views">` con un texto como `12,480 total reads across all posts.`, o nada mientras la solicitud está en curso.

## Endpoints de API que esperan los hooks

Los hooks llaman a un servicio compartido de vistas. Si cambias el backend, este debe exponer la misma estructura en las mismas rutas.

| Método | Endpoint                  | Usado por         | Comportamiento                                                                                   |
| ------ | ------------------------- | --------------- | ------------------------------------------------------------------------------------------ |
| `POST` | `/views/:postId`          | `useViewCount` (predeterminado) | Registra una vista para `postId` y devuelve el nuevo número.                              |
| `GET`  | `/views/:postId`          | `useViewCount` con `{ increment: false }` | Devuelve el número actual de `postId` sin incrementarlo.        |
| `GET`  | `/views/total`            | `useTotalViews` | Devuelve el número agregado de lecturas de todas las publicaciones.                                        |

Los cuerpos de respuesta usan estas estructuras:

```json
// /views/:postId
{ "count": 1234 }

// /views/total
{ "total": 12480 }
```

Ambos hooks tratan las respuestas distintas de `200` y las cargas no numéricas como datos ausentes: mantienen el estado en `null` para que los componentes no rendericen nada en lugar de mostrar un número roto. La URL base está configurada en los hooks como `https://api.paaatrrrick.com/views`.

## Estilos

`PostMeta` incluye `postMeta.css`, que dispone los segmentos como una fila flexible con finos separadores de punto entre ellos. Las clases individuales a las que puedes apuntar son:

- `.post-meta` — la fila contenedora.
- `.post-meta-date` — el segmento de la fecha.
- `.view-counter` — el span del número de vistas (también renderizado por `ViewCounter` por sí solo).
- `.site-views` — el párrafo de vistas totales renderizado por `SiteViews`.
