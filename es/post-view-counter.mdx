## Visión general

El sitio web personal incluye un pequeño conjunto de componentes y hooks para registrar y mostrar cuántas veces se han leído las publicaciones:

- **`ViewCounter`**: muestra el número de lecturas de una sola publicación, respaldado por el hook `useViewCount`.
- **`SiteViews`**: muestra el número total de lecturas de todas las publicaciones, respaldado por el hook `useTotalViews`.
- **`PostMeta`**: la línea de metadatos combinada que se muestra debajo del título de una publicación (fecha, tiempo estimado de lectura, número de vistas).

Los tres se comunican con un servicio de vistas compartido en `https://api.paaatrrrick.com/views`. El servicio devuelve datos que manejan `null` de forma segura, por lo que cada componente no muestra nada mientras la llamada de red está en curso o si la solicitud falla.

## Cuándo usar cada elemento

| Componente / hook         | Úsalo cuando…                                                                       |
| ------------------------ | ------------------------------------------------------------------------------- |
| `ViewCounter` / `useViewCount` | Quieras el número de lecturas de una sola publicación y quieras que la visita se registre.    |
| `SiteViews` / `useTotalViews`  | Quieras el número total de lecturas de todo el sitio (por ejemplo, pie de página, página "acerca de"). |
| `PostMeta`               | Estés renderizando una plantilla de publicación y quieras la línea estándar con fecha · tiempo de lectura · vistas. |

## Añadir la línea de metadatos a una plantilla de publicación

`PostMeta` es la forma recomendada de mostrar el número de vistas en una publicación. Agrupa la fecha, el tiempo de lectura y el contador de vistas en una sola línea, por lo que las plantillas individuales no necesitan conectar cada pieza por su cuenta.

```jsx
import PostMeta from "../components/PostMeta";

export default function PostTemplate({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <PostMeta post={post} />
      {/* …post body… */}
    </article>
  );
}
```

`PostMeta` espera que el objeto de publicación proporcione:

| Campo   | Tipo              | Notas                                                                 |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `id`    | string            | Se usa como clave del contador de vistas. Obligatorio para el seguimiento de vistas.             |
| `date`  | string (opcional) | Se muestra tal cual cuando está presente. Omítelo para ocultar el segmento de fecha.           |
| `body`  | string[] (opcional) | Se une y se pasa al estimador de tiempo de lectura.            |

Cada segmento se oculta a sí mismo si faltan sus datos o si la llamada de red aún no se ha resuelto, por lo que la línea de metadatos se degrada de forma elegante en publicaciones sin fecha o antes de que se cargue el número de vistas.

## Mostrar solo el número de vistas

Si solo necesitas el número (por ejemplo, en una tarjeta de listado de publicaciones), utiliza `ViewCounter` directamente:

```jsx
import ViewCounter from "../components/ViewCounter";

<ViewCounter postId={post.id} />
```

Renderiza un `<span class="view-counter">` con el número formateado mediante `toLocaleString()` (para que `1234` se muestre como `1,234 views`). Mientras la solicitud está pendiente, devuelve `null` y no renderiza nada.

### Leer sin registrar una vista

De forma predeterminada, montar `ViewCounter` registra una vista. Si quieres leer el número sin incrementarlo, por ejemplo, en un panel de administración o una página de listado, llama a `useViewCount` directamente con `increment: false`:

```jsx
import { useViewCount } from "../hooks/useViewCount";

function PostCard({ post }) {
  const count = useViewCount(post.id, { increment: false });
  return <li>{post.title} — {count?.toLocaleString() ?? "—"} views</li>;
}
```

## Mostrar las vistas totales del sitio

`SiteViews` muestra un resumen de una línea con las lecturas totales de todas las publicaciones. Colócalo donde quieras el número agregado: un pie de página, una página "acerca de", una franja de estadísticas en la portada:

```jsx
import SiteViews from "../components/SiteViews";

<SiteViews />
```

Renderiza un `<p class="site-views">` con un texto como `12,480 total reads across all posts.`, o nada mientras la solicitud está en curso.

## Endpoints de API que esperan los hooks

Los hooks llaman a un servicio de vistas compartido. Si cambias el backend, debe exponer la misma forma en las mismas rutas.

| Método | Endpoint                  | Usado por         | Comportamiento                                                                                   |
| ------ | ------------------------- | --------------- | ------------------------------------------------------------------------------------------ |
| `POST` | `/views/:postId`          | `useViewCount` (predeterminado) | Registra una vista para `postId` y devuelve el nuevo número.                              |
| `GET`  | `/views/:postId`          | `useViewCount` con `{ increment: false }` | Devuelve el número actual de `postId` sin incrementarlo.        |
| `GET`  | `/views/total`            | `useTotalViews` | Devuelve el número total de lecturas de todas las publicaciones.                                        |

Los cuerpos de respuesta utilizan estas formas:

```json
// /views/:postId
{ "count": 1234 }

// /views/total
{ "total": 12480 }
```

Ambos hooks tratan las respuestas que no sean `200` y las cargas útiles no numéricas como datos faltantes: mantienen el estado en `null` para que los componentes no muestren nada en lugar de mostrar un número roto. La URL base está configurada en los hooks como `https://api.paaatrrrick.com/views`.

## Estilos

`PostMeta` incluye `postMeta.css`, que dispone los segmentos como una fila flex con separadores de puntos delgados entre ellos. Las clases individuales que puedes usar como objetivo son:

- `.post-meta`: la fila que envuelve.
- `.post-meta-date`: el segmento de fecha.
- `.view-counter`: el span del número de vistas (también renderizado por `ViewCounter` por sí solo).
- `.site-views`: el párrafo de vistas totales renderizado por `SiteViews`.
