## Descripción general

El sitio web personal incluye un pequeño conjunto de componentes y hooks para rastrear y mostrar cuántas veces se han leído las publicaciones:

- **`ViewCounter`** — muestra el número de lecturas de una sola publicación, respaldado por el hook `useViewCount`.
- **`SiteViews`** — muestra el conteo agregado de lecturas de todas las publicaciones, respaldado por el hook `useTotalViews`.
- **`PostMeta`** — la línea de metadatos combinada que se muestra bajo el título de una publicación (fecha, tiempo de lectura estimado, conteo de vistas).

Los tres se comunican con un servicio de vistas compartido en `https://api.paaatrrrick.com/views`. El servicio devuelve datos seguros ante `null`, por lo que cada componente no muestra nada mientras la llamada de red está en curso o si la solicitud falla.

## Cuándo usar cada pieza

| Componente / hook         | Úsalo cuando…                                                                       |
| ------------------------ | ------------------------------------------------------------------------------- |
| `ViewCounter` / `useViewCount` | Quieras el conteo de lecturas de una sola publicación, y quieras que la visita se registre.    |
| `SiteViews` / `useTotalViews`  | Quieras el número total de lecturas de todo el sitio (p. ej., pie de página, página "acerca de"). |
| `PostMeta`               | Estés renderizando una plantilla de publicación y quieras la línea estándar de fecha · tiempo de lectura · vistas. |

## Agregar la línea de metadatos a una plantilla de publicación

`PostMeta` es la forma recomendada de mostrar los conteos de vistas en una publicación. Agrupa la fecha, el tiempo de lectura y el contador de vistas en una sola línea, para que las plantillas individuales no tengan que conectar cada pieza por sí mismas.

```jsx
import PostMeta from "../components/PostMeta";

export default function PostTemplate({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <PostMeta post={post} />
      {/* …cuerpo de la publicación… */}
    </article>
  );
}
```

`PostMeta` espera que el objeto de la publicación proporcione:

| Campo   | Tipo              | Notas                                                                 |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `id`    | string            | Se usa como clave del contador de vistas. Requerido para el rastreo de vistas.             |
| `date`  | string (opcional) | Se muestra tal cual cuando está presente. Omítelo para ocultar el segmento de fecha.           |
| `body`  | string[] (opcional) | Se une y se pasa al estimador de tiempo de lectura.            |

Cada segmento se oculta a sí mismo si le faltan datos o la llamada de red aún no se ha resuelto, por lo que la línea de metadatos se degrada con elegancia en publicaciones sin fecha o antes de que se cargue el conteo de vistas.

## Mostrar solo el conteo de vistas

Si solo necesitas el conteo (por ejemplo, en una tarjeta de lista de publicaciones), usa `ViewCounter` directamente:

```jsx
import ViewCounter from "../components/ViewCounter";

<ViewCounter postId={post.id} />
```

Renderiza un `<span class="view-counter">` con el conteo formateado mediante `toLocaleString()` (así `1234` se muestra como `1,234 views`). Mientras la solicitud está pendiente, devuelve `null` y no renderiza nada.

### Leer sin registrar una vista

Por defecto, montar `ViewCounter` registra una vista. Si deseas leer el conteo sin incrementarlo — por ejemplo, en un panel de administración o una página de listado — llama a `useViewCount` directamente con `increment: false`:

```jsx
import { useViewCount } from "../hooks/useViewCount";

function PostCard({ post }) {
  const count = useViewCount(post.id, { increment: false });
  return <li>{post.title} — {count?.toLocaleString() ?? "—"} views</li>;
}
```

## Mostrar las vistas totales del sitio

`SiteViews` renderiza un resumen de una línea de las lecturas totales de todas las publicaciones. Colócalo donde quieras el número agregado — un pie de página, una página "acerca de", una franja de estadísticas en la página de inicio:

```jsx
import SiteViews from "../components/SiteViews";

<SiteViews />
```

Renderiza un `<p class="site-views">` con texto como `12,480 total reads across all posts.`, o nada mientras la solicitud está en curso.

## Endpoints de API que esperan los hooks

Los hooks llaman a un servicio de vistas compartido. Si cambias el backend, debe exponer la misma forma en las mismas rutas.

| Método | Endpoint                  | Usado por         | Comportamiento                                                                                   |
| ------ | ------------------------- | --------------- | ------------------------------------------------------------------------------------------ |
| `POST` | `/views/:postId`          | `useViewCount` (por defecto) | Registra una vista para `postId` y devuelve el nuevo conteo.                              |
| `GET`  | `/views/:postId`          | `useViewCount` con `{ increment: false }` | Devuelve el conteo actual para `postId` sin incrementarlo.        |
| `GET`  | `/views/total`            | `useTotalViews` | Devuelve el conteo agregado de lecturas de todas las publicaciones.                                        |

Los cuerpos de respuesta usan estas formas:

```json
// /views/:postId
{ "count": 1234 }

// /views/total
{ "total": 12480 }
```

Ambos hooks tratan las respuestas no `200` y las cargas útiles no numéricas como datos faltantes: mantienen el estado en `null` para que los componentes no muestren nada en lugar de mostrar un número roto. La URL base está configurada en los hooks como `https://api.paaatrrrick.com/views`.

## Estilos

`PostMeta` viene con `postMeta.css`, que dispone los segmentos como una fila flex con separadores de puntos delgados entre ellos. Las clases individuales que puedes usar como objetivo son:

- `.post-meta` — la fila envolvente.
- `.post-meta-date` — el segmento de fecha.
- `.view-counter` — el span del conteo de vistas (también renderizado por `ViewCounter` por sí solo).
- `.site-views` — el párrafo de vistas totales renderizado por `SiteViews`.
