## Resumen {#overview}

El sitio web personal incluye un pequeño conjunto de componentes y hooks para registrar y mostrar cuántas veces se han leído las publicaciones:

- **`ViewCounter`**: muestra el número de lecturas de una sola publicación, con el respaldo del hook `useViewCount`.
- **`SiteViews`**: muestra el número total de lecturas de todas las publicaciones, con el respaldo del hook `useTotalViews`.
- **`PostMeta`**: la línea combinada que aparece bajo el título de una publicación (fecha, tiempo de lectura estimado y número de visitas).

Los tres se comunican con un servicio de visitas compartido en `https://api.paaatrrrick.com/views`. El servicio devuelve datos seguros frente a `null`, así que cada componente no muestra nada mientras la llamada de red está en curso o si la solicitud falla.

## Cuándo usar cada pieza {#when-to-use-each-piece}

| Componente / hook        | Úsalo cuando…                                                                   |
| ------------------------ | ------------------------------------------------------------------------------- |
| `ViewCounter` / `useViewCount` | Quieres el número de lecturas de una sola publicación y quieres que se registre la visita. |
| `SiteViews` / `useTotalViews`  | Quieres el número total de lecturas de todo el sitio (por ejemplo, en el pie de página o en la página "Acerca de"). |
| `PostMeta`               | Estás mostrando una plantilla de publicación y quieres la línea estándar de fecha · tiempo de lectura · visitas. |

## Añadir la línea de metadatos a una plantilla de publicación {#adding-the-byline-to-a-post-template}

`PostMeta` es la forma recomendada de mostrar el número de visitas en una publicación. Reúne la fecha, el tiempo de lectura y el contador de visitas en una sola línea, así que cada plantilla no tiene que conectar cada pieza por su cuenta.

```jsx
import PostMeta from "../components/PostMeta";

export default function PostTemplate({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <PostMeta post={post} />
      {/* …post body… */}
    </article>
  );
}
```

`PostMeta` espera que el objeto de la publicación proporcione:

| Campo   | Tipo              | Notas                                                                 |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `id`    | string            | Se usa como clave del contador de visitas. Obligatorio para registrar visitas. |
| `date`  | string (opcional) | Se muestra tal cual cuando existe. Omítelo para ocultar el segmento de la fecha. |
| `body`  | string[] (opcional) | Se une y se pasa al estimador del tiempo de lectura.               |

Cada segmento se oculta si le faltan datos o si la llamada de red aún no ha terminado, así que la línea se degrada sin problemas en publicaciones sin fecha o antes de que cargue el número de visitas.

## Mostrar solo el número de visitas {#showing-just-the-view-count}

Si solo necesitas el número (por ejemplo, en la tarjeta de una lista de publicaciones), usa `ViewCounter` directamente:

```jsx
import ViewCounter from "../components/ViewCounter";

<ViewCounter postId={post.id} />
```

Muestra un `<span class="view-counter">` con el número formateado mediante `toLocaleString()` (así, `1234` se muestra como `1,234 views`). Mientras la solicitud está pendiente, devuelve `null` y no muestra nada.

### Leer sin registrar una visita {#reading-without-recording-a-view}

De forma predeterminada, montar `ViewCounter` registra una visita. Si quieres leer el número sin incrementarlo (por ejemplo, en un panel de administración o en una página de listado), llama a `useViewCount` directamente con `increment: false`:

```jsx
import { useViewCount } from "../hooks/useViewCount";

function PostCard({ post }) {
  const count = useViewCount(post.id, { increment: false });
  return <li>{post.title} — {count?.toLocaleString() ?? "—"} views</li>;
}
```

## Mostrar las visitas totales del sitio {#showing-total-site-views}

`SiteViews` muestra un resumen de una línea con el total de lecturas de todas las publicaciones. Colócalo donde quieras mostrar la cifra total: un pie de página, una página "Acerca de" o una franja de estadísticas en la página de inicio.

```jsx
import SiteViews from "../components/SiteViews";

<SiteViews />
```

Muestra un `<p class="site-views">` con un texto como `12,480 total reads across all posts.`, o nada mientras la solicitud está en curso.

## Endpoints de la API que esperan los hooks {#api-endpoints-the-hooks-expect}

Los hooks llaman a un servicio de visitas compartido. Si cambias el backend, debe exponer la misma estructura en las mismas rutas.

| Método | Endpoint                  | Usado por       | Comportamiento                                                                             |
| ------ | ------------------------- | --------------- | ------------------------------------------------------------------------------------------ |
| `POST` | `/views/:postId`          | `useViewCount` (predeterminado) | Registra una visita para `postId` y devuelve el nuevo número.                |
| `GET`  | `/views/:postId`          | `useViewCount` con `{ increment: false }` | Devuelve el número actual de `postId` sin incrementarlo.           |
| `GET`  | `/views/total`            | `useTotalViews` | Devuelve el número total de lecturas de todas las publicaciones.                           |

Los cuerpos de respuesta usan estas estructuras:

```json
// /views/:postId
{ "count": 1234 }

// /views/total
{ "total": 12480 }
```

Ambos hooks tratan las respuestas distintas de `200` y las cargas no numéricas como datos ausentes: mantienen el estado en `null` para que los componentes no muestren nada en lugar de una cifra errónea. La URL base está configurada en los hooks como `https://api.paaatrrrick.com/views`.

## Estilos {#styling}

`PostMeta` incluye `postMeta.css`, que dispone los segmentos en una fila flex con finos separadores de punto entre ellos. Las clases que puedes usar son:

- `.post-meta`: la fila contenedora.
- `.post-meta-date`: el segmento de la fecha.
- `.view-counter`: el span del número de visitas (que `ViewCounter` también muestra por sí solo).
- `.site-views`: el párrafo de visitas totales que muestra `SiteViews`.
