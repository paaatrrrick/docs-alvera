Este glosario define los términos que se usan a lo largo de estos documentos. Léelo una vez y vuelve a consultarlo cada vez que una palabra no te resulte clara.

## Términos

- **Despliegue**: Una versión publicada de tu sitio. Cada push a tu rama main crea un nuevo despliegue.
- **Vista previa**: Una compilación temporal de un pull request, para que puedas revisar los cambios antes de que se publiquen.
- **Navegación**: La estructura de la barra lateral que organiza tus páginas, definida en tu archivo de configuración.
- **Snippet**: Un bloque de contenido reutilizable que puedes incluir en varias páginas.
- **MDX**: El formato de archivo que se utiliza para las páginas de documentación. MDX combina Markdown con componentes JSX, de modo que puedes mezclar texto, bloques de código y elementos interactivos en el mismo archivo.

Si estás empezando, lee primero el [inicio rápido](/quickstart) y luego configura tu entorno con la [guía de desarrollo local](/development).
