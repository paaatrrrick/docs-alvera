Este glosario define los términos que se usan en esta documentación. Vuelve a consultarlo cuando una palabra no te quede clara.

## Términos

- **Deployment (implementación)**: Una versión publicada de tu sitio. Mintlify crea un nuevo deployment cada vez que haces merge en tu rama de despliegue. Consulta [Cómo funciona Mintlify](/es/how-mintlify-works).
- **MDX**: El formato de archivo de cada página. MDX es Markdown más componentes de React como `<Card>`, `<Tabs>` y `<Accordion>`. Cada archivo MDX comienza con frontmatter YAML, como `title` y `description`. Consulta [Sintaxis Markdown](/es/essentials/markdown).
- **Navegación**: La estructura de la barra lateral que organiza tus páginas en pestañas y grupos. La defines en el campo `navigation` de `docs.json`. Consulta [Navegación](/es/essentials/navigation).
- **Vista previa**: Una compilación temporal de un pull request. Úsala para revisar los cambios antes de que se publiquen. Para obtener una vista previa local, ejecuta `mint dev`.
- **Snippet**: Un bloque de contenido reutilizable almacenado en el directorio `snippets/`. Puedes importar un snippet en cualquier página. Consulta [Snippets reutilizables](/es/essentials/reusable-snippets).

Si estás empezando, lee primero la [guía de inicio rápido](/es/quickstart). Después, configura tu entorno con la [guía de desarrollo local](/es/development).
