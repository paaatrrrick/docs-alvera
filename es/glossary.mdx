Este glosario define los términos utilizados a lo largo de estos documentos. Léelo una vez y consúltalo cada vez que una palabra no esté clara.

## Términos

- **Despliegue** — Una versión publicada de tu sitio. Cada envío a tu rama principal crea un nuevo despliegue.
- **Vista previa** — Una compilación temporal de un pull request, para que puedas revisar los cambios antes de que se publiquen.
- **Navegación** — La estructura de la barra lateral que organiza tus páginas, definida en tu archivo de configuración.
- **Snippet** — Un bloque de contenido reutilizable que puedes incluir en varias páginas.
- **MDX** — El formato de archivo utilizado para las páginas de documentación. MDX combina Markdown con componentes al estilo JSX, para que puedas mezclar prosa, bloques de código y componentes interactivos en un único archivo.

Si acabas de empezar, lee primero la [guía rápida](/quickstart) y luego configura tu entorno con la [guía de desarrollo local](/development).
