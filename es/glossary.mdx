Este glosario define los términos que se usan con más frecuencia en esta documentación. Léelo una vez y vuelve a consultarlo cuando una palabra no quede clara.

## Términos

**Deployment**
Una versión publicada de tu sitio de documentación. Cada push a tu rama principal crea un nuevo deployment.

**Preview**
Una compilación temporal generada para un pull request. Úsala para revisar los cambios antes de que se publiquen.

**Navegación**
La estructura de la barra lateral que organiza tus páginas. La defines en `docs.json`. Consulta [navegación](/es/essentials/navigation).

**Snippet**
Un bloque de contenido reutilizable que puedes incluir en varias páginas. Consulta [snippets reutilizables](/es/essentials/reusable-snippets).

**Webhook**
Una llamada HTTP que envía un payload de evento a una URL que tú configuras. Consulta la [descripción general de webhooks](/es/webhooks-overview).

Si estás empezando, lee primero el [inicio rápido](/es/quickstart) y luego configura tu entorno con la [guía de desarrollo local](/es/development).
