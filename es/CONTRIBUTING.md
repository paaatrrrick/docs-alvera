# Contribuye a la documentación

¡Gracias por tu interés en contribuir a nuestra documentación! Esta guía te ayudará a empezar.

## Cómo contribuir

### Opción 1: Editar directamente en GitHub

1. Ve a la página que quieres editar
2. Haz clic en el botón “Edit this file” (el icono del lápiz)
3. Haz tus cambios y envía un pull request

### Opción 2: Desarrollo local

1. Haz un fork y clona este repositorio
2. Instala la CLI de Mintlify: `npm i -g mint`
3. Crea una rama para tus cambios
4. Haz los cambios
5. Ve al directorio de documentación y ejecuta `mint dev`
6. Previsualiza tus cambios en `http://localhost:3000`
7. Confirma tus cambios y envía un pull request

Para obtener más información sobre el desarrollo local, consulta nuestra [guía de desarrollo](development.mdx).

## Pautas de redacción

- **Usa la voz activa**: “Ejecuta el comando”, no “El comando debe ejecutarse”
- **Dirígete directamente al lector**: usa “tú” en lugar de “el usuario”
- **Mantén las frases concisas**: intenta expresar una idea por frase
- **Empieza por el objetivo**: inicia las instrucciones con lo que el usuario quiere lograr
- **Usa una terminología coherente**: no alternes entre sinónimos para el mismo concepto
- **Incluye ejemplos**: muestra, no te limites a decir
