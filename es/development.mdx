<Info>
  **Requisitos previos**:
  - Node.js versión 19 o superior
  - Un repositorio de documentación con un archivo `docs.json`
</Info>

Sigue estos pasos para instalar y ejecutar Mintlify en tu sistema operativo.

<Steps>
<Step title="Instala la CLI de Mintlify">

```bash
npm i -g mint
```
</Step>

<Step title="Previsualiza localmente">

Navega a tu directorio de documentación donde se encuentra tu archivo `docs.json` y ejecuta el siguiente comando:

```bash
mint dev
```

Una vista previa local de tu documentación estará disponible en `http://localhost:3000`.

</Step>
</Steps>

## Puertos personalizados

Por defecto, Mintlify usa el puerto 3000. Puedes personalizar el puerto en el que se ejecuta Mintlify usando la opción `--port`. Por ejemplo, para ejecutar Mintlify en el puerto 3333, usa este comando:

```bash
mint dev --port 3333
```

Si intentas ejecutar Mintlify en un puerto que ya está en uso, usará el siguiente puerto disponible:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Versiones de Mintlify

Cada versión de la CLI está asociada a una versión específica de Mintlify. Si tu vista previa local no coincide con la versión de producción, actualiza la CLI:

```bash
npm mint update
```

## Validar enlaces

Usa la CLI para encontrar enlaces rotos en tu documentación:

```bash
mint broken-links
```

## Formato de código

Sugerimos usar extensiones en tu IDE para reconocer y dar formato a MDX. Si usas VSCode, considera la [extensión MDX para VSCode](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) para el resaltado de sintaxis, y [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) para el formato de código.

## Solución de problemas

<AccordionGroup>
  <Accordion title='Error: Could not load the "sharp" module using the darwin-arm64 runtime'>

    Esto puede deberse a una versión desactualizada de node. Prueba lo siguiente:
    1. Elimina la versión actualmente instalada de la CLI: `npm remove -g mint`
    2. Actualiza a Node v19 o superior.
    3. Reinstala la CLI: `npm i -g mint`
  </Accordion>

  <Accordion title="Problema: Aparece un error desconocido">
  
    Solución: Ve a la raíz de tu dispositivo y elimina la carpeta `~/.mintlify`. Luego ejecuta `mint dev` de nuevo.
  </Accordion>
</AccordionGroup>

¿Tienes curiosidad por saber qué cambió en la última versión de la CLI? Consulta el [registro de cambios de la CLI](https://www.npmjs.com/package/mintlify?activeTab=versions).
