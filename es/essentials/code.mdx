## Código en línea

Para marcar una `palabra` o `frase` como código, enciérrala entre acentos graves (`).

```
To denote a `word` or `phrase` as code, enclose it in backticks (`).
```

## Bloques de código

Usa [bloques de código con cercado](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks) encerrando el código entre tres acentos graves y, después de los acentos iniciales, indica el lenguaje de programación de tu fragmento para obtener resaltado de sintaxis. Opcionalmente, también puedes escribir el nombre de tu código después del lenguaje de programación.

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```
