## Imagen

### Con Markdown

Usa la [sintaxis de Markdown](https://www.markdownguide.org/basic-syntax/#images) para agregar imágenes:

```md
![title](/path/image.jpg)
```

Los archivos de imagen deben pesar menos de 5MB. Para imágenes más grandes, alójalas en un servicio como [Cloudinary](https://cloudinary.com/) o [S3](https://aws.amazon.com/s3/) e incrusta la URL.

### Con elementos incrustados

Para tener más control sobre las imágenes, usa [elementos incrustados](https://mintlify.com/docs/image-embeds):

```html
<img height="200" src="/path/image.jpg" />
```

Mintlify admite [etiquetas HTML en Markdown](https://www.markdownguide.org/basic-syntax/#html). Esto es útil si prefieres las etiquetas HTML a la sintaxis de Markdown y te permite crear documentación con flexibilidad infinita.

</Tip>

### iFrames

Usa un iframe para cargar otra página HTML dentro del documento. Se usa sobre todo para incrustar videos.

```html
<iframe src="https://www.youtube.com/embed/4KzFe50RQkQ"> </iframe>
```
