Las etiquetas son una forma flexible de organizar tu contenido más allá de la navegación habitual.

## Añadir etiquetas

Puedes etiquetar cualquier página desde [los ajustes de página](/es/settings/page-tags). Una página puede tener tantas etiquetas como quieras.

Una vez etiquetadas, los lectores pueden hacer clic en una etiqueta para ver todas las páginas que la incluyen, algo estupendo para temas que abarcan varias secciones.

## Páginas de etiquetas

Generamos una página para cada etiqueta de forma automática. Puedes personalizar su aspecto en [los ajustes de etiquetas](#tag-pag-settings), o leer [la guía de etiquetado](./content/tagging-best-practices) para consejos sobre una buena taxonomía.

No crees demasiadas etiquetas. Un puñado bien elegido supera a un centenar desordenadas. Encontrarás más sobre esto en [el artículo de taxonomía](https://example-broken.dev/taxonomy).
