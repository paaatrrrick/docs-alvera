## Descripción general

La sección de experiencia laboral muestra una lista cronológica de puestos en la página de inicio del sitio web personal. Cada entrada se genera a partir del array `workExperience` y muestra un título, una descripción opcional, una imagen de logotipo opcional y una cadena de cronología.

Esta página documenta las incorporaciones recientes a esa lista para que los visitantes y colaboradores sepan qué ha cambiado y cómo se configuran las nuevas entradas.

## Esquema de las entradas

Cada entrada del array `workExperience` admite los siguientes campos:

| Campo      | Tipo   | Obligatorio | Descripción                                                  |
| ---------- | ------ | ----------- | ------------------------------------------------------------ |
| `title`    | string | Sí          | Puesto y nombre de la empresa que se muestran como encabezado de la entrada. |
| `text`     | string | No          | Breve descripción de las responsabilidades o logros.         |
| `image`    | string | No          | URL pública del logotipo de la empresa o del puesto.         |
| `timeLine` | string | Sí          | Periodo y ubicación en formato legible.                      |

## Redactar descripciones de puestos

Usa el campo `text` para comunicar el impacto, no solo las responsabilidades.

- Empieza por la contribución de mayor impacto.
- Menciona áreas de enfoque concretas (por ejemplo, fiabilidad, latencia, pipelines de evaluación).
- Destaca la colaboración entre equipos cuando aporte contexto al puesto.
- Limita la descripción a dos o tres frases para que la página de inicio siga siendo fácil de recorrer.

## Cuándo actualizar esta lista

Añade una nueva entrada siempre que empieces o termines un puesto, o quieras destacarlo en el sitio web personal. Ordena las entradas en orden cronológico inverso para que el puesto más reciente aparezca primero.
