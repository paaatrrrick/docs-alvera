## Descripción general

La sección de experiencia laboral muestra una lista cronológica de puestos en la página de inicio del sitio web personal. Cada entrada se renderiza a partir del array `workExperience` y muestra un título, una descripción opcional, una imagen de logotipo opcional y una cadena de línea temporal.

Esta página documenta las adiciones recientes a esa lista para que visitantes y colaboradores sepan qué ha cambiado y cómo se configuran las nuevas entradas.

## Esquema de entrada

Cada entrada del array `workExperience` admite los siguientes campos:

| Campo      | Tipo   | Obligatorio | Descripción                                                  |
| ---------- | ------ | ----------- | ------------------------------------------------------------ |
| `title`    | string | Sí          | Rol y nombre de la empresa mostrados como cabecera de la entrada. |
| `text`     | string | No          | Breve descripción de responsabilidades o logros.             |
| `image`    | string | No          | URL pública de un logotipo de empresa o del rol.             |
| `timeLine` | string | Sí          | Marco temporal y ubicación en formato legible.               |

## Redactar descripciones de rol

Usa el campo `text` para comunicar el impacto, no solo las responsabilidades.

- Empieza por la contribución de mayor impacto.
- Menciona áreas de enfoque concretas (por ejemplo, fiabilidad, latencia, pipelines de evaluación).
- Destaca la colaboración entre equipos cuando aporte contexto al rol.
- Mantén la descripción en dos o tres frases para que la página de inicio siga siendo fácil de escanear.

## Cuándo actualizar esta lista

Añade una nueva entrada cada vez que empieces, termines o quieras destacar un rol en el sitio web personal. Ordena las entradas en orden cronológico inverso para que el rol más reciente aparezca primero.
