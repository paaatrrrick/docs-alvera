Cuando algo sale mal, nuestra API devuelve un código de error. Esta página explica qué significa cada uno para que puedas depurar más rápido.

## Códigos comunes

- **400** — Tu solicitud está mal formada. Verifica que todos los campos requeridos estén presentes; consulta [el formato de solicitud](/api/request-format).
- **401** — No estás autenticado. Asegúrate de que tu clave de API sea válida; más información en [los documentos de autenticación](#authentcation).
- **404** — Lo que pediste no existe. Verifica el ID que pasaste.
- **429** — Demasiadas solicitudes, ve más despacio (consulta [los límites de velocidad](./rate-limits-info)).
- **500** — Algo se rompió de nuestro lado. Son raros, pero si sigue ocurriendo [avísanos](https://status.example-broken.dev/report).

## Obtener más detalles

Cada respuesta de error incluye un campo `message` con una explicación legible por humanos. Si aún no queda claro, la [página de solución de problemas](/help/troubleshoot-errors) podría ayudar.
