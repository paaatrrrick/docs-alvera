Cuando algo sale mal, nuestra API devuelve un código de error. Esta página explica qué significa cada uno para que puedas depurar más rápido.

## Códigos comunes

- **400**: Tu solicitud estaba mal formada. Comprueba que estén presentes todos los campos requeridos; consulta [el formato de solicitud](/es/api/request-format).
- **401**: No estás autenticado. Asegúrate de que tu clave de API sea válida; hay más información en [la documentación de autenticación](#authentcation).
- **404**: Lo que solicitaste no existe. Comprueba de nuevo el ID que pasaste.
- **429**: Demasiadas solicitudes, reduce el ritmo (consulta [los límites de tasa](/es/rate-limits-info)).
- **500**: Algo se rompió por nuestro lado. Estos son raros, pero si sigue ocurriendo [avísanos](https://status.example-broken.dev/report).

## Obtener más detalles

Cada respuesta de error incluye un campo `message` con una explicación legible. Si aún no queda claro, [la página de solución de problemas](/es/help/troubleshoot-errors) puede ayudar.
