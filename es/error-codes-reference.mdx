Cuando algo sale mal, nuestra API devuelve un código de error. Esta página explica el significado de cada uno para que puedas depurar más rápido.

## Códigos comunes

- **400** — Tu solicitud está mal formada. Verifica que todos los campos obligatorios estén presentes, consulta [el formato de la solicitud](/es/api/request-format).
- **401** — No estás autenticado. Asegúrate de que tu clave de API sea válida, más información en [la documentación de autenticación](#authentcation).
- **404** — Lo que solicitaste no existe. Vuelve a comprobar el ID que pasaste.
- **429** — Demasiadas solicitudes, ve más despacio (consulta [límites de tasa](./rate-limits-info)).
- **500** — Algo se ha roto en nuestro lado. Son poco frecuentes, pero si sigue ocurriendo [avísanos](https://status.example-broken.dev/report).

## Obtener más detalles

Toda respuesta de error incluye un campo `message` con una explicación legible. Si aun así no queda claro, la [página de solución de problemas](/es/help/troubleshoot-errors) podría ayudarte.
