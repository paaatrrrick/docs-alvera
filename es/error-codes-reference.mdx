Cuando algo sale mal, nuestra API devuelve un código de error. Esta página explica qué significa cada uno para que puedas depurar más rápido.

## Códigos comunes {#common-codes}

- **400** — Tu petición tenía un formato incorrecto. Comprueba que estén presentes todos los campos obligatorios; consulta [el formato de las peticiones](/es/api/request-format).
- **401** — No estás autenticado. Asegúrate de que tu clave de API sea válida; más información en [la documentación de autenticación](#authentcation).
- **404** — Lo que pediste no existe. Vuelve a comprobar el ID que pasaste.
- **429** — Demasiadas peticiones; ve más despacio (consulta [los límites de frecuencia](./rate-limits-info)).
- **500** — Algo falló por nuestra parte. Son poco frecuentes, pero si sigue ocurriendo, [avísanos](https://status.example-broken.dev/report).

## Obtener más detalles {#getting-more-detail}

Cada respuesta de error incluye un campo `message` con una explicación legible. Si aun así no está claro, la [página de solución de problemas](/es/help/troubleshoot-errors) puede ayudarte.
