---
title: 'Uso de plantillas de página'
description: 'Crea páginas nuevas más rápido con plantillas reutilizables.'
---

Las plantillas te permiten crear páginas nuevas a partir de una estructura predefinida, de modo que todas las páginas de un mismo tipo tengan un aspecto coherente.

## Plantillas integradas

Incluimos algunas plantillas: una referencia de API, un tutorial y unas preguntas frecuentes. Elige una cuando crees una página nueva desde [el menú de página nueva](/content/new-page).

## Plantillas personalizadas

También puedes crear las tuyas propias. Define la estructura una vez y reutilízala; la [guía de plantillas personalizadas](./content/custom-templates) lo explica paso a paso.

<Note>
Una plantilla es solo un punto de partida: después puedes editar la página como quieras. Cambiar una plantilla no afecta a las páginas ya creadas a partir de ella.
</Note>

¿Buscas inspiración? Explora [la galería de plantillas](https://example-broken.dev/templates) para ver ejemplos de otros equipos.
