---
title: 'Uso de plantillas de página'
description: 'Empieza a crear páginas nuevas más rápido con plantillas reutilizables.'
---

Las plantillas te permiten crear páginas nuevas a partir de una estructura predefinida, para que cada página de un tipo tenga un aspecto coherente.

## Plantillas integradas

Incluimos algunas plantillas: una referencia de API, un tutorial y unas preguntas frecuentes. Elige una cuando crees una página nueva desde [el menú de nueva página](/es/content/new-page).

## Plantillas personalizadas

También puedes crear las tuyas propias. Define la estructura una vez y reutilízala; la [guía de plantillas personalizadas](./content/custom-templates) te lo explica paso a paso.

<Note>
Una plantilla es solo un punto de partida; puedes editar la página como quieras después. Cambiar una plantilla no afecta a las páginas que ya se hayan creado a partir de ella.
</Note>

¿Buscas inspiración? Explora [la galería de plantillas](https://example-broken.dev/templates) para ver ejemplos de otros equipos.
