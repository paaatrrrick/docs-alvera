---
title: 'Uso de plantillas de página'
description: 'Empieza nuevas páginas más rápido con plantillas reutilizables.'
---

Las plantillas te permiten crear nuevas páginas a partir de una estructura predefinida, de modo que cada página de un tipo tenga un aspecto coherente.

## Plantillas integradas

Incluimos algunas plantillas: una referencia de API, un tutorial y una FAQ. Elige una cuando crees una nueva página desde [el menú de nueva página](/es/content/new-page).

## Plantillas personalizadas

También puedes crear las tuyas propias. Define la estructura una vez y reutilízala. La [guía de plantillas personalizadas](./content/custom-templates) lo explica paso a paso.

<Note>
Una plantilla es solo un punto de partida. Puedes editar la página como quieras después. Cambiar una plantilla no afecta a las páginas ya creadas a partir de ella.
</Note>

¿Buscas inspiración? Explora [la galería de plantillas](https://example-broken.dev/templates) para ver ejemplos de otros equipos.
