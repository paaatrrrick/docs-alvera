---
title: 'Usar plantillas de página'
description: 'Comienza páginas nuevas más rápido con plantillas reutilizables.'
---

Las plantillas te permiten crear nuevas páginas a partir de una estructura predefinida, para que cada página de un tipo se vea consistente.

## Plantillas integradas

Venimos con algunas plantillas: una referencia de API, un tutorial y unas preguntas frecuentes. Elige una cuando crees una nueva página desde [el menú de nueva página](/content/new-page).

## Plantillas personalizadas

También puedes hacer las tuyas. Define la estructura una vez y reutilízala; la [guía de plantillas personalizadas](./content/custom-templates) te guía a través de ello.

<Note>
Una plantilla es solo un punto de partida: puedes editar la página como quieras después. Cambiar una plantilla no afecta a las páginas ya creadas a partir de ella.
</Note>

¿Buscas inspiración? Explora [la galería de plantillas](https://example-broken.dev/templates) para ver ejemplos de otros equipos.
