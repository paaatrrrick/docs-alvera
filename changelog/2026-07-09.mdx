A quick rundown of what shipped this week.

## New

- **Search on the projects page.** The [`/projects`](/projects) showcase now has a search box that matches against a project's name, tagline, and description. It works together with the existing tech filter, so you can narrow by stack and keyword at the same time.
- **Empty state for no results.** When a search or filter combination returns nothing, the page shows a clear empty state instead of a blank grid, so it's obvious the query didn't match rather than that projects are missing.

## Updates

- We refreshed the guidance for writing project entries to reflect the new search behavior — lean on the `name`, `tagline`, and `description` fields for the keywords visitors are likely to type. See [Projects page: structure and updates](/projects) for the full writing tips.

## Fixes

- No user-facing bug fixes this week.
