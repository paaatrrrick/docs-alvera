Here's what shipped this week.

## New features

- **Search on the projects page.** The [`/projects`](/projects) showcase now includes a search box that filters cards by project name, tagline, and description. Combine it with the existing tech filter to narrow down to exactly what you're looking for. If nothing matches, an empty state makes it clear the list came up short. See the [projects page guide](/projects) for tips on writing entries so they surface from search.
