Updates that shipped to the personal website this week.

## New features

- **Project status badges.** Each card on [`/projects`](/projects) now shows an Active or Archived badge in the header. Active projects render with a green badge; archived projects render with a gray badge so visitors can tell at a glance which projects are still maintained. See [Projects page: structure and updates](/projects) for the `status` field and the writing guidance for when to switch a project to Archived.
- **Project search.** The [`/projects`](/projects) page now includes a search box that matches against a project's name, tagline, and description, so visitors can jump straight to what they're looking for.

## Updates

- **Projects page polish.** Search and the tech tag filter now compose: pick a tag, then narrow further with a query. Empty results show a short "No projects match your search" message instead of a blank grid.

If something on the site looks off, replies to the newsletter are the fastest way to get a fix in.
