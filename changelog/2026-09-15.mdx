<Update label="September 15, 2026">

## New features

**Search on the projects page.** The [`/projects`](/projects) showcase now includes a search box that matches against project name, tagline, and description. Search works alongside the existing tech filter, so you can narrow by stack and then find a specific project by keyword. An empty state appears when no projects match, so it's clear when a query returns nothing.

See the [projects page reference](/projects) for guidance on writing entries that surface well in search.
