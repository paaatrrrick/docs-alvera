Here's what shipped this week.

## New

- **Status badges on project cards.** Every card on [`/projects`](/projects) now shows an **Active** or **Archived** badge in the header so you can tell at a glance which projects are still being maintained. See [Projects page: structure and updates](/projects) for the `status` field reference.
- **Search on the projects page.** A search box above the grid filters projects by name, tagline, and description. It combines with the tech tag filter, so you can narrow to a stack and then search within it.
- **Tech tag filter.** Click any tech tag above the grid to show only projects that use it. Choose **All** to reset.
- **Dedicated `/projects` showcase page.** Side projects now live on their own route with a responsive card grid, longer descriptions, tech tags, and a link to the repo or live site. See [Projects page: structure and updates](/projects) for the entry schema and writing guidance.
