<Update label="Week of September 15, 2026" description="Projects page">

## New

**Search on the projects page.** The [`/projects`](/projects) showcase now has a search box above the tech filter. Type a keyword and results narrow by project name, tagline, or description. Search combines with the tech filter, so you can search within a stack.

**Empty state.** When no projects match the active search and filter, the grid shows a short "No projects match your search." message instead of a blank area.

For guidance on writing project fields so they surface well in search, see [Projects page: structure and updates](/projects#writing-guidance).

</Update>
