<Update label="July 18, 2026" description="Projects page search">

## New features

**Search on the projects page.** The `/projects` showcase now includes a search box that filters cards in real time. Search matches against a project's name, tagline, and description, and works alongside the existing tech stack filter — pick a tech tag and type a keyword to narrow further. When no projects match, the page shows an empty state instead of a blank grid.

Write your entries with keywords a visitor would actually type. See the [writing guidance](/projects#writing-guidance) on the projects page reference for tips on what to put in `name`, `tagline`, and `description` so cards surface from search.

</Update>
