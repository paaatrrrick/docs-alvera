## New

### Project status badges

Every card on the [/projects](/projects) page now shows an **Active** or **Archived** badge in its header. Active projects get a green badge; archived ones turn gray, so visitors can tell at a glance which side projects are still shipping updates.

See the [projects page reference](/projects) for the full entry schema, including the new `status` field.

## Updates

### Search and filter on /projects

The projects showcase page now includes a search box and a tech-tag filter. Search matches project name, tagline, and description, and combines with the tag filter so you can narrow the grid to, say, "everything React that mentions notes."

- Tips for writing search-friendly project entries live in the [projects reference](/projects).

### Reading stats on posts

Posts now show a byline with the publish date, estimated reading time, and view count, along with a site-wide total reads counter. Counts refresh on visit and gracefully hide while loading.

- Details on how each piece is wired up: [post view counter](/post-view-counter).
