## New features

- **Search on the projects page.** The [`/projects`](/projects) showcase now has a search box that filters by project name, tagline, and description. Combine it with the existing tech filter to narrow to a specific stack, and see an empty state when nothing matches. Write your entries with the words visitors would actually type so projects surface from search. For tips, see the [writing guidance](/projects#writing-guidance).
