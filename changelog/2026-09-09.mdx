## New features

- **Search the projects page.** The [`/projects`](/projects) showcase now has a search box that matches against each project's name, tagline, and description. Search works alongside the existing tech filter, so you can narrow by stack and then type to find a specific project. See the [Projects page reference](/projects) for details on how each field is indexed.

## Updates

- **Empty state on the projects page.** When a search or filter combination returns nothing, the grid now shows a short "No projects match your search." message instead of an empty page.
