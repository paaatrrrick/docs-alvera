## New features

- **Search on the projects page.** The [`/projects`](/projects) showcase now has a search box that filters cards by name, tagline, and description. Search combines with the existing tech filter, so you can narrow to a stack and then type to find a specific project. When nothing matches, the grid shows a short empty state instead of a blank space.
