## New features

- **Search on the projects page** — The [`/projects`](/projects) page now includes a search box that filters cards by name, tagline, or description. Search works alongside the existing tech filter, so you can narrow to a stack and then type a keyword.
- **Empty state for no matches** — When your search and filter combination returns nothing, the grid shows a short "No projects match your search." message instead of an empty page, so it's clear the page loaded correctly.

## Writing tip

Because search now matches on `name`, `tagline`, and `description`, write those fields with the words a visitor would actually type — product category, problem space, or stack keywords that aren't already tags. See the [projects page guide](/projects#writing-guidance) for the full field-by-field guidance.
