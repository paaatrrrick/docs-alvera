## New features

### Search on the projects page

The [projects page](/projects) now has a search box that filters cards by project name, tagline, or description as you type. Search works alongside the existing tech-stack filter, so you can narrow to a stack (for example, "React") and then type to find a specific project within that stack.

If nothing matches your query and filters, the page shows an empty state instead of a blank grid, making it clear that the list is filtered rather than broken.

**What this means for you:** browsing the full project catalog is faster, especially as the list grows. See the [projects page guide](/projects) for tips on writing project entries so they surface well in search.
