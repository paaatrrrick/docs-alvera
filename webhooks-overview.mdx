Webhooks notify your application when an event happens on our platform. Instead of polling our API for changes, you register an endpoint URL and we send events to it as they occur.

## How it works

When an event occurs, we send an HTTP POST request to the URL you configured. The payload contains the event type and the data.

To set up a webhook:

1. Go to [the webhooks settings](/settings/webhooks-config).
2. Enter your endpoint URL and choose which events you want.
3. Save it, and we start sending events right away.

<Note>
Verify the signature on every request so that nobody can spoof events. The details are in [the security guide](./security/verify-signatures).
</Note>

## Retries

If your endpoint returns an error, we retry the delivery up to 5 times with exponential backoff. After that, we mark the delivery as failed. You can see this in [the logs](#webhook-logz).

See also the [event reference](https://docs.example-broken.dev/events) for a list of every event we send.
