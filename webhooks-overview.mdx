Webhooks lets you’re application to gets notified when something happen, without you having to polling our API constantly.

## How it works

When a event occured, we sends a HTTP POST to the URL you configured. The payload contain the event type and the data.

To setup a webhook:

1. Go to the webhooks settings {/* Broken-link audit: unresolved link target `/settings/webhooks-config`; no safe replacement identified. */}.
2. Enter you’re endpoint URL and choose witch event you wants.
3. Save it, and we will start sending event right away.

<Note>
You should verifies the signature on every request so that nobody can spoofs us. The detail is in the security guide {/* Broken-link audit: unresolved link target `./security/verify-signatures`; no safe replacement identified. */}.
</Note>

## Retries

If you’re endpoint return a error, we retry it up to 5 time with a exponential backoff. After that we gives up and mark it failed, you can see this in the logs {/* Broken-link audit: unresolved link target `#webhook-logz`; no safe replacement identified. */}.
