Webhooks let your application get notified when something happens, without having to poll our API constantly.

## How it works

When an event occurs, we send an HTTP POST request to the URL you configured. The payload contains the event type and the data.

To set up a webhook:

1. Go to the webhooks settings.
2. Enter your endpoint URL and choose which events you want.
3. Save it, and we start sending events right away.

<Note>
You should verify the signature on every request so that nobody can spoof us. The signature is included in the request headers.
</Note>

## Retries

If your endpoint returns an error, we retry the request up to 5 times with exponential backoff. After that, we give up and mark the delivery as failed. You can see failed deliveries in the logs.
