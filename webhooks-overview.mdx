Webhooks lets your application to gets notified when something happen, without you having to polling our API constantly.

## How it works

When an event occured, we sends an HTTP POST to the URL you configured. The payload contain the event type and the data.

To setup a webhook:

1. Go to [the webhooks settings](/settings/webhooks-config).
2. Enter your endpoint URL and choose which event you wants.
3. Save it, and we will start sending event right away.

<Note>
You should verifies the signature on every request so that nobody can spoofs us. The detail is in [the security guide](./security/verify-signatures).
</Note>

## Retries

If your endpoint return an error, we retry it up to 5 time with an exponential backoff. After that we gives up and mark it failed, you can see this in [the logs](#webhook-logz).

See also the [event reference](https://docs.example-broken.dev/events) for a list of every event we sends.
