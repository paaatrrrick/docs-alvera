## 概要

伝説のポケモンは、通常1つのゲームにつき1体しか登場しない希少で強力なポケモンであり、その地方の神話と結びついています。幻のポケモンも同様に希少ですが、通常は野生で出現するのではなく、特別なイベントを通じて配布されます。この2つを合わせたものが、ポケモン図鑑の中でも最も象徴的な一角を成しています。

## 伝説のトリオとデュオ

多くの世代で、役割や地方、由来を共有するテーマ性のある伝説のポケモンのグループが登場します。

| グループ           | メンバー                                | 世代       |
| ----------------- | ------------------------------------ | ---------- |
| 伝説の鳥ポケモン    | フリーザー、サンダー、ファイヤー           | 第1世代    |
| 伝説の獣ポケモン    | ライコウ、エンテイ、スイクン              | 第2世代    |
| 天候トリオ         | カイオーガ、グラードン、レックウザ         | 第3世代    |
| 創造トリオ         | ディアルガ、パルキア、ギラティナ           | 第4世代    |
| 正義の剣士        | コバルオン、テラキオン、ビリジオン、ケルディオ | 第5世代    |
| 島の守り神        | カプ・コケコ、レヒレ、ブルル、フィニ        | 第7世代    |

本編シリーズの各ペアには、パッケージにマスコットとなる伝説のポケモンが登場します。

- **第1世代** — ミュウツー（暗示的）、そして幻のポケモンとしてミュウ
- **第2世代** — ルギア（銀）とホウオウ（金）
- **第3世代** — カイオーガ（サファイア）とグラードン（ルビー）
- **第4世代** — ディアルガ（ダイヤモンド）とパルキア（パール）
- **第5世代** — レシラム（ブラック）とゼクロム（ホワイト）

## 伝説のポケモンの捕獲

ほとんどの伝説のポケモンは、メインストーリーの終盤付近の固定された場所で一度きりの遭遇となります。いくつかのコツを紹介します：

- 遭遇前にセーブしておくと、倒れてしまったりモンスターボールを使い切ったりした場合にやり直せます。
- 「ねむり」や「まひ」などの状態異常技を持ち込むと、捕獲率が上がります。
- ハイパーボール、タイマーボール（長期戦時）、ダークボール（夜間や洞窟内）は通常、最良の捕獲手段となります。
- 色違いロックのあるゲームでは、伝説のポケモンは色違いで出現しません。ソフトリセットの前に、その世代のルールを確認してください。

## 本編以外での登場

伝説のポケモンはフランチャイズ全体を通じて登場します：

- **アニメ** — *ミュウツーの逆襲* から *ココ* まで、ほぼ毎年のように映画で活躍しています。
- **トレーディングカードゲーム** — 高レアリティのカードや拡張パックの目玉として頻繁に印刷されています。
- **Pokémon GO** — レイドバトルやスペシャルリサーチのタスクを通じて配信されています。
