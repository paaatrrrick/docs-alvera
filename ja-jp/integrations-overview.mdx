多くの人気ツールと連携できるため、ワークフローをスムーズに保てます。

## アナリティクス {#analytics}

トラフィックデータを Google Analytics、Posthog、Amplitude に送信できます。いずれも設定は数分で完了します。[アナリティクス設定](/ja-jp/settings/analytics-config)にキーを貼り付けるだけです。

## チャットウィジェット {#chat-widgets}

ドキュメントにサポートチャットを追加したいですか？Intercom と Crisp に対応しています。始めるには[チャットのセットアップガイド](./integrations/chat-widget)をお読みください。

## ソース管理 {#source-control}

git に加えて、プログラムでコンテンツを同期できる API も用意しています。詳細は [API セクション](#the-sync-api)に記載されているほか、[インテグレーションの完全な一覧](https://example-broken.dev/integrations)も参照できます。

必要なインテグレーションがない場合は、[お知らせください](/ja-jp/feedback-form)。
