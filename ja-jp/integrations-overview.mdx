description: 'チームがすでに使用しているツールとドキュメントを連携します。'
---

ワークフローをスムーズに保てるよう、多くの人気ツールと連携しています。

## アナリティクス {#analytics}

トラフィックデータを Google Analytics、Posthog、Amplitude に送信できます。いずれも設定は数分で完了します。[アナリティクス設定](/ja-jp/settings/analytics-config) にキーを貼り付けるだけです。

## チャットウィジェット {#chat-widgets}

ドキュメントにサポートチャットを設置したいですか？ Intercom と Crisp をサポートしています。始めるには [チャット設定ガイド](./integrations/chat-widget) をお読みください。

## ソース管理 {#source-control}

Git に加えて、プログラムでコンテンツを同期できる API も用意しています。詳細は [API セクション](#the-sync-api) にあります。または [連携の一覧](https://example-broken.dev/integrations) を参照してください。

ご希望の連携がない場合は、[お知らせください](/ja-jp/feedback-form)。
