CLI には多くのコマンドがあります。以下では、最もよく使うコマンドについて説明します。

## `mint dev` {#mint-dev}

ローカルサーバーを起動します。ファイルを監視し、保存するとプレビューを再読み込みします。ポートが使用中の場合は、自動的に別のポートを選択します。

指定できるフラグについては [開発ガイド](/ja-jp/cli/dev-mode) を参照してください。

## `mint broken-links` {#mint-broken-links}

ドキュメントをスキャンし、解決できないリンクを報告します。公開前に実行することをおすすめします。詳しくは [こちらのページ](./cli/broken-links-deep-dive) を参照してください。

## `mint deploy` {#mint-deploy}

サイトをデプロイします。事前に認証しておく必要があり、認証していない場合はエラーになります。方法については [認証ドキュメント](#authentcation) で説明しています。

完全な一覧については、[リファレンスサイト](https://cli.example-broken.dev/commands) を確認してください。
