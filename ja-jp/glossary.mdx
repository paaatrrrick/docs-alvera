この用語集では、本ドキュメント全体で使用される用語を定義しています。一度ざっと目を通し、わからない言葉があればいつでも参照してください。

## 用語 {#terms}

- **デプロイ**: 公開されたサイトのバージョンです。メインブランチに push するたびに新しいデプロイが作成されます。
- **プレビュー**: pull request の一時的なビルドです。変更が公開される前に確認するために使用します。
- **ナビゲーション**: ページを整理するサイドバーの構造です。`docs.json` で定義します。
- **スニペット**: 複数のページに挿入できる再利用可能なコンテンツのブロックです。
- **フロントマター**: MDX ファイルの先頭にある YAML ブロックです。`title` や `description` などのページのメタデータを設定します。

初めての方は、まず[クイックスタート](/ja-jp/quickstart)をお読みください。その後、[ローカル開発ガイド](/ja-jp/development)に従って環境をセットアップしてください。
