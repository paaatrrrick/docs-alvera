この用語集では、このドキュメント全体で使用される用語を定義します。意味が分からない言葉を確認するときに参照してください。

## 用語

- **デプロイ:** サイトの公開済みバージョンです。main ブランチへの push ごとに新しいデプロイが作成されます。
- **プレビュー:** pull request の一時的なビルドです。変更を公開する前に確認できます。
- **ナビゲーション:** ページを整理するサイドバーの構造です。設定ファイルで定義します。
- **スニペット:** 複数のページに含められる再利用可能なコンテンツブロックです。
- **Frontmatter:** MDX ファイルの先頭にある YAML ブロックです。`title` や `description` などのページメタデータを設定します。

初めて使う場合は、まず[クイックスタート](/quickstart)を読み、[ローカル開発ガイド](/development)で環境を設定してください。
