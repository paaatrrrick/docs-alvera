Mintlify は、MDX ファイルを含む Git リポジトリを、高速で検索可能なドキュメントサイトに変換します。このページでは、内部で何が起きているかを理解できるよう、各構成要素について説明します。

## コミットからページ公開まで {#from-commit-to-published-page}

1. **コンテンツを書きます。** ページは MDX で作成します。MDX は、Markdown に `<Card>`、`<Tabs>`、`<Accordion>` などの React コンポーネントを加えたものです。
2. **ナビゲーションを設定します。** `docs.json` では、タブ、グループ、テーマ、ナビバーやフッターなどのグローバル要素を定義します。
3. **GitHub にプッシュします。** Mintlify の GitHub アプリがデプロイブランチの変更を検出します。
4. **Mintlify がサイトをビルドします。** コンテンツが検証され、リンクがチェックされ、サイトが静的アセットにコンパイルされます。
5. **サイトが公開されます。** 新しいビルドが通常数秒以内にドメインにデプロイされます。

## ローカル開発 {#local-development}

プッシュする前に、Mintlify CLI を使用して変更をプレビューします。

```bash
mint dev
```

これにより、ホットリロード付きでドキュメントが `http://localhost:3000` で配信されます。問題を早期に発見するには、次を実行します。

```bash
mint validate
mint broken-links
```

## 作成モデル {#authoring-model}

- **MDX ファイル** — すべてのページは YAML フロントマター（`title`、`description`）を持つ `.mdx` ファイルです。
- **コンポーネント** — Mintlify には、コールアウト、タブ、コードグループ、アコーディオン、カードなどの組み込みコンポーネントが用意されています。
- **スニペット** — 再利用可能なコンテンツは `snippets/` に格納され、どのページにもインポートできます。
- **画像とアセット** — リポジトリのルートからの相対パスで参照します。

## 設定 {#configuration}

`docs.json` は、サイト構造に関する唯一の信頼できる情報源です。

- `navigation` — タブ、グループ、ページの順序。
- `colors`、`logo`、`favicon` — ブランディング。
- `navbar`、`footer` — グローバルリンクとソーシャルリンク。
- `contextual` — 各ページの「Copy / Open in ChatGPT」メニューを制御します。

## 検索と AI {#search-and-ai}

公開されるすべてのサイトには、次の機能が含まれます。

- **全文検索** — ビルドごとに自動的にインデックスが作成されます。
- **AI チャット** — ドキュメントをコンテキストとして使用し、質問に回答します。
- **MCP および LLM インテグレーション** — Cursor や Claude などのツールがドキュメントを参照できます。
