Webhook を使用すると、API を絶えずポーリングしなくても、何かが発生したときにアプリケーションに通知を送ることができます。

## 仕組み {#how-it-works}

イベントが発生すると、設定した URL に HTTP POST を送信します。ペイロードにはイベントの種類とデータが含まれます。

Webhook を設定するには、次の手順を実行します。

1. [Webhook 設定](/ja-jp/settings/webhooks-config)に移動します。
2. エンドポイントの URL を入力し、受信するイベントを選択します。
3. 保存すると、すぐにイベントの送信が開始されます。

<Note>
第三者によるなりすましを防ぐため、すべてのリクエストで署名を検証してください。詳しくは[セキュリティガイド](./security/verify-signatures)を参照してください。
</Note>

## 再試行 {#retries}

エンドポイントがエラーを返した場合、指数バックオフを使用して最大 5 回まで再試行します。それでも失敗した場合は再試行を中止し、失敗として記録します。これは[ログ](#webhook-logz)で確認できます。

送信されるすべてのイベントの一覧については、[イベントリファレンス](https://docs.example-broken.dev/events)も参照してください。
