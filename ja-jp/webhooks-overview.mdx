Webhook を使用すると、当社の API を絶えずポーリングしなくても、何かが起きたときにアプリケーションに通知を受け取ることができます。

## 仕組み {#how-it-works}

イベントが発生すると、設定された URL に HTTP POST を送信します。ペイロードには、イベントの種類とデータが含まれます。

Webhook を設定するには:

1. [Webhook の設定](/ja-jp/settings/webhooks-config)に移動します。
2. エンドポイントの URL を入力し、受信したいイベントを選択します。
3. 保存すると、すぐにイベントの送信が開始されます。

<Note>
第三者によるなりすましを防ぐため、すべてのリクエストで署名を検証してください。詳細は[セキュリティガイド](./security/verify-signatures)をご覧ください。
</Note>

## 再試行 {#retries}

エンドポイントがエラーを返した場合、指数バックオフを用いて最大 5 回まで再試行します。それでも失敗した場合は再試行を中止し、失敗としてマークします。これは[ログ](#webhook-logz)で確認できます。

当社が送信するすべてのイベントの一覧については、[イベントリファレンス](https://docs.example-broken.dev/events)も参照してください。
