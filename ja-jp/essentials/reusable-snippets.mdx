## カスタムスニペットの作成 {#creating-a-custom-snippet}

**前提条件**: `snippets` ディレクトリにスニペットファイルを作成します。

<Note>
  `snippets` ディレクトリ内のページはすべてスニペットとして扱われ、
  単独のページとしてはレンダリングされません。スニペットから単独のページを
  作成したい場合は、スニペットを別のファイルにインポートし、
  コンポーネントとして呼び出してください。
</Note>

### デフォルトエクスポート {#default-export}

1. 複数の場所で再利用したいコンテンツをスニペットファイルに追加します。
   必要に応じて、スニペットをインポートする際に props で値を埋め込める
   変数を追加することもできます。

```mdx snippets/my-snippet.mdx
Hello world! This is my content I want to reuse across pages. My keyword of the
day is {word}.
```

<Warning>
  インポートを機能させるには、再利用したいコンテンツが `snippets`
  ディレクトリ内にある必要があります。
</Warning>

2. スニペットをインポート先のファイルにインポートします。

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import MySnippet from '/snippets/path/to/my-snippet.mdx';

## Header

Lorem ipsum dolor sit amet.

<MySnippet word="bananas" />
```

### 再利用可能な変数 {#reusable-variables}

1. スニペットファイルから変数をエクスポートします。

```mdx snippets/path/to/custom-variables.mdx
export const myName = 'my name';

export const myObject = { fruit: 'strawberries' };
```

2. インポート先のファイルでスニペットをインポートし、変数を使用します。

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import { myName, myObject } from '/snippets/path/to/custom-variables.mdx';

Hello, my name is {myName} and I like {myObject.fruit}.
```

### 再利用可能なコンポーネント {#reusable-components}

1. スニペットファイル内で、アロー関数の形式でコンポーネントをエクスポートし、
   props を受け取るコンポーネントを作成します。

```mdx snippets/custom-component.mdx
export const MyComponent = ({ title }) => (
  <div>
    <h1>{title}</h1>
    <p>... snippet content ...</p>
  </div>
);
```

<Warning>
  MDX はアロー関数の本体内ではコンパイルされません。可能な限り HTML
  構文を使用するか、MDX を使用する必要がある場合はデフォルトエクスポートを使用してください。
</Warning>

2. スニペットをインポート先のファイルにインポートし、props を渡します。

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import { MyComponent } from '/snippets/custom-component.mdx';

Lorem ipsum dolor sit amet.

<MyComponent title={'Custom title'} />
```
