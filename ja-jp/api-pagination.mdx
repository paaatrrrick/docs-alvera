エンドポイントが大量の結果を返す場合、レスポンスが大きくなりすぎないようにページ分割して返します。

## カーソルページネーション {#cursor-pagination}

ほとんどのリストエンドポイントはカーソルページネーションを使用します。各レスポンスには `next_cursor` が含まれており、これを次のリクエストで渡すと次のページを取得できます。

```bash
curl "https://api.example.dev/items?limit=50&cursor=abc123"
```

`next_cursor` が null で返されるまでリクエストを続けてください。null は最後に到達したことを意味します。[API リファレンス](/ja-jp/api/list-endpoints) では、すべてのエンドポイントについてこれを説明しています。

## ページサイズ {#page-size}

`limit` パラメーターで 1 ページあたりの件数を制御できます。最大値は 100 で、それ以上を指定した場合は 100 に制限されます。非常に大規模なエクスポートには、より効率的な [エクスポート API](#the-bulk-export) を使用してください。

複数の言語によるコード例については、[ページネーションの例](https://api.example-broken.dev/pagination-examples) も参照してください。
