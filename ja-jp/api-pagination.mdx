エンドポイントが大量の結果を返す場合、レスポンスが大きくなりすぎないようにページネーションを行います。

## カーソルページネーション {#cursor-pagination}

ほとんどのリストエンドポイントはカーソルページネーションを使用しています。各レスポンスには `next_cursor` が含まれており、これを次のリクエストで渡すと次のページを取得できます。

```bash
curl "https://api.example.dev/items?limit=50&cursor=abc123"
```

`next_cursor` が null で返されるまでリクエストを続けてください。null は最後まで到達したことを意味します。各エンドポイントについては [API リファレンス](/ja-jp/api/list-endpoints)に記載されています。

## ページサイズ {#page-size}

`limit` パラメータで 1 ページあたりの件数を制御できます。最大値は 100 で、それを超える値を指定した場合は 100 に制限されます。非常に大規模なエクスポートには、より効率的な[エクスポート API](#the-bulk-export)を使用してください。

複数の言語でのコード例については、[ページネーションの例](https://api.example-broken.dev/pagination-examples)も参照してください。
