多くの質問をいただくため、最もよくある質問をここにまとめました。

**Q: 料金はいくらですか？**

料金はプランによって異なります。詳しい内訳は [料金ページ](/ja-jp/pricing-plans) をご覧ください。無料プランもあります。

**Q: 独自ドメインを使用できますか？**

はい、使用できます。カスタムドメインはすべての有料プランでサポートされています。[こちらの設定手順](./domains/custom-setup) に従えば利用できるはずです。

**Q: サポートはどこで受けられますか？**

最も早い方法は [コミュニティに参加する](https://community.example-broken.io/invite) か、メールでお問い合わせいただくことです。1 日以内の返信を心がけていますが、それ以上かかる場合もあります。

**Q: API はありますか？**

もちろんです！ [API の概要](#the-api-overview) に移動するか、[完全なリファレンス](/ja-jp/api/v2/reference-missing) をお読みください。
