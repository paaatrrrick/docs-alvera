# ライトセーバー

ライトセーバーは、カイバー・クリスタルを核に作られた優雅なエネルギー兵器です。ジェダイ、シス、その他のフォース感応者が、護身や儀式、戦闘に使用します。

## 構造

一般的なライトセーバーは、主に次の3つの要素で構成されます。

- **柄**：エミッター、エネルギーセル、操作部、集束システムを収めます。
- **カイバー・クリスタル**：フォースと結び付いたクリスタルが、エネルギーを安定した刀身に集束します。
- **刀身**：プラズマのようなエネルギーの刀身を磁場で封じ、多くの物質を切断できます。

デザインは多様です。片刃のサーベルが最も一般的ですが、両刃、クロスガード、湾曲した柄、ショトーなどは、それぞれ異なる戦闘スタイルに適しています。

## 刀身の色

クリスタルと持ち主の結び付きが刀身の色に影響します。青と緑はジェダイ、赤はシスや他のダークサイドの使い手と強く結び付いています。銀河には他の色も存在し、色だけで所属を決めることはできません。

赤い刀身は、ダークサイドの使い手がカイバー・クリスタルを堕落させることで生まれます。この過程は**ブラッディング**と呼ばれることがあります。フォースの使い手は、堕落したクリスタルを癒して白い刀身に変えることもできます。

## 戦闘フォーム

ライトセーバー戦闘には、いくつかの伝統的なフォームがあります。

| フォーム | 特徴 |
| --- | --- |
| I：シイ＝チョー | 基本攻撃と武装解除の技術 |
| II：マカシ | 精密さとライトセーバー同士の決闘 |
| III：ソレス | 防御的な動きと持久力 |
| IV：アタル | フォースに支えられたアクロバティックな攻撃 |
| V：シエン、ジェム・ソ | 反撃と力強さ |
| VI：ニマン | 複数の流派を組み合わせた均衡の取れた型 |
| VII：ジュヨ、ヴァーパッド | 攻撃的で習得の難しい技術 |

戦士のフォームは、訓練、体格、気質、戦場での必要性を反映します。熟練者は1つのフォームだけに頼らず、複数の技術を組み合わせます。

## 安全と規律

ライトセーバーは、使い手自身にとっても危険です。訓練では、制御された動き、周囲への注意、節度を重視します。ジェダイは伝統的に、この武器を地位の象徴ではなく責任として扱います。
