# ライトセーバー

ライトセーバーは、カイバー・クリスタルを中心に作られたエネルギー兵器です。ジェダイ、シス、その他のフォース感応者は、防衛、儀礼、戦闘のためにライトセーバーを使用します。

## 構造

ほとんどのライトセーバーは、主に3つの要素で構成されています：

- **柄**: ハンドルには、エミッター、パワーセル、操作装置、集束システムが収められています。
- **カイバー・クリスタル**: フォースに感応したクリスタルが、エネルギーを安定したブレードへと集束させます。
- **ブレード**: 磁場がプラズマ状のエネルギーブレードを封じ込め、多くの物質を切断できます。

デザインは多岐にわたります。単刃のライトセーバーが最も一般的です。両刃、クロスガード、湾曲した柄、ショートのデザインは、それぞれ異なる戦闘スタイルに対応します。

## ブレードの色

クリスタルと使い手の結びつきが、ブレードの色に影響します。ジェダイは青や緑のブレードを振るうことが多く、シスやその他のダークサイドの使い手は、赤いブレードを振るうことが一般的です。銀河の各地には他の色も見られますが、色だけで使い手の所属が決まるわけではありません。

ダークサイドの使い手は、しばしば**ブリーディング**と呼ばれる過程でカイバー・クリスタルを堕落させ、赤いブレードを生み出すことができます。フォース使いは後に、堕落したクリスタルを浄化し、白いブレードを生み出すこともできます。

## 戦闘形態

ライトセーバー戦闘は、いくつかの伝統的な型へと発展しました：

| 型 | 主眼 |
| --- | --- |
| I: Shii-Cho | 基本となる攻撃と武装解除の技術 |
| II: Makashi | 精密さとライトセーバー同士の決闘 |
| III: Soresu | 防御的な動きと持久力 |
| IV: Ataru | フォースに支えられたアクロバティックな攻撃 |
| V: Shien and Djem So | 反撃と力強さ |
| VI: Niman | 複数の流派を組み合わせたバランスの取れた型 |
| VII: Juyo and Vaapad | 攻撃的で、習得の難しい技術 |

戦士が選ぶ型には、その訓練、体格、気質、そして戦場での必要性が反映されます。熟練者は、一つの型だけに従うのではなく、複数の技術を組み合わせることがよくあります。

## 安全と規律

ライトセーバーは、使い手にとっても危険な武器です。訓練では、制御された動き、周囲への注意、そして自制が重視されます。ジェダイは伝統的に、この武器を地位の象徴ではなく、責任を伴うものとして扱います。
