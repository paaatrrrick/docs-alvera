ライトセーバー戦闘には 7 つの古典的な型があります。それぞれの型は、攻撃、防御、フォースの使用のバランスを異なる形で重視しています。

## 7 つの型 {#the-seven-forms}

| 型 | 名称 | 特徴 |
| --- | --- | --- |
| I | Shii-Cho | 複数の相手に対する大きく薙ぎ払う攻撃 |
| II | Makashi | ほかのライトセーバー使いとの精密な決闘 |
| III | Soresu | ブラスターの射撃に対する堅実で効率的な防御 |
| IV | Ataru | フォースを活かしたアクロバティックで攻撃的な技 |
| V | Shien / Djem So | 反撃とブラスターのボルトの跳ね返し |
| VI | Niman | ライトセーバーとフォースの能力を融合させたバランスの取れた技法 |
| VII | Juyo / Vaapad | 激しい感情を力に変える、獰猛で予測不能な攻撃 |

## 代表的な使い手 {#notable-practitioners}

- **Obi-Wan Kenobi** は Soresu を極め、相手が消耗するまで持ちこたえました。
- **Count Dooku** は一対一の決闘における優雅さから Makashi を好みました。
- **Yoda** は Ataru を頼りとし、フォースを使って小柄な体格を補いました。
- **Anakin Skywalker** は Djem So で戦い、強力な反撃で相手を圧倒しました。
- **Mace Windu** は Juyo の派生形である Vaapad を編み出しましたが、これを制御できる Jedi はごくわずかでした。

## 型の選び方 {#choosing-a-form}

Jedi は通常、最初に Shii-Cho を学びます。その後、自分の気質や長所に最も合った型を専門にします。刃そのものに力を与えるものについては、[カイバー・クリスタル](/ja-jp/star-wars-kyber-crystals)を参照してください。
