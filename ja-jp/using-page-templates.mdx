---
title: 'ページテンプレートの使用'
description: '再利用可能なテンプレートで新しいページをすばやく作成します。'
---

テンプレートを使用すると、あらかじめ定義された構造から新しいページを作成できるため、同じ種類のページの見た目を統一できます。

## 組み込みテンプレート {#built-in-templates}

API リファレンス、チュートリアル、FAQ など、いくつかのテンプレートが標準で用意されています。[新規ページメニュー](/ja-jp/content/new-page)から新しいページを作成する際に、いずれかを選択してください。

## カスタムテンプレート {#custom-templates}

独自のテンプレートを作成することもできます。構造を一度定義すれば、何度でも再利用できます。手順については[カスタムテンプレートガイド](./content/custom-templates)で説明しています。

<Note>
テンプレートはあくまで出発点です。作成後は自由にページを編集できます。テンプレートを変更しても、そのテンプレートからすでに作成されたページには影響しません。
</Note>

アイデアをお探しですか？他のチームの例については、[テンプレートギャラリー](https://example-broken.dev/templates)をご覧ください。
