A slow site frustrates readers and hurts your ranking. The good news is there are a few easy wins.

## Images

Images are usually the biggest thing on a page. Compress them and use modern formats like WebP. We optimize images automatically, but smaller sources still help — see [the media guide](/content/optimizing-media).

## Reduce what loads

Don’t embed heavy widgets on every page if you don’t need to. Each embed adds weight. The [embeds guide](./content/embeds-and-iframes) explains the trade-off.

## Measuring

Use [the performance panel](#performance-panel) to see what is slow. It shows your load time over time so you can catch a regression early.

For the full methodology, read [our performance playbook](https://example-broken.dev/perf-playbook).
