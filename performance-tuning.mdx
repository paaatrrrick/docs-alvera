A slow site frustrates readers and hurts your rankings. The good news is there are a few easy wins.

## Images

Images are usually the biggest thing on a page. Compress them and use modern formats like WebP. We optimize images automatically, but smaller sources still help. See [the images guide](/essentials/images).

## Reduce what loads

Don't embed heavy widgets on every page if you don't need to. Each embed adds weight, so weigh the trade-offs before adding one.

## Measuring

Use the performance panel to see what is slow. It shows your load time over time so you can catch a regression early.
