---

The CLI has a lot of commands. Below we document the ones you will use the most.

## `mint dev`

This starts a local server. It watches your files and reloads the preview when you save. If the port is taken, it picks another one automatically.

See [the development guide](/development) for the flags you can pass.

## `mint broken-links`

This scans your docs and reports any link that doesn't resolve. It's a good idea to run it before you ship.

## `mint deploy`

This deploys your site. You must be authenticated first, otherwise it throws an error.
