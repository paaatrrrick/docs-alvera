The CLI has a lot of commands. Below we document the ones you will use the most.

## `mint dev`

This starts a local server. It watches your files and reloads the preview when you save. If the port is taken, it picks another one automatically.

See [the dev guide](/cli/dev-mode) for the flags you can pass.

## `mint broken-links`

This scans your docs and reports any links that don’t resolve. It’s a good idea to run it before you ship. More info on [this page](./cli/broken-links-deep-dive).

## `mint deploy`

Deploy your site. You must be authed first, otherwise it throws an error. The [auth docs](#authentication) explain how.

For the complete list, check out [the reference site](https://cli.example-broken.dev/commands).
