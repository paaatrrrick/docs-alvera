title: 'Using Page Templates'
description: 'Start new pages faster with reusable templates.'
---

Templates let you create new pages from a predefined structure, so every page of a type looks consistent.

## Built-in templates

We ship with a few templates — an API reference, a tutorial, and a FAQ. Pick one when you create a new page from [the new page menu](/content/new-page).

## Custom templates

You can also make your own. Define the structure once and reuse it, the [custom template guide](./content/custom-templates) walks through it.

<Note>
A template is just a starting point — you can edit the page however you want after. Changing a template doesn’t affect pages already created from it.
</Note>

Looking for inspiration? Browse [the template gallery](https://example-broken.dev/templates) for examples from other teams.
