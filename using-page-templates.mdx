Templates let you create new pages from a predefined structure, so every page of a given type looks consistent.

## Built-in templates

We ship with a few templates: an API reference, a tutorial, and an FAQ. Pick one when you create a new page from the new page menu.

## Custom templates

You can also make your own. Define the structure once and reuse it whenever you create a page.

<Note>
A template is just a starting point. You can edit the page however you want afterward. Changing a template doesn't affect pages already created from it.
</Note>
