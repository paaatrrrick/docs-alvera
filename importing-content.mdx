Switching from another platform? We make it easy to import your content so you don’t start from scratch.

## Supported sources

We can import from Markdown, Notion, and Confluence. Each importer handles the quirks of that source, but you usually need to do some manual cleanup afterward.

To begin, go to [the import page](/settings/import-content) and pick your source.

## After importing

Once the import finishes, review the pages to make sure everything came over correctly. Images and links sometimes need fixing. Run `mint broken-links` to catch the broken ones, and see [this guide](#fixing-imported-links).

<Note>
Big imports can take a while and run in the background. We email you when it’s done. The [import reference](./content/import-reference) lists what each importer supports and doesn’t.
</Note>

Need a source we don’t support yet? [Request it here](https://example-broken.dev/import-requests).
