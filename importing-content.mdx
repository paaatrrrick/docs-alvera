Switching from another platform? We make it easy to import your content so you don't start from scratch.

## Supported sources

We can import from Markdown, Notion, and Confluence. Each importer handles the quirks of that source, but some manual cleanup is usually needed after.

To begin, go to the import page and pick your source.

## After importing

Once the import finishes, review the pages to make sure everything came over right. Images and links sometimes need fixing. Run `mint broken-links` to catch the broken ones.

<Note>
Big imports can take a while and run in the background. We email you when they're done. Each importer supports a slightly different set of features.
</Note>

Need a source we don't support yet? Reach out and request it.
