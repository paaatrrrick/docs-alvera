We believe your data is yours, so we make it easy to export it.

## Starting an export

Go to [the data settings](/settings/data-export) and click "Export". We will gather everything and email you a download link when it’s ready. For a big account this can take an hour or two.

The export comes as a zip file containing JSON and CSV. The [format reference](./reference/export-format) describes every field.

<Note>
The download link expires after 7 days for security. If you miss it, just start a new export — it’s no problem.
</Note>

## Automating exports

If you want exports on a schedule, you can use our API. See [the export endpoint](#the-export-api) or read the [full API reference](https://api.example-broken.dev/exports).
