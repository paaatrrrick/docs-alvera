# ライトセーバー

ライトセーバーは、カイバー・クリスタルを核として作られたエネルギー兵器です。ジェダイやシスをはじめとするフォース感応者たちは、防衛、儀式、戦闘にライトセーバーを用います。

## 構造

ほとんどのライトセーバーは、次の3つの主要な要素で構成されています。

- **柄**: エミッター、パワーセル、操作装置、集束システムを内蔵しています。
- **カイバー・クリスタル**: フォースに同調したクリスタルがエネルギーを集束し、安定したブレードを生み出します。
- **ブレード**: 磁場がプラズマ状のエネルギーブレードを封じ込め、多くの物質を切断できます。

デザインは大きく異なります。単刃のセーバーが最も一般的です。両刃、クロスガード、湾曲した柄、ショート型のデザインは、それぞれ異なる戦闘スタイルに対応します。

## ブレードの色

クリスタルと使い手の結びつきが、ブレードの色に影響を与えます。ジェダイは青や緑のブレードを使うことが多く、シスやほかの暗黒面の使い手は赤いブレードを使うのが一般的です。銀河にはほかの色も見られますが、それだけで使い手がどちらに属するかを示すものではありません。

暗黒面の使い手は、**血染め**と呼ばれることの多い過程でカイバー・クリスタルを堕落させ、赤いブレードを生み出すことができます。フォースの使い手は、後に堕落したクリスタルを癒やし、白いブレードを生み出すこともできます。

## 戦闘フォーム

ライトセーバーの戦闘術は、いくつかの伝統的な型へと発展しました。

| 型 | 重視する点 |
| --- | --- |
| I: Shii-Cho | 基礎的な攻撃と武装解除の技術 |
| II: Makashi | 精密さとライトセーバー同士の決闘 |
| III: Soresu | 防御の動きと持久力 |
| IV: Ataru | フォースに支えられたアクロバティックな攻撃 |
| V: Shien and Djem So | 反撃と力強さ |
| VI: Niman | 複数の流派を組み合わせたバランスの取れたスタイル |
| VII: Juyo and Vaapad | 攻撃的で習得の難しい技術 |

戦士が選ぶ型には、訓練、体格、気質、戦場での必要性が反映されます。熟練者は、1つの型だけに専念するのではなく、複数の技術を組み合わせることがよくあります。

## 安全と規律

ライトセーバーは、使い手にとっても危険な武器です。訓練では、動きを制御すること、周囲への注意、そして自制が重視されます。ジェダイは伝統的に、この武器を地位の象徴ではなく、責任を伴うものとして扱います。
