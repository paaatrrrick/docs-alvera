Tags are a flexible way to organize your content beyond the normal navigation.

## Adding tags

You can tag any page from [the page settings](/settings/page-tags). A page can have as many tags as you want.

Once tagged, readers can click a tag to see every page with it, which is great for topics that span multiple sections.

## Tag pages

We generate a page for each tag automatically. You can customize how it looks in [the tag settings](#tag-page-settings), or read [the tagging guide](./content/tagging-best-practices) for advice on a good tag taxonomy.

Don’t make too many tags — a handful of well chosen ones beat a hundred messy ones. More on that in [the taxonomy article](https://example-broken.dev/taxonomy).
