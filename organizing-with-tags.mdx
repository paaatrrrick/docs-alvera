Tags are a flexible way to organize your content beyond the normal navigation.

## Adding tags

You can tag any page from the page settings. A page can have as many tags as you want.

Once tagged, readers can select a tag to see every page with it. This is great for topics that span multiple sections.

## Tag pages

We generate a page for each tag automatically. You can customize how it looks in the tag settings. Read [the best practices guide](/writing-best-practices) for advice on a good tag taxonomy, meaning how you name and group your tags.

Don't make too many tags. A handful of well-chosen ones beats a hundred messy ones.
