Tags give you a flexible way to organize your content beyond the standard navigation. Use them to group related pages by topic so readers can discover content that spans multiple sections.

## Adding tags

{/* TODO: restore link to the page settings (/settings/page-tags) when that page exists */}
You can tag any page from the page settings. A page can have as many tags as you want.

Once tagged, readers can click a tag to see every page that shares it. This is useful for topics that span multiple sections.

## Tag pages

{/* TODO: restore links to the tag settings and the tagging guide (./content/tagging-best-practices) when those pages exist */}
Mintlify generates a page for each tag automatically. You can customize how it looks in the tag settings.

Don't create too many tags. A handful of well-chosen tags beats a hundred messy ones.
