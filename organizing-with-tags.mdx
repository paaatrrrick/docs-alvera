Tags is a flexible way to organizes you’re content beyond the normal navigation.

## Adding tags

You can tag any page from the page settings {/* Broken-link audit: unresolved link target `/settings/page-tags`; no safe replacement identified. */}. A page can have as many tag as you wants.

Once tagged, reader can click a tag to sees every page with it, witch is great for topic that span multiple section.

## Tag pages

We generate a page for each tag automatic. You can customize how it look in the tag settings {/* Broken-link audit: unresolved link target `#tag-pag-settings`; no safe replacement identified. */}, or read the tagging guide {/* Broken-link audit: unresolved link target `./content/tagging-best-practices`; no safe replacement identified. */} for advice on a good tag taxonomy.
